If your agent can be reached at a phone number, or can dial one, Bluejay can test it. No SDK, no infrastructure: Bluejay handles the telephony on its side.

### Which direction?

- **Inbound agent**: your agent answers calls. Bluejay's digital human dials your number.
- **Outbound agent**: your agent places calls. Bluejay's digital humans answer on their own numbers.

## Inbound: Bluejay dials your agent

1. Click **Create Agent**, set type **Inbound**, mode **Voice**, connection type **Phone**, and paste your agent's phone number in full international format (e.g. `+15551234567`).
2. Go to the **Simulations** page, click **Create Simulation** in the top left, select your agent, and add or auto-generate digital human personas.
3. In the **Simulations** tab, click **Run** on the simulation, then click **Run Calls**.
4. When the calls finish, review transcripts, recordings, and metric scores.

Works with any phone system: VoIP providers, cloud contact centers, PBX, toll-free, or a plain mobile number.

## Outbound: your agent dials Bluejay

1. Click **Create Agent**, set type **Outbound**, mode **Voice**, connection type **Phone**.
2. Give each digital human in your simulation a phone number. These are the numbers your agent will dial.
3. In Bluejay, add a webhook subscribed to the `outbound_simulation_started` event (see [Webhooks](/key-concepts/webhooks/overview)). When you run the simulation, it delivers the numbers to dial:

```json
{
  "type": "outbound_simulation_started",
  "agent_id": 123,
  "simulation_id": 123,
  "simulation_run_id": 123,
  "digital_humans": [
    { "id": 123, "name": "example_name", "phone_number": "+15551234567", "associated_simulation_result_ids": [123] }
  ]
}
```

4. When the webhook fires, have your system place a call to each `phone_number`, exactly as it dials real customers. You can also dial the numbers manually for a quick test; the digital humans wait on their lines until the run's timeout.
5. The digital humans answer, the conversations run, and results land like any other simulation.

### Things to note

- **Direction is set on the agent**, not the simulation. An Inbound agent is always called by Bluejay; an Outbound agent must place the calls itself.
- **Outbound runs wait for your agent to dial.** Tests stay pending until the call arrives or the timeout hits.
- **Tool calls and traces aren't captured over plain phone calls.** The phone network can't carry the simulation ID your system would need to link them. If you need tool call capture, use [SIP](/simulation-integrations/sip) or a native provider integration (Vapi, Retell, ElevenLabs, LiveKit).
