Sync your Retell agents into Bluejay and run simulations against them, in either direction. Every tool call the agent makes during a conversation lands in Bluejay's Tool Adherence tab.

### Ways to connect

The synced (direct) integration handles both directions; the Bluejay agent's **type** picks the path automatically:

| You want to test... | Mechanism | Phone number? | Tool calls captured? |
|---|---|---|---|
| An agent that answers calls (**inbound**) | Web-call bridge into Retell's cloud | Not needed | Yes |
| An agent that **places** calls (outbound) | Bluejay tells Retell to place the call | **Required**: a Retell number bound to the agent | Yes |
| The agent over its **real phone number** | [Phone connection](#phone-connection): Bluejay dials it like a real caller | The agent's Retell number | No |

For the direct integration, steps 1 to 3 below are the same for both directions. Then jump to [Inbound](#inbound-run-it) or [Outbound](#outbound-bind-a-number-then-run).

### Quick Prerequisites

- **Retell API Key with the Webhook badge**
- **At least one Retell agent**
- **A Bluejay Account**

## Setup (both directions)

### 1. Generate Your Retell API Key

1. In Retell, go to **Settings** then **API Keys**, and generate a new API key.
2. Ensure the key has the **Webhook** badge next to it (Bluejay uses it to verify webhook signatures).

<video autoPlay muted loop playsInline className="w-full rounded-xl" src="/videos/retell-sim-1.mp4"></video>

### 2. Set the Webhook URL on Your Retell Agent

1. In Retell, open your agent and click **Webhook Settings**.
2. Paste this URL into **Agent Level Webhook URL**:

```
https://api.getbluejay.ai/v1/integrations/retell
```

3. Keep the default events enabled: `call_started`, `call_ended`, `call_analyzed`.
4. Save and publish the agent.

<video autoPlay muted loop playsInline className="w-full rounded-xl" src="/videos/retell-sim-3.mp4"></video>

### 3. Save Your Key in Bluejay and Sync

1. In Bluejay, go to **Settings**, then **Integrations**, then the **Retell** tab.
2. Paste your Retell API key and click **Save Changes**.
3. Click **Sync Agents from Retell** and confirm in the prompt.
4. Within 5 to 15 seconds, every Retell agent in your workspace appears in Bluejay as a native agent.

<video autoPlay muted loop playsInline className="w-full rounded-xl" src="/videos/retell-sim-4.mp4"></video>

<Tip>
  Faster path: click the **+** button in the top left of Bluejay, select **Retell**, paste your API key, and click **Save and Sync**.

  <video autoPlay muted loop playsInline className="w-full rounded-xl" src="/videos/retell-sim-5.mp4"></video>
</Tip>

## Inbound: run it

Your agent answers; the digital human calls in. Nothing else to configure.

1. Open your synced agent in Bluejay and confirm its type is **Inbound**.
2. Go to the **Simulations** page and click **Create Simulation** in the top left, then open the **Goal Adherence Rate** tab and click **Auto-generate** to create digital human personas from your agent's prompt. Pick how many you want and click **Save**.
3. Click **Generate Digital Human** and confirm it's selected.
4. Back in the **Simulations** tab, click **Run** on the simulation, then click **Run Calls**.
5. When the call finishes, review the transcript, tool calls, and metric scores.

<video autoPlay muted loop playsInline className="w-full rounded-xl" src="/videos/retell-sim-6.mp4"></video>

## Outbound: bind a number, then run

Your agent dials; the digital human answers. Bluejay uses your Retell API key to tell Retell to place the call, so the agent needs a number to dial from.

### 1. Bind a phone number to your agent in Retell

1. In Retell, go to **Phone Numbers** and click into your phone number.
2. Set both **Inbound Call Agent** AND **Outbound Call Agent** to your agent.
3. Save.

<video autoPlay muted loop playsInline className="w-full rounded-xl" src="/videos/retell-sim-2.mp4"></video>

### 2. Set the Bluejay agent to Outbound

Open the synced agent in Bluejay and set its type to **Outbound**. The Connection tab shows the number bound in Retell.

### 3. Run it

Create a simulation the same way as inbound (each digital human needs a phone number for your agent to dial). Then, in the **Simulations** tab, click **Run** on the simulation and click **Run Calls**. Bluejay tells Retell to dial each digital human from your bound number, and the calls place automatically.

## Phone connection

If your Retell agent is bound to a phone number, you can also skip the integration entirely and test it the way a real caller reaches it.

1. Create an agent in Bluejay with type **Inbound**, mode **Voice**, and the **Phone** connection type.
2. Paste the agent's Retell phone number in full international format (e.g. `+15551234567`).
3. Create a simulation and run it. Bluejay dials the number and the digital human holds the conversation.

Use this when you specifically want to exercise the real telephony path: carrier audio, DTMF, the exact number your customers dial. The tradeoff: tool calls aren't linked to the result over a plain phone call, so results cover the conversation itself (transcript, recording, metrics). For tool call capture, use the synced integration above.

### Caveats

| Issue | Cause | Fix |
|---|---|---|
| Outbound call never places | No Retell phone number bound to the agent (there's no fallback) | Bind a number to the agent in Retell, then re-sync |
| Sync/webhook rejected (401) | API key missing, or missing the **Webhook** badge | Save a webhook-enabled key in Settings → Integrations → Retell |
| Setup fails, missing agent id | No `Retell Agent ID` on the agent | Set the Retell Agent ID (type it or pick from the synced list) |
| `NO_CONNECTION`, concurrency limit | Retell 429 (inbound) or SIP 503 (outbound) — too many concurrent calls | Lower Bluejay's max-concurrent (not a key issue) |
| Tool calls missing | Agent webhook URL not set in Retell | Set the agent webhook to `https://api.getbluejay.ai/v1/integrations/retell` (a backfill poller is best-effort otherwise) |
| Older call fails as `SIP_TRUNK_RECYCLED` | Same digital-human phone number reused across concurrent outbound runs | Give concurrent runs distinct DH numbers |
