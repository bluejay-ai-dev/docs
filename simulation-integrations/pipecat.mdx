To test your Pipecat Cloud agent, Bluejay starts a session for it in a Daily room and joins the room as a Digital Human, so you need no phone number.

## Connect

<Steps>
<Step title="Deploy the agent">
Deploy your agent to Pipecat Cloud with the [Pipecat quickstart](https://docs.pipecat.ai/getting-started/quickstart). Note the agent name in `pcc-deploy.toml`, because you enter it in Bluejay later.
</Step>
<Step title="Create a public API key">
In the Pipecat dashboard, open **API Keys** and create a key on the **Public** tab. The key starts with `pk_`.
</Step>
<Step title="Add the key to Bluejay">
Paste the key on the **Pipecat** tab of the Integrations settings, or on the agent.
</Step>
<Step title="Create the agent">
Create an Inbound Voice agent, choose the **Pipecat** connection type, and enter the agent name from the first step as **Pipecat Agent Name**. The **Pipecat** connection supports inbound agents only.
</Step>
</Steps>

<Warning>
A private Pipecat key does not work. Bluejay rejects a key that does not start with `pk_`, and the call fails with **No Connection** and `PIPECAT_CONNECTION_FAILED`.
</Warning>

## Fields

Set these fields on the agent:

| Field | Required | Description |
|---|---|---|
| Pipecat Agent Name | Yes | The agent name in Pipecat Cloud. |
| Pipecat Agent Configuration | No | JSON that Bluejay sends as `body` to your agent on start. |
| Pipecat Room Properties | No | JSON that Bluejay merges into the Daily room properties. |

To report tool calls from a simulation, your bot needs its result ID. Bluejay adds the simulation IDs (`X-Simulation-Result-Id` and the other `X-` keys) to the `body` it sends on start, so your bot can read its own result ID from `args.body` and send its tool calls to [`/v1/update-simulation-result`](/api-reference/endpoint/update-simulation-result).

## Limits

If a run fails, find the symptom below:

| Symptom | Cause |
|---|---|
| **No Connection** with `PIPECAT_CONNECTION_FAILED` | The Pipecat session stopped before audio started, for example because the key is not a `pk_` key. |
| Run fails at start | No Pipecat key is saved, or the agent has no **Pipecat Agent Name**. |
