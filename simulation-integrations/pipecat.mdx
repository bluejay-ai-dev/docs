Bluejay calls the Pipecat Cloud start endpoint for your agent. Then it joins the Daily room that Pipecat creates and talks to your agent as a Digital Human.

## Connect

<Steps>
<Step title="Deploy the agent">
Deploy your agent to Pipecat Cloud. Use the [Pipecat quickstart](https://docs.pipecat.ai/getting-started/quickstart). Record the agent name from `pcc-deploy.toml`.
</Step>
<Step title="Create a public API key">
In the Pipecat dashboard, open **API Keys**. Create a key on the **Public** tab. The key starts with `pk_`.
</Step>
<Step title="Add the key to Bluejay">
Open **Settings**, then **Integrations**, then the **Pipecat** tab. Paste the key and click **Save Changes**.
</Step>
<Step title="Create the agent">
Create an agent with mode **Voice** and connection type **Pipecat**. Enter the **Pipecat Agent Name**.
</Step>
</Steps>

<Warning>
A private Pipecat key does not work. Bluejay rejects a key that does not start with `pk_`, and the call fails.
</Warning>

## Fields

| Field | Required | Description |
|---|---|---|
| Pipecat Agent Name | Yes | The agent name in Pipecat Cloud. |
| Pipecat Agent Configuration | No | JSON that Bluejay sends as `body` to your agent on start. |
| Pipecat Room Properties | No | JSON that Bluejay merges into the Daily room properties. |

Bluejay adds the simulation IDs (`X-Simulation-Result-Id` and related keys) to the `body` it sends on start. Your bot can read its own result ID from `args.body` and report tool calls to [`/v1/update-simulation-result`](/api-reference/endpoint/update-simulation-result).

## Test

Create a simulation for the agent and run it. Each call starts a new Pipecat session. Open the result to see the transcript and recording.
