Bluejay sends Digital Human messages to your Kore.ai bot through its Webhook channel, and the bot replies to a Bluejay webhook URL.

## Connect

You need a Kore.ai bot with a **Webhook** channel. The channel app must use **HS256** as the JWT signing algorithm. Bluejay does not support RS256.

<Steps>
<Step title="Copy the Kore.ai credentials">
In Bot Builder, open **Channels & Flows**, then **Webhook**, then **Configurations**. Copy the values in the table below.
</Step>
<Step title="Create the agent in Bluejay">
Create an agent with mode **Text** and connection type **Kore.ai**. Enter the four fields, then save the agent.
</Step>
<Step title="Generate the access token">
In the agent **Connection** settings, click **Generate access token**. Copy the token. To see it again later, click **View access token**.
</Step>
<Step title="Configure the Kore.ai Webhook channel">
Set **Integration Mode** to **Asynchronous**. Paste the **Bluejay Webhook URL** into **Post URL**. Paste the token into **Access Token**.
</Step>
<Step title="Publish the bot">
Save the channel, then publish the bot. The Webhook channel does not send messages until you publish.
</Step>
</Steps>

| Bluejay field | Kore.ai value | API field |
|---|---|---|
| Kore Host | The platform domain only, for example `https://platform.kore.ai` | `kore_host` |
| Bot ID | **Bot Id**, starts with `st-` | `kore_bot_id` |
| Client ID | The Webhook app **Client ID**, starts with `cs-` | `kore_client_id` |
| Client Secret | The Webhook app **Client Secret** | `kore_client_secret` |

The Bluejay Webhook URL has this format: `https://api.getbluejay.ai/v1/kore-webhook/<agent_id>`.

<Note>
Do not put the full Post URL in **Kore Host**. Bluejay adds the `/chatbot/v2/webhook/<bot_id>` path, so a full URL gives a 404.
</Note>

<Accordion title="Create the agent with the API">

```bash
curl -X POST https://api.getbluejay.ai/v1/add-agent \
  -H "X-API-Key: $BLUEJAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Kore Support Bot",
    "type": "INBOUND",
    "mode": "TEXT",
    "connection_type": "KORE",
    "kore_host": "https://platform.kore.ai",
    "kore_bot_id": "st-...",
    "kore_client_id": "cs-...",
    "kore_client_secret": "<HS256 secret>"
  }'
```

Then send `POST /v1/generate-kore-inbound-token` with the `agent_id`. The response shows the token one time. A second call replaces the token.

</Accordion>

## Test

Create a simulation for the agent and run it. With the API, use [`/v1/queue-http-text-simulation-run`](/api-reference/endpoint/queue-http-text-simulation-run). Kore.ai agents use the same queue as HTTP Webhook agents.

| Symptom | Cause | Fix |
|---|---|---|
| `ConnectTimeout` in the result error | Bluejay cannot reach the Kore.ai host | Use a host that the public internet can reach. |
| Kore.ai returns 401 | Kore.ai rejects the JWT | Check Client ID and Client Secret, and make sure the app uses HS256. |
| Kore.ai returns 404 | Wrong Bot ID, bot not published, or full URL in Kore Host | Fix the field, then publish the bot. |
| `POST /v1/kore-webhook/<agent_id>` returns 401 | The access token in Kore.ai does not match | Copy the token from **View access token** into Kore.ai again. |
| Replies show in Kore.ai but not in Bluejay | The channel uses Synchronous mode | Set Asynchronous mode and publish again. |

## Limits

- If your Kore.ai tenant resolves to private IP addresses, Bluejay cannot reach it. You need a public endpoint or a network tunnel.
- If you rotate the Client Secret in Kore.ai, update **Client Secret** on the Bluejay agent.
