## Connect

<Tabs>
<Tab title="Website">
1. Create an agent with mode **Text** and connection type **HTTP Webhook**.
2. Enter the **HTTP Webhook URL**.
3. Save the agent.
4. Under **Webhook Signing Key**, click **Generate signing key** and copy the key.
</Tab>
<Tab title="API">

```bash
curl -X POST https://api.getbluejay.ai/v1/add-agent \
  -H "X-API-Key: $BLUEJAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Customer Support Bot",
    "type": "INBOUND",
    "mode": "TEXT",
    "connection_type": "HTTP_WEBHOOK",
    "http_webhook": "https://your-server.com/webhook"
  }'
```

Set `http_webhook_sync_reply` to `true` if your endpoint returns the agent reply in the response body. See [Reply in the response body](#reply-in-the-response-body).
</Tab>
</Tabs>

## Run a conversation

<Steps>
<Step title="Queue the run">
In the app, open the simulation and click **Create New Run**. With the API, call [`/v1/queue-http-text-simulation-run`](/api-reference/endpoint/queue-http-text-simulation-run) with `simulation_id`.

```json
{ "simulation_run_id": "4434", "simulation_result_ids": ["13062"], "agent_id": "258", "status": "success" }
```

You get one `simulation_result_id` per conversation. Optional request fields: `digital_human_ids`, `runs_per_digital_human`, `agent_version_id`.
</Step>
<Step title="Receive the first message">
For an **Inbound** agent, Bluejay posts the Digital Human first message to your webhook. For an **Outbound** agent, Bluejay posts `"message": null` to tell your agent to start.
</Step>
<Step title="Reply">
Send each agent message to `/v1/send-http-text-message` with the `simulation_result_id`.

```bash
curl -X POST https://api.getbluejay.ai/v1/send-http-text-message \
  -H "X-API-Key: $BLUEJAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "simulation_result_id": "13062",
    "message": "What operating system do you have?",
    "message_id": "682098ae-2ec1-4d4f-8223-0cdd9580cff3"
  }'
```
</Step>
<Step title="End the conversation">
Send `"end_conversation": true` to end and evaluate the conversation. The Digital Human can also end it.
</Step>
</Steps>

## Fields

Request to `/v1/send-http-text-message`:

| Field | Type | Required | Description |
|---|---|---|---|
| `simulation_result_id` | string | Yes | The conversation ID. |
| `type` | string | No | `message` (default) or `tool_call`. |
| `message` | string | If `type` is `message` | The agent message. |
| `end_turn` | boolean | No | Default `true`. If `false`, Bluejay holds the message and waits for more. |
| `end_conversation` | boolean | No | Default `false`. If `true`, Bluejay ends and evaluates the conversation. |
| `message_id` | string | No | Bluejay drops a second message with the same ID. |
| `name` | string | If `type` is `tool_call` | The tool name. |
| `parameters` | object | No | The tool input. |
| `output` | any | No | The tool output. |

Webhook body that Bluejay sends to your URL:

```json
{
  "simulation_result_id": "13062",
  "message_id": "15a481c1-...",
  "message": "Hi, I need help with a refund.",
  "metadata": null,
  "end_conversation": false,
  "end_turn": true
}
```

Return any `2xx` status. Bluejay sends `Content-Type: application/json`, and `X-Bluejay-Signature` when the agent has a signing key.

## Log tool calls

Send one request with `"type": "tool_call"` for each tool your agent runs. Bluejay stores the tool call on the result and computes `start_offset_ms`. A tool call does not add a transcript line and does not start a Digital Human reply.

```bash
curl -X POST https://api.getbluejay.ai/v1/send-http-text-message \
  -H "X-API-Key: $BLUEJAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "simulation_result_id": "13062",
    "type": "tool_call",
    "name": "lookup_order",
    "parameters": {"order_id": "ORD-2024-001"},
    "output": {"status": "shipped"}
  }'
```

## Reply in the response body

If `http_webhook_sync_reply` is `true`, Bluejay reads the agent reply from your webhook response and you do not call `/v1/send-http-text-message`. Bluejay waits up to 60 seconds for the response.

The body can be one object, a list of objects, or a string. Bluejay reads the first of these keys: `message`, `reply`, `text`, `content`, `response`. It also reads `end_turn` and `end_conversation`. If Bluejay finds no message, it waits for `/v1/send-http-text-message`.

## Verify the signature

Bluejay signs the raw body with HMAC-SHA256 and the signing key, and sends the hex digest in `X-Bluejay-Signature`. Compute the digest over the raw bytes before you parse the JSON.

```python
import hashlib, hmac

def verify_signature(raw_body: bytes, signature_header: str, signing_key: str) -> bool:
    expected = hmac.new(signing_key.encode(), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature_header)
```

Bluejay creates the key the first time you save an HTTP webhook. Later updates keep the same key. To see it, click **View signing key** in the agent **Connection** settings.

## Limits

- Bluejay waits 10 seconds for your webhook to respond, or 60 seconds with `http_webhook_sync_reply`.
- By default, if no message arrives for 5 minutes, Bluejay ends the conversation.
