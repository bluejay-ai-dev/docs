Bluejay opens a WebSocket to your server and exchanges raw audio with it. The protocol is CHIRP: binary frames carry audio, and optional text frames carry events.

## Connect

Create an agent with mode **Voice** and connection type **Websocket**, then fill in the fields.

| Field | Required | Description |
|---|---|---|
| Websocket URL | Yes | For example `wss://your-host/voice`. |
| Websocket Username | No | If set with the password, Bluejay sends `Authorization: Basic <base64(user:pass)>`. |
| Websocket Password | No | See Websocket Username. |

Bluejay also sends `X-Simulation-Result-Id` on the upgrade request. Use it with [`/v1/update-simulation-result`](/api-reference/endpoint/update-simulation-result) to report tool calls or traces.

The minimum server accepts the upgrade, checks the credentials, reads binary frames, and writes binary frames. You can ignore all text frames.

<CodeGroup>

```python Python (websockets)
# pip install websockets
import asyncio, base64, os
from websockets.asyncio.server import serve

EXPECTED = "Basic " + base64.b64encode(
    f"{os.environ['CHIRP_USER']}:{os.environ['CHIRP_PASS']}".encode()).decode()

async def handler(ws):
    if ws.request.headers.get("Authorization") != EXPECTED:
        await ws.close(1008, "unauthorized"); return
    async for msg in ws:
        if isinstance(msg, bytes):
            await ws.send(msg)  # replace the echo with your agent audio

async def main():
    async with serve(handler, "0.0.0.0", 8080):
        await asyncio.Future()

asyncio.run(main())
```

```typescript TypeScript (ws)
// npm i ws
import { createServer } from 'http'
import { WebSocketServer } from 'ws'

const { CHIRP_USER, CHIRP_PASS } = process.env
const expected = 'Basic ' + Buffer.from(`${CHIRP_USER}:${CHIRP_PASS}`).toString('base64')

const server = createServer()
const wss = new WebSocketServer({ noServer: true })

server.on('upgrade', (req, socket, head) => {
  if (req.headers.authorization !== expected) {
    socket.write('HTTP/1.1 401 Unauthorized\r\n\r\n'); socket.destroy(); return
  }
  wss.handleUpgrade(req, socket, head, (ws) => wss.emit('connection', ws, req))
})

wss.on('connection', (ws) => {
  ws.on('message', (data, isBinary) => {
    if (isBinary) ws.send(data, { binary: true }) // replace the echo with your agent audio
  })
})

server.listen(8080)
```

```go Go (gorilla/websocket)
package main

import (
    "crypto/subtle"
    "encoding/base64"
    "net/http"
    "os"

    "github.com/gorilla/websocket"
)

var up = websocket.Upgrader{CheckOrigin: func(r *http.Request) bool { return true }}

func main() {
    expected := "Basic " + base64.StdEncoding.EncodeToString(
        []byte(os.Getenv("CHIRP_USER")+":"+os.Getenv("CHIRP_PASS")))
    http.HandleFunc("/voice", func(w http.ResponseWriter, r *http.Request) {
        if subtle.ConstantTimeCompare([]byte(r.Header.Get("Authorization")), []byte(expected)) != 1 {
            http.Error(w, "unauthorized", 401); return
        }
        c, err := up.Upgrade(w, r, nil)
        if err != nil { return }
        defer c.Close()
        for {
            mt, msg, err := c.ReadMessage()
            if err != nil { return }
            if mt == websocket.BinaryMessage {
                _ = c.WriteMessage(websocket.BinaryMessage, msg)
            }
        }
    })
    http.ListenAndServe(":8080", nil)
}
```

## Audio

| Property | Value |
|---|---|
| Frame type | WebSocket binary |
| Encoding | `pcm_s16le` (signed 16-bit little-endian) |
| Sample rate | 16000 Hz |
| Channels | 1 (mono) |
| Frame size | Any even byte length. 20 ms (640 bytes) is a good size. |

Play every binary frame from Bluejay as the Digital Human voice. Send your agent audio in the same format.

## Text events

Text frames are UTF-8 JSON with one envelope. If you omit `id`, `ts_ms`, or `data`, Bluejay fills them in.

```json
{ "type": "speech.started", "id": "c0e1a39f-...", "ts_ms": 1729123456789, "data": { "utterance_id": "u_abc123" } }
```

| `type` | `data` | Bluejay sends it when | If you send it |
|---|---|---|---|
| `speech.started` | `utterance_id` | The Digital Human starts to speak. | If the Digital Human is speaking, Bluejay interrupts it and sends `speech.completed` for that utterance. |
| `speech.completed` | `utterance_id` | The Digital Human stops speaking. | Bluejay records the end of your turn. |
| `session.error` | `code`, `message` | Your frame is not valid. Bluejay drops the frame and the session continues. | Bluejay logs it in the result metadata under `customer_session_errors`. |
| `mark` | `name` | Only as an echo of your `mark`. | Bluejay echoes the same `name` after all audio you sent before it has played to the Digital Human. |

Bluejay derives `speech.started` and `speech.completed` from speaker detection. Some audio frames of an utterance can arrive before `speech.started` or after `speech.completed`. Do not stop playback on `speech.completed`.

To interrupt the Digital Human (barge-in), send `speech.started`. There is no separate interrupt event.

To match a `mark` echo, use `data.name`. The echo has a new `id` and `ts_ms`.

`session.error` codes:

| Code | Meaning |
|---|---|
| `INVALID_MESSAGE` | The JSON is not valid, `type` is unknown, or `data` is not an object. |
| `MISSING_FIELD` | `type`, `utterance_id`, or `name` is missing. |
| `INVALID_AUDIO_FRAME` | The binary frame is empty or has an odd byte length. |

## Test

Create a simulation for the agent and run it. To end a call, close the WebSocket with code `1000`. Bluejay also closes the WebSocket when the call ends.

## Limits

- If your server returns HTTP 401 or 403 on the upgrade, Bluejay does not retry. Check the username and password.
- If your server returns HTTP 429, Bluejay does not retry. Lower the simulation concurrency.
- For other connection failures, Bluejay tries 3 times with backoff.
