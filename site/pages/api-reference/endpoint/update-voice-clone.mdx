Renames a cloned or generated voice, sets its gender, or both. Send only the fields you change. `gender` sets grammatical gender in languages that have it. Digital Humans that use the voice keep it.

Returns `voice_id`, `name` and `gender`.

Rate limit: 100 requests per minute.
