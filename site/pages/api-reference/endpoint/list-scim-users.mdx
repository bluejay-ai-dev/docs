title: "GET /v1/scim/Users"

`GET https://api.getbluejay.ai/v1/scim/Users`

<Note>
  SCIM endpoints authenticate with a SCIM token from **Settings → Security → User provisioning (SCIM)**, sent as `Authorization: Bearer <token>`. A Bluejay API key does not work here. Identity providers like Okta and Entra call these for you; see [SSO and User Provisioning](/administration/sso-and-provisioning).
</Note>

## Authorization

<ParamField name="Authorization" type="string" required>
  SCIM token from Settings → Security → User provisioning (SCIM). Not an API key.
</ParamField>

## Query parameters

<ParamField query="filter" type="string or null"></ParamField>

<ParamField query="startIndex" type="integer">
  Default: `1`
</ParamField>

<ParamField query="count" type="integer">
  Default: `100`
</ParamField>
