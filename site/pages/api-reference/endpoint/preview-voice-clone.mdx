Returns a short spoken sample of a cloned or generated voice as an MP3 (`audio/mpeg`). A generated voice plays over its own background clip. `voice_id` is the ID that [Create Voice Clone](/api-reference/endpoint/create-voice-clone) returns.

Rate limit: 100 requests per minute.
