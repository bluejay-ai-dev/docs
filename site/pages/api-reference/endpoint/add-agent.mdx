Every connection type also reads `provider_request_data`, the agent's variables.

An `OPENAI_REALTIME` agent without `openai_realtime_url` connects to OpenAI's own Realtime endpoint. An `EMAIL` agent always gets `mode` `EMAIL`.

If you leave out `connection_type`, Bluejay infers it from the fields you send. For example, `vapi_assistant_id` makes a `VAPI` agent. Google CES, Dialogflow CX, Amelia and Bland agents are inferred as voice agents, so send `connection_type` for a chat agent. A request with none of these fields makes a `PHONE` agent.
