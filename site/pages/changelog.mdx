## Hang up on transfer is on by default

  <Columns cols={1}>

**November 19th, 2026**

*Improvement* *API* *Simulations*

</Columns>

  New simulations now hang up when the agent transfers the call, so a Digital Human never reaches your live team by accident. This applies to simulations created in the app, through Create Simulation and through Bluejay as Code. Pass `hangup_on_transfer: false` to let transfers through. Existing simulations keep their setting.

## Digital Human tags

  <Columns cols={1}>

**November 4th, 2026**

*Improvement* *API* *Digital Humans*

</Columns>

  The `tag` query parameter on `GET /v1/digital-humans` and the `tag` field on Create and Update Digital Human are deprecated. They stop working November 11, 2026. Use `tags` instead. A request that still uses `tag` returns a `warning` field in the response.

  The `tags` filter ignores case and accepts several tags. Repeat the parameter, as in `?tags=a&tags=b`, or pass a JSON list. A Digital Human must have every tag you list.

  The `tag` field on Digital Human responses stays for now.

  [List Digital Humans](/api-reference/endpoint/get-all-digital-humans) · [Create Digital Human](/api-reference/endpoint/create-digital-human) · [Update Digital Human](/api-reference/endpoint/update-digital-human)

## Agent variables

  <Columns cols={1}>

**November 3rd, 2026**

*New* *Simulations*

</Columns>

  Set values once on an agent in **Agent Variables** on the **Simulation Settings** tab, and every Digital Human of that agent uses them on its next run. A Digital Human's trait with the same name overrides an agent variable. Write `{{name}}` in success criteria, intent, description, or personality, and Bluejay fills in the value before the Digital Human and the grader see it, for voice and text.

  Synced Retell conversation flow and ElevenLabs agents fill their agent variables from the provider's default dynamic variables when they have none yet.

  [Agent variables](/test/simulations/digital-humans#agent-variables) · [Update Agent](/api-reference/endpoint/update-agent)

## Itemized success criteria

  <Columns cols={1}>

**October 15th, 2026**

*New* *Simulations*

</Columns>

  Success criteria are bullets now. Each bullet is a workspace `success_criterion` metric. Bluejay grades each expected behavior met / not met, stores `success_score` as passed-count / `max_value`, keeps overall pass/fail at 100%, and reports `criteria_pass_rate` (0–100) on `/v2` retrieve.

  `/v1` digital human get, create, update, generate, and retrieve stay a string and a boolean. There is no public `/v2` generate route yet.

## API key on HTTP text messages

  <Columns cols={1}>

**September 29th, 2026**

*Improvement* *API*

</Columns>

  `POST /v1/send-http-text-message` now requires your API key on every request. Send it as `X-API-Key` or `Authorization: Bearer` with each message and each tool-call log.

  A request without a key returns 401. A key from another organization, or a key limited to a workspace that doesn't own the simulation, returns 404.

  If your agent already sends the same key you use to queue the simulation, nothing changes.

  [Send HTTP Text Message](/api-reference/endpoint/send-http-text-message) · [Chat testing](/integrations/http-webhooks)

## Agent versions

  <Columns cols={1}>

**September 9th, 2026**

*Improvement* *API*

</Columns>

  **New:** agent versions live at `/v1/agents/{id}/versions` (create, list, get, delete, promote, labels).

  **Same as before:** `POST /v1/evaluate` and `/evaluate-call`. New optional integer `version`. `label` still works. Omit `version` and we use the version that currently has the `production` label. An unknown version uses the production version and returns a `warning`. An unknown label is created and attached to the production version.

  **Deprecated:** `/v1/agents/{id}/prompts` paths still work. Get-by-label stays on `GET /prompts?label=` (no `/versions` twin).

  **New:** create/queue simulation accepts `agent_version_id`.

  **Deprecated:** `prompt_id` on create/queue simulation. Same uuid, still works. If both are sent and they differ, the request is 400.

  [Evaluate](/api-reference/endpoint/evaluate) · [Create Agent Version](/api-reference/endpoint/create-prompt-version)

</Columns>
