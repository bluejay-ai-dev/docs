---
title: "Bedrock"
description: "Trace Bedrock Converse calls."
---

`BluejayClient(tracing=True)` traces Bedrock through boto3. No extra package. `converse` and `converse_stream` are covered.

<CodeGroup label="Python and TypeScript examples">

```python title="Python"
from bluejay import BluejayClient

client = BluejayClient(tracing=True)

reply = bedrock.converse(modelId="anthropic.claude-3-5-haiku-20241022-v1:0", messages=messages)
```

```typescript title="TypeScript"
// In Node.js, use an OpenTelemetry instrumentor or a manual model span.
```

</CodeGroup>

When the call runs inside a [session](/sdk/observability#trace-chat-or-sms), the span joins that call.
