## Agents

Ask your assistant to add the agents you test, look them up, change them, or delete them.

| Tool | Description |
|---|---|
| `add_agent` | Create an agent. |
| `get_agent` | Get one agent. |
| `list_agents` | List agents. |
| <Code>update&#95;agent</Code> | Update an agent. |
| <Code>delete&#95;agent</Code> | Delete an agent. |
| <Code>set&#95;agent&#95;mock&#95;tools</Code> | Turn [mock tool calls](/test/simulations/mock-tool-calls) on or off for an agent. Every tool starts on **Generated**. |
| <Code>set&#95;agent&#95;tool&#95;mock</Code> | Set one tool's mode: **Fixed**, **Generated** or **Real backend**. Also turns mock tool calls on for the agent. |

## Agent versions

Ask your assistant to save a new version of your agent, find an earlier version, or label a version.

| Tool | Description |
|---|---|
| <Code>create&#95;agent&#95;version</Code> | Create an agent version. |
| <Code>list&#95;agent&#95;versions</Code> | List agent versions, with an optional label filter. |
| <Code>get&#95;agent&#95;version</Code> | Get an agent version by version number. |
| <Code>get&#95;agent&#95;version&#95;by&#95;id</Code> | Get an agent version by ID. |
| <Code>delete&#95;agent&#95;version</Code> | Delete an agent version. |
| <Code>add&#95;agent&#95;version&#95;labels</Code> | Add labels to an agent version. |
| <Code>list&#95;agent&#95;version&#95;labels</Code> | List the labels on an agent version. |
| <Code>remove&#95;agent&#95;version&#95;labels</Code> | Remove labels from an agent version. |

## Personas

[Personas](/test/simulations/digital-humans#personas) are who calls. Pass `persona_ids` to <Code>create&#95;digital&#95;humans</Code> or <Code>generate&#95;digital&#95;humans</Code> and each Digital Human runs once as each persona; leave it out and it runs once as the baseline, its own settings. On <Code>update&#95;digital&#95;humans</Code>, leaving it out keeps the current personas and `[]` goes back to the baseline. Updating a persona changes every Digital Human that runs as it.

| Tool | Description |
|---|---|
| <Code>list&#95;personas</Code> | List personas. |
| <Code>create&#95;persona</Code> | Create a persona. |
| <Code>update&#95;persona</Code> | Update a persona. |
| <Code>delete&#95;persona</Code> | Delete a persona and take it off every Digital Human. The Default persona can't be deleted. |

## Digital Humans

Each Digital Human is one test case. If you already have test cases, give them to your assistant and ask it to create one Digital Human for each, rather than generating new ones. Your assistant can also generate Digital Humans, add them to simulations, and check how a Digital Human did in past calls. It can also manage your background noises and communities.

| Tool | Description |
|---|---|
| <Code>create&#95;digital&#95;humans</Code> | Create one or more Digital Humans. |
| <Code>generate&#95;digital&#95;humans</Code> | Generate Digital Humans with AI. |
| <Code>get&#95;digital&#95;human</Code> | Get one Digital Human. |
| <Code>list&#95;digital&#95;humans</Code> | List Digital Humans. |
| <Code>update&#95;digital&#95;humans</Code> | Update one or more Digital Humans. |
| <Code>delete&#95;digital&#95;human</Code> | Delete a Digital Human. |
| <Code>duplicate&#95;digital&#95;human</Code> | Copy a Digital Human. |
| <Code>bulk&#95;set&#95;digital&#95;human&#95;simulations</Code> | Set the simulations of up to 100 Digital Humans. |
| <Code>get&#95;digital&#95;human&#95;run&#95;history</Code> | List all calls of one Digital Human. |
| <Code>get&#95;voice&#95;options</Code> | List the voices you can use, and each language's accents, genders, and default accent. |
| <Code>create&#95;custom&#95;background&#95;noise&#95;upload&#95;url</Code> | Get a signed URL to upload a background noise file. |
| <Code>create&#95;custom&#95;background&#95;noise</Code> | Add an uploaded noise to the library. |
| <Code>list&#95;custom&#95;background&#95;noises</Code> | List the background noise library. |
| <Code>create&#95;community</Code> | Create a community. |
| <Code>get&#95;community</Code> | Get one community. |
| <Code>list&#95;communities</Code> | List communities. |
| <Code>update&#95;community</Code> | Update a community. |
| <Code>delete&#95;community</Code> | Delete a community. |

## Simulations

Ask your assistant to set up a simulation, run it, and read the results and transcripts. In an HTTP Webhook conversation, it can also send the agent's messages.

| Tool | Description |
|---|---|
| <Code>create&#95;simulation</Code> | Create a simulation. |
| <Code>get&#95;simulation</Code> | Get one simulation. |
| <Code>list&#95;simulations</Code> | List simulations. |
| <Code>update&#95;simulation</Code> | Update a simulation. |
| <Code>delete&#95;simulation</Code> | Delete a simulation. |
| <Code>queue&#95;simulation&#95;run</Code> | Run a simulation. |
| <Code>queue&#95;email&#95;simulation&#95;run</Code> | Run an email simulation. |
| <Code>get&#95;simulation&#95;runs</Code> | List the runs of a simulation. |
| <Code>get&#95;simulation&#95;results</Code> | Get one page of the results of a run. |
| <Code>get&#95;simulation&#95;result</Code> | Get one result. |
| <Code>get&#95;simulation&#95;transcript</Code> | Get the transcript of one simulation conversation. |
| <Code>send&#95;http&#95;text&#95;message</Code> | Send an agent message in an HTTP Webhook conversation. |
| <Code>end&#95;conversations</Code> | End running conversations. |

## Labs

| Tool | Description |
|---|---|

## Scenarios

Ask your assistant to build or change a Scenario Builder graph one node or edge at a time, and to check a graph before saving it. The tool names say workflow because the API calls each scenario graph a workflow.

| Tool | Description |
|---|---|
| <Code>create&#95;workflow</Code> | Create a scenario. |
| <Code>get&#95;workflow</Code> | Get one scenario. |
| <Code>list&#95;workflows</Code> | List scenarios. |
| <Code>update&#95;workflow</Code> | Update a scenario. |
| <Code>duplicate&#95;workflow</Code> | Copy a scenario. |
| <Code>delete&#95;workflow</Code> | Delete a scenario. |
| <Code>validate&#95;workflow&#95;definition</Code> | Check a scenario graph without saving it. |
| <Code>list&#95;scenario&#95;nodes</Code> | List the nodes and edges of a scenario. |
| <Code>create&#95;scenario&#95;node</Code> | Add a node. |
| <Code>update&#95;scenario&#95;node</Code> | Update a node. |
| <Code>delete&#95;scenario&#95;node</Code> | Remove a node and its edges. Asks for confirmation. |
| <Code>add&#95;scenario&#95;edge</Code> | Add an edge. |
| <Code>delete&#95;scenario&#95;edge</Code> | Remove an edge. Asks for confirmation. |

## Workflows

Ask your assistant to pull your agent workflow from the provider, edit its nodes and edges, and push it back. Pushing makes the workflow live, so the assistant asks you first.

| Tool | Description |
|---|---|
| <Code>sync&#95;agent&#95;workflow</Code> | Pull the latest workflow from the provider. Asks for confirmation. |
| <Code>push&#95;agent&#95;workflow</Code> | Push the stored workflow to the provider. This makes it live. Asks for confirmation. |
| <Code>get&#95;workflow&#95;summary</Code> | Get the workflow graph. |
| <Code>list&#95;workflow&#95;paths</Code> | List the paths through the workflow. |
| <Code>add&#95;workflow&#95;node</Code> | Add a node. |
| <Code>update&#95;workflow&#95;node</Code> | Update a node. |
| <Code>delete&#95;workflow&#95;node</Code> | Remove a node and its edges. |
| <Code>add&#95;workflow&#95;edge</Code> | Add an edge. |
| <Code>delete&#95;workflow&#95;edge</Code> | Remove an edge. |
