## Folders

Ask your assistant to sort your agents into folders.

| Tool | Description |
|---|---|
| <Code>create&#95;folder</Code> | Create a folder. |
| `get_folder` | Get one folder. |
| <Code>list&#95;folders</Code> | List folders. |
| <Code>update&#95;folder</Code> | Update a folder. |
| <Code>delete&#95;folder</Code> | Delete a folder. |
| <Code>move&#95;agent&#95;to&#95;folder</Code> | Move an agent to a folder or to the root. |

## Labels

Ask your assistant to add labels to an agent, or change or delete them.

| Tool | Description |
|---|---|
| <Code>create&#95;agent&#95;label</Code> | Create a label on an agent. |
| <Code>get&#95;agent&#95;label</Code> | Get one label. |
| <Code>list&#95;agent&#95;labels</Code> | List the labels of an agent. |
| <Code>update&#95;agent&#95;label</Code> | Update a label. |
| <Code>delete&#95;agent&#95;label</Code> | Delete a label. |

## Phone numbers

Ask your assistant to buy a phone number, list your numbers, or release a number you no longer need.

| Tool | Description |
|---|---|
| <Code>add&#95;phone&#95;number</Code> | Buy a phone number. |
| <Code>list&#95;phone&#95;numbers</Code> | List phone numbers. |
| <Code>release&#95;phone&#95;number</Code> | Release a phone number. |

## Transcripts

| Tool | Description |
|---|---|
| <Code>translate&#95;transcript</Code> | Translate a transcript. |

## Voice platforms

Ask your assistant to sync your Vapi agents into Bluejay, manage the tools on a Vapi assistant, merge ElevenLabs branches, or work with Bland pathways and knowledge bases.

| Tool | Description |
|---|---|
| <Code>sync&#95;vapi&#95;agents</Code> | Sync all Vapi assistants and squads into Bluejay. Synced agents get the current Vapi name, prompt, and workflow. Asks for confirmation. |
| <Code>create&#95;vapi&#95;squad</Code> | Create a Vapi squad. |
| <Code>list&#95;vapi&#95;tools</Code> | List Vapi tools. |
| <Code>list&#95;vapi&#95;assistant&#95;tools</Code> | List the tools on a Vapi assistant. |
| <Code>add&#95;vapi&#95;assistant&#95;tool</Code> | Add a tool to a Vapi assistant. |
| <Code>remove&#95;vapi&#95;assistant&#95;tool</Code> | Remove a tool from a Vapi assistant. |
| <Code>list&#95;elevenlabs&#95;agents</Code> | List ElevenLabs agents. |
| <Code>list&#95;elevenlabs&#95;branches</Code> | List the branches of an ElevenLabs agent. |
| <Code>merge&#95;elevenlabs&#95;branches</Code> | Merge one ElevenLabs branch into another. Asks for confirmation. |
| <Code>list&#95;bland&#95;pathways</Code> | List Bland pathways. |
| <Code>sync&#95;bland&#95;knowledge&#95;bases</Code> | Pull knowledge bases from Bland again. |
| <Code>get&#95;bland&#95;knowledge&#95;base&#95;changes</Code> | List Bland knowledge bases that changed on a sync. |
