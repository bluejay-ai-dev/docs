## Monitor

Ask your assistant to find production conversations and traces, read a conversation's transcript, tool calls, and errors, or set up alerts and see when they triggered.

| Tool | Description |
|---|---|
| <Code>list&#95;conversations</Code> | Query production conversations. |
| <Code>get&#95;conversation</Code> | Get one conversation with its transcript, tool calls, and errors. |
| `list_traces` | List recent traces. |
| `get_trace` | Get one trace. |
| `get_span` | Get one span. |
| <Code>create&#95;alert</Code> | Create an alert. |
| `list_alerts` | List alerts. |
| <Code>update&#95;alert</Code> | Update an alert. |
| <Code>delete&#95;alert</Code> | Delete an alert. |
| <Code>get&#95;alert&#95;results</Code> | List the recent triggers of an alert. |

## Uptime monitors

Ask your assistant to set up uptime monitors and report a monitor's uptime and latency over time.

| Tool | Description |
|---|---|
| <Code>create&#95;uptime&#95;monitor</Code> | Create an uptime monitor. |
| <Code>get&#95;uptime&#95;monitor</Code> | Get one uptime monitor. |
| <Code>list&#95;uptime&#95;monitors</Code> | List uptime monitors. |
| <Code>update&#95;uptime&#95;monitor</Code> | Update an uptime monitor. |
| <Code>delete&#95;uptime&#95;monitor</Code> | Delete an uptime monitor. |
| <Code>get&#95;uptime&#95;monitor&#95;series</Code> | Get uptime and latency over time for a monitor. |

## Dashboards

Ask your assistant to build a dashboard, add chart widgets to it, and arrange them.

| Tool | Description |
|---|---|
| <Code>create&#95;dashboard</Code> | Create an empty dashboard. |
| <Code>get&#95;dashboard</Code> | Get a dashboard with its widgets and layout. |
| <Code>list&#95;dashboards</Code> | List dashboards. |
| <Code>update&#95;dashboard</Code> | Rename a dashboard or change its description. |
| <Code>update&#95;dashboard&#95;layout</Code> | Set the widget positions on a dashboard. |
| <Code>duplicate&#95;dashboard</Code> | Copy a dashboard and its widgets. |
| <Code>delete&#95;dashboard</Code> | Delete a dashboard and its widgets. You cannot delete a default dashboard. |
| <Code>create&#95;widget</Code> | Create a chart widget on a dashboard. |
| `get_widget` | Get one widget. |
| <Code>list&#95;widgets</Code> | List widgets. |
| <Code>update&#95;widget</Code> | Replace the configuration of a widget. |
| <Code>duplicate&#95;widget</Code> | Copy a widget. |
| <Code>delete&#95;widget</Code> | Delete a widget. |

## Schedules

Ask your assistant to run a simulation on a schedule, or change or delete a schedule.

| Tool | Description |
|---|---|
| <Code>create&#95;schedule</Code> | Create a schedule. |
| <Code>get&#95;schedule</Code> | Get one schedule. |
| <Code>list&#95;schedules</Code> | List schedules. |
| <Code>update&#95;schedule</Code> | Update a schedule. |
| <Code>delete&#95;schedule</Code> | Delete a schedule. |
