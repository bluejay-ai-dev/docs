`BluejayClient(tracing=True)` traces the Anthropic SDK. No extra package. Messages `create` and `stream` are covered.

<CodeGroup>

```python Python icon="/logo/python.svg"
from bluejay import BluejayClient

client = BluejayClient(tracing=True)

reply = anthropic_client.messages.create(model="claude-sonnet-4-5", max_tokens=1024, messages=messages)
```

```typescript TypeScript icon="/logo/typescript.svg"
// In Node.js, use an OpenTelemetry instrumentor or a manual model span.
```

</CodeGroup>

When the call runs inside a [session](/sdk/observability#trace-chat-or-sms), the span joins that call.
