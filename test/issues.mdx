Bluejay groups similar failures in your simulation results into one issue, so you triage one problem in place of many failed calls. Simulations have their own issues list, separate from production.

If you are tracking issues from production calls, see [Issues](/monitor/issues).

## Track an issue

To track the work on an issue, set its status. Supported statuses include:

- **Open**
- **In Progress**
- **Resolved**
- **Ignored**

To order the work across the team, set a priority. A new issue shows **No priority**. Supported priorities include:

- **Low**
- **Medium**
- **High**
- **Urgent**

## Issue types

| Type | Meaning |
|---|---|
| Agent Failure | Bluejay grouped similar failures into one issue. |
| System Error | Bluejay matched a known error, for example a [call error code](/test/simulations/reference#error-codes). |
