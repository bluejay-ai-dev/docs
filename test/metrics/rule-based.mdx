Use a rule-based metric to check a fixed fact of the conversation without writing a prompt. Each of these metrics returns Pass or Fail, and no LLM grades it.

## Tool Call

Passes when the agent called the tools you name. A transcript does not show tool calls, so send them to Bluejay with the conversation, as in [Tool calls, events, and metadata](/test/metrics#tool-calls-events-and-metadata).

## Phrase Match

Checks whether specific words were said in the transcript.

## Transfer Landed

Passes when the Digital Human you choose answers the transfer within a time limit counted from the start of the call. The default is 180 seconds and the maximum is 900.
