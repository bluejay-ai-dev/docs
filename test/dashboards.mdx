To create a dashboard visualizing your simulations, open **Simulations → Dashboards**.

If you are setting up dashboards for real-world calls, see [Dashboards](/monitor/dashboards).

![Simulation dashboard with outcome pass and fail rate, conversation count over time, conversation type, and conversation count by agent widgets](/images/dashboards-simulation.png)

## Build a dashboard

A dashboard holds widgets. Each widget charts one or more metrics, over time or broken down by agent or type.

## Public dashboards

Share a dashboard through a link with people who don't have a Bluejay account, such as a customer or a stakeholder.

<Steps>
  <Step title="Open the dashboard">
    In **Simulations → Dashboards**, select the custom dashboard you want to share.
  </Step>
  <Step title="Create a share link">
    Click **Share**, set up the link, then click **Create share link**.
    - **Share with agents**: the agents whose simulations the link shows.
    - **Visible tabs**: which parts of a conversation, such as the transcript or traces, a viewer can open from a widget.
  </Step>
</Steps>

<Warning>Anyone with the link can open the dashboard unless you protect it with a password.</Warning>

- Viewers see live data, not a snapshot, and can change the time range and filter by the shared agents.
- Viewers can't edit widgets or the layout.
- A link stays active until you delete it. Deleting it stops it working at once.
- You can change a link's agents and visible tabs later, but not its password. To change the password, create a new link.

## Using Bluejay AI

Ask [Bluejay AI](/improve/bluejay-ai) to build or change a dashboard in plain language. It can:

- Create a dashboard and fill it with widgets for the metrics you name, including your custom metrics.
- Change a widget's metrics, chart type, or grouping, or remove it.
- Arrange the widgets on a dashboard.
- Draw a one-off chart in the chat without saving it to a dashboard.

For example:

- "Make a simulation dashboard of pass rate by agent"
- "Add a bar chart of turn count by agent"
- "Chart conversation count by day for the last month"
