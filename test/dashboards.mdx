To create a dashboard visualizing your simulations, open **Simulations → Dashboards**.

If you are setting up dashboards for real-world calls, see [Dashboards](/monitor/dashboards).

![Simulation dashboard with outcome pass and fail rate, conversation count over time, conversation type, and conversation count by agent widgets](/images/dashboards-simulation.png)

## Build a dashboard

A dashboard holds widgets. Each widget charts one or more metrics, over time or broken down by agent or type.

To share a dashboard outside Bluejay, create a share link.

## Build with Bluejay AI

Ask [Bluejay AI](/improve/bluejay-ai) to build a dashboard for you, for example "Make a dashboard of pass rate by agent for the last month". It can also add, change, and remove widgets.
