Use this type when your agent calls businesses that answer with a phone menu, for example "Press 1 for billing".

## Build the flow

In **Scenario Builder**, draw the phone menu and what your agent does at each step. The Digital Human plays this menu, and your agent calls through it.

<img className="block dark:hidden" src="/images/ivr-flow-builder.png" alt="Scenario Builder with an IVR Menu that offers options 1 and 2, an Agent DTMF node for each key, a 10-second Hold, and a Human Agent with an intent and success criteria" />
<img className="hidden dark:block" src="/images/ivr-flow-builder-dark.png" alt="Scenario Builder with an IVR Menu that offers options 1 and 2, an Agent DTMF node for each key, a 10-second Hold, and a Human Agent with an intent and success criteria" />

For a full example, see [Test an Agent That Calls Through a Phone Menu](/cookbook/ivr-phone-menu).

## Run it

<Steps>
  <Step title="Pick the type">
    [Create a simulation](/test/simulations/create#pick-a-type-yourself) and pick **IVR Flow** under **Or pick a type yourself**.
  </Step>
  <Step title="Pick the IVR Flows">
    Each IVR Flow becomes one Digital Human that goes through the whole phone menu in one call.
  </Step>
</Steps>

## Limits

- Outbound voice agents only.
