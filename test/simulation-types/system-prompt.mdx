Use this type to check that your agent follows its own instructions.

## Set it up

<Steps>
  <Step title="Pick the type">
    [Create a simulation](/test/simulations/create#pick-a-type-yourself) and pick **Generate from System Prompt** under **Or pick a type yourself**. Bluejay reads the agent's prompt, so there is nothing to write.
  </Step>
  <Step title="Review the Digital Humans">
    Edit any Digital Human that does not test what you meant.
  </Step>
</Steps>

## How rules are tested

Bluejay finds the rules in the prompt and tests each rule from both sides: one Digital Human that the agent must help, and one that it must push back on.

- **Digital humans** starts at two per rule, which tests every rule. A lower number leaves the last rules of the prompt untested.
- The maximum is 200 for each generate request, so a prompt with more than 100 rules is never fully tested.
- A prompt with no rules that Bluejay can test cannot use this type.
