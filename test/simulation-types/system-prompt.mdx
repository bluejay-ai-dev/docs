Your agent's system prompt is the list of instructions it is given, like "Always confirm the caller's date of birth". This type finds each rule in that prompt and writes tests to check that your agent follows it.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/sim-type-system-prompt.mp4"></video>

## When to use it

- Use this when your prompt has rules that must always hold, like what to never say or what to always ask.
- Use this after you edit the prompt, to check that the old rules still work.
- Use this when you want tests without writing any yourself. Bluejay reads the prompt, so there is nothing to type.

## How it works

1. You pick the type. Bluejay shows the agent's prompt and the tests it wrote, with the quote from the prompt that each test checks.
2. You remove any test you do not want.
3. You add [personas](/test/simulations/personas), or click **Skip personas**.
4. On the **Review** page you check the Digital Humans, then run them.

## How rules are tested

Bluejay finds the rules in the prompt and tests each rule from both sides: one Digital Human that the agent must help, and one that it must push back on.

- **Digital humans** starts at two per rule, which tests every rule. A lower number leaves the last rules of the prompt untested.
- The maximum is 200 for each generate request, so a prompt with more than 100 rules is never fully tested.
- A prompt with no rules that Bluejay can test cannot use this type. If the agent has no prompt, the step offers **Add a system prompt** instead.
