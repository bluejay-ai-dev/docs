---
title: "System Prompt"
description: "Make Digital Humans that test each rule in your agent's system prompt."
icon: list-check
---

Use this type to check that your agent follows its own instructions. Bluejay reads the system prompt, finds the rules your agent must follow, and makes two Digital Humans for each rule: one that the agent must help, and one that it must push back on.

## Set it up

<Steps>
  <Step title="Choose the type">
    [Create a simulation](/test/simulations/create#create-a-simulation) and click the **Generate from System Prompt** card.
  </Step>
  <Step title="Review the rules">
    Bluejay shows the system prompt next to the rules that it found.
  </Step>
  <Step title="Set the number of Digital Humans">
    Bluejay sets **Digital humans** to two for each rule, which tests every rule. You can set a lower number, from 1 to 200, but then some rules are not tested, and Bluejay shows how many.
  </Step>
  <Step title="Generate">
    Click **Save**, then click **Generate Digital Humans**.
  </Step>
</Steps>

## Limits

- If Bluejay finds no rules that it can test in the prompt, you cannot generate Digital Humans with this type.
- Bluejay makes a maximum of 200 Digital Humans, so a prompt with more than 100 rules is not fully tested.
