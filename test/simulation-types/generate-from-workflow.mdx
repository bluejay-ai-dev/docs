Some agents are built as a [workflow](/test/simulations/reference#workflow): a set of steps or sub-agents that hand the call to each other, like a front desk that passes billing questions to a billing agent. This type sends one Digital Human down each path of that workflow, so every branch gets a call.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/sim-type-generate-from-workflow.mp4"></video>

## When to use it

- Use this when your agent is built in a tool that has workflows or handoffs, and you want every path tested.
- Use this after you change the workflow, to make sure no branch broke.
- Use [Scenario Adherence](/test/simulation-types/scenario-adherence) instead when you want to draw the expected flow yourself.

## How it works

1. You bring the agent's workflow into Bluejay once (see [Before you start](#before-you-start)).
2. You pick the type. Bluejay draws the workflow and writes one test for each path. Click **Show full script** on a test to see the steps it takes.
3. You add [personas](/test/simulations/personas), or click **Skip personas**.
4. On the **Review** page you check the Digital Humans, then run them.

## Before you start

Get your agent's workflow into Bluejay in one of these ways:

- Click **Pull** on the **Workflow** tab of Agent Settings. This works for agents on ElevenLabs, Vapi, Retell, Bland, Amelia, Google Dialogflow, and Google CES.
- Import a workflow from a document with [Bluejay AI](/improve/bluejay-ai).

If the agent has no workflow yet, the step shows **Sync your workflow** instead of tests. If you already pulled it, make sure that the workflow has more than one page or sub-agent.
