Use this type when your agent is a [Workflow](/test/simulations/create#workflow) of several agents, for example a root agent that hands off to billing and support agents. Bluejay reads each path through the Workflow and makes Digital Humans that follow it, so every handoff gets a test.

## Before you start

The agent needs a Workflow in Bluejay. Get one in one of these ways:

- Click **Pull** on the **Workflow** tab of Agent Settings. This works for agents on ElevenLabs, Vapi, Retell, and Google Dialogflow.
- Import a Workflow from a document with [Bluejay AI](/improve/bluejay-ai).

## Set it up

<Steps>
  <Step title="Choose the type">
    [Create a simulation](/test/simulations/create#create-a-simulation) and click the **Generate From Workflow** card.
  </Step>
  <Step title="Set the count for each path">
    The list shows each path through the Workflow and its number of steps. Set how many Digital Humans each path gets.
  </Step>
  <Step title="Generate">
    Click **Save**, then click **Generate Digital Humans**.
  </Step>
</Steps>

If the list says **Nothing to generate yet**, pull the Workflow from your provider first. If you already pulled it, make sure that the Workflow has more than one page or sub-agent.
