Use this type when your agent is a [workflow](/test/simulations/reference#workflow) of several agents, for example a root agent that hands off to billing and support agents. Bluejay reads each path through the workflow and makes Digital Humans that follow it, so every handoff gets a test.

## Before you start

First get your agent's workflow into Bluejay, in one of these ways:

- Click **Pull** on the **Workflow** tab of Agent Settings. This works for agents on ElevenLabs, Vapi, Retell, and Google Dialogflow.
- Import a workflow from a document with [Bluejay AI](/improve/bluejay-ai).

## Set it up

<Steps>
  <Step title="Generate from the workflow">
    [Create a simulation](/test/simulations/create#create-a-simulation), click the **Generate From Workflow** card, then click **Save** and **Generate Digital Humans**.
  </Step>
</Steps>

If the list says **Nothing to generate yet**, pull the workflow from your provider first. If you already pulled it, make sure that the workflow has more than one page or sub-agent.
