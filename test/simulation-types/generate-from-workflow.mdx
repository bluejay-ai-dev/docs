Use this type when your agent is a [workflow](/test/simulations/reference#workflow) of several agents, for example a root agent that hands off to billing and support agents.

## Before you start

Get your agent's workflow into Bluejay in one of these ways:

- Click **Pull** on the **Workflow** tab of Agent Settings. This works for agents on ElevenLabs, Vapi, Retell, Bland, Amelia, and Google Dialogflow.
- Import a workflow from a document with [Bluejay AI](/improve/bluejay-ai).

## Set it up

<Steps>
  <Step title="Select the card">
    [Create a simulation](/test/simulations/create#create-a-simulation) and select the **Generate From Workflow** card.

    <img className="block dark:hidden" src="/images/create-simulation-card-generate-from-workflow.png" alt="Generate From Workflow card in the Create Simulation type picker" />
    <img className="hidden dark:block" src="/images/create-simulation-card-generate-from-workflow-dark.png" alt="Generate From Workflow card in the Create Simulation type picker" />
  </Step>
  <Step title="Choose how many Digital Humans each path gets">
    Each path through the workflow starts with one Digital Human, so every handoff gets a test. Raise the number for the paths you want to test more.

    If you see **Nothing to generate yet**, pull the workflow first. If you already pulled it, make sure that the workflow has more than one page or sub-agent.
  </Step>
</Steps>
