![Use Previous Digital Humans card in the Create Simulation type picker](/images/simulation-type-card-previous-digital-humans.png)

Use this type to run the same callers again, for example to compare two agent versions or to check that a fixed failure stays fixed. Bluejay uses the Digital Humans as they are and does not generate new ones.

## Set it up

<Steps>
  <Step title="Pick the Digital Humans">
    [Create a simulation](/test/simulations/create#create-a-simulation) and click the **Use Previous Digital Humans** card. Select single Digital Humans, or a whole Community with **Select entire community**. Then click **Save** and **Generate Digital Humans**.
  </Step>
</Steps>

To keep a set of callers for each agent or flow, save them as a [Community](/test/simulations/digital-humans#communities).
