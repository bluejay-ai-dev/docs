Use this type to run the same callers again, for example to compare two agent versions or to check that a fixed failure stays fixed.

## Set it up

<Steps>
  <Step title="Select the card">
    [Create a simulation](/test/simulations/create#create-a-simulation) and select the **Use Previous Digital Humans** card.

    <img className="block dark:hidden" src="/images/create-simulation-card-previous-digital-humans.png" alt="Use Previous Digital Humans card in the Create Simulation type picker" />
    <img className="hidden dark:block" src="/images/create-simulation-card-previous-digital-humans-dark.png" alt="Use Previous Digital Humans card in the Create Simulation type picker" />
  </Step>
  <Step title="Pick the Digital Humans">
    Select single Digital Humans, or select the checkbox next to a Community to add all its members. Bluejay runs them as they are and does not generate new ones.
  </Step>
</Steps>

To keep a set of callers for each agent or flow, save them as a [Community](/test/simulations/digital-humans#communities).
