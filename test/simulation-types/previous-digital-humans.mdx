This type runs Digital Humans you already have, exactly as they are. Bluejay does not write anything new.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/sim-type-previous-digital-humans.mp4"></video>

## When to use it

- Use this when you changed your agent and want to run the same callers as last time, so you can compare the results.
- Use this to check that a call that failed before now passes.
- Use this to build a new simulation out of the best tests from older ones.

## How it works

1. You search for the Digital Humans you want and tick them. Tick a Community on the right to add all of its members at once.
2. You click **Continue**.
3. On the **Review** page you check the list, then run it.

To keep a set of callers together for each agent or flow, save them as a [Community](/test/simulations/digital-humans#communities).
