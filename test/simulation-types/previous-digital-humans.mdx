---
title: "Use Previous Digital Humans"
description: "Run Digital Humans or Communities you already have, so each test uses the same callers."
icon: users
---

Use this type to run the same callers again, for example to compare two agent versions or to check that a fixed failure stays fixed. Bluejay uses the Digital Humans as they are and does not generate new ones.

## Set it up

<Steps>
  <Step title="Choose the type">
    [Create a simulation](/test/simulations/create#create-a-simulation) and click the **Use Previous Digital Humans** card.
  </Step>
  <Step title="Select the Digital Humans">
    To add a full Community, select **Select entire community** next to it in the **Communities** list. To add single Digital Humans, select them in the list. To find one, use the search box above the list.
  </Step>
  <Step title="Generate">
    Click **Save**, then click **Generate Digital Humans**.
  </Step>
</Steps>

To keep a set of callers for each agent or flow, save them as a [Community](/test/simulations/digital-humans#communities).
