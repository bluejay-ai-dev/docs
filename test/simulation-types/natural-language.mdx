Use this type when you would rather describe your callers than write each Digital Human yourself.

## Set it up

<Steps>
  <Step title="Select the card">
    [Create a simulation](/test/simulations/create#create-a-simulation) and select the **Generate from Natural Language** card.

    <img className="block dark:hidden" src="/images/create-simulation-card-natural-language.png" alt="Generate from Natural Language and Goal Adherence cards in the Create Simulation type picker" />
    <img className="hidden dark:block" src="/images/create-simulation-card-natural-language-dark.png" alt="Generate from Natural Language and Goal Adherence cards in the Create Simulation type picker" />
  </Step>
  <Step title="Describe your callers">
    Write what you want to test, for example "callers who ask for a refund after the 30-day window". You can make 1 to 100 Digital Humans.

    <img className="block dark:hidden" src="/images/create-simulation-natural-language.png" alt="The Generate from Natural Language settings with a prompt describing dental-cleaning callers, the Quick Templates above it, and the number of calls set to 1" />
    <img className="hidden dark:block" src="/images/create-simulation-natural-language-dark.png" alt="The Generate from Natural Language settings with a prompt describing dental-cleaning callers, the Quick Templates above it, and the number of calls set to 1" />
  </Step>
  <Step title="Review the Digital Humans">
    Edit any Digital Human that does not test what you meant.
  </Step>
</Steps>
