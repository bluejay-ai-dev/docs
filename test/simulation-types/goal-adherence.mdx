Use this type to check that your agent does its main jobs. You list the goals, for example "Complete booking" or "Handle refund", and Bluejay makes Digital Humans that each try to reach one of them. It is the type that the dialog selects first.

## Set it up

<Steps>
  <Step title="Choose the type">
    [Create a simulation](/test/simulations/create#create-a-simulation) and click the **Goal Adherence** card.
  </Step>
  <Step title="Add the goals">
    Type a goal in **Add a goal** and click **Add**. To read the goals from the agent's system prompt instead, click **Auto-generate**.
  </Step>
  <Step title="Set the count for each goal">
    In the **Goals** list, select the goals to test and set how many Digital Humans each one gets.
  </Step>
  <Step title="Generate">
    Click **Save**, then click **Generate Digital Humans**.
  </Step>
</Steps>

Bluejay saves the goal list on the agent, so the next simulation for that agent starts with the same goals. To skip a goal in one run without deleting it, clear its checkbox.
