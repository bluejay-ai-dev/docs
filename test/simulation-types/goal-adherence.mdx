Use this type to check that your agent does its main jobs, such as "Complete booking" or "Handle refund".

## Set it up

<Steps>
  <Step title="Select the card">
    [Create a simulation](/test/simulations/create#create-a-simulation) and select the **Goal Adherence** card.

    <img className="block dark:hidden" src="/images/create-simulation-card-natural-language.png" alt="Generate from Natural Language and Goal Adherence cards in the Create Simulation type picker" />
    <img className="hidden dark:block" src="/images/create-simulation-card-natural-language-dark.png" alt="Generate from Natural Language and Goal Adherence cards in the Create Simulation type picker" />
  </Step>
  <Step title="Add the goals">
    Write the goals, or click **Auto-generate** to start from the agent's system prompt.

    - Bluejay saves the goals on the agent, so the next simulation for that agent starts with the same list.
    - To skip a goal in one run without deleting it, clear its checkbox.
  </Step>
  <Step title="Review the Digital Humans">
    Edit any Digital Human that does not test what you meant.
  </Step>
</Steps>
