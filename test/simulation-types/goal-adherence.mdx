A goal is one job your agent must get done on a call, like "Book a cleaning" or "Collect the caller's date of birth". Bluejay makes a Digital Human for each goal and checks whether your agent got it done.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/sim-type-goal-adherence.mp4"></video>

## When to use it

- Use this when you know the main jobs your agent has and want a quick test for each one.
- Use this as your first simulation if you are not sure where to start. **Auto-generate** reads your agent's prompt and writes the goals for you.
- Use [Scenario Adherence](/test/simulation-types/scenario-adherence) instead when the agent must follow exact steps in a fixed order.

## How it works

1. You write the goals, or click **Auto-generate** to get a list from the agent's system prompt.
2. You tick the goals to run. Each ticked goal becomes a Digital Human. Use the number next to a goal to run it more than once.
3. You add [personas](/test/simulations/personas) if you want each goal tried by different kinds of callers, or click **Skip personas**.
4. On the **Review** page you check the Digital Humans, then run them.

Bluejay saves the goals on the agent, so the next simulation for that agent starts with the same list. To leave a goal out of one run, untick it instead of deleting it.
