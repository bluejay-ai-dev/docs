This type takes a real conversation and plays the caller's side back to your agent. Each transcript becomes one Digital Human that calls your agent the same way the real caller did.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/sim-type-replay-from-transcript.mp4"></video>

## When to use it

- Use this when a real call went wrong and you want to check your fix on that same call.
- Use this to keep a set of important calls that must keep working every time you change the agent.
- Use this when you have production calls in Bluejay and want tests that sound like your real callers.

## How it works

1. You bring the transcripts in one of three ways: paste them on **Direct Input**, pick calls on **Production Calls**, or upload a file on **CSV Upload**. Bluejay uses only the tab that is open when you go on.
2. You pick a replay mode, **Smart Replay** or **Strict Replay** (see below).
3. You click **Continue**. Bluejay reads each transcript and writes its success criteria, which can take a little while.
4. On the **Review** page you check the Digital Humans, then run them.

A transcript is one line per turn, starting with who is speaking:

```txt
Agent: Thanks for calling Northwind Dental. How can I help?
Caller: Hi, I'd like to book a cleaning for next Tuesday morning.
```

## Replay modes

| Mode | What the Digital Human says |
|---|---|
| **Smart Replay** | It keeps the same goal as the real caller, and answers what your agent actually says. |
| **Strict Replay** | The exact lines of the transcript, word for word. |

Use **Strict Replay** when your agent must give the same answers as before. If your agent changed what it says, the fixed lines may stop making sense. **Smart Replay** is usually the better choice then.

## CSV columns

The CSV file has a header row and one transcript in each row. The columns are:

- `Transcript`
- `Name`, optional
- `Success Criteria`, optional
- `TC_<tool>`, optional, an expected tool call
- `CT_<trait>`, optional, the value of a [trait](/test/simulations/digital-humans#traits)
