Use this type to test your agent again on conversations that went wrong, or on calls you want to keep working after a change. Each transcript becomes one Digital Human that replays that caller.

## Set it up

<Steps>
  <Step title="Choose the type">
    [Create a simulation](/test/simulations/create#create-a-simulation) and click the **Replay From Transcript** card.
  </Step>
  <Step title="Add the transcripts">
    Pick a source tab:

    - **Direct Input**: paste a transcript, add optional **Success Criteria**, and click **Add New Transcript**. Do this for each transcript.
    - **Production Calls**: select calls from your [Logs](/monitor/logs).
    - **CSV Upload**: upload a CSV file with one transcript in each row.
  </Step>
  <Step title="Generate">
    Choose a [replay mode](#replay-modes), then click **Save** and **Generate Digital Humans**.
  </Step>
</Steps>

## Replay modes

| Mode | What the Digital Human says |
|---|---|
| **Smart Replay** | The transcript lines when they fit the conversation, and new lines when they do not. This is the default. |
| **Strict Replay** | The exact lines of the transcript. |
| **Persona Generation** | New lines, based on the caller and the context of the transcript. |

Use **Strict Replay** when your agent must give the same answers as before. If your agent changed what it says, the fixed lines may stop making sense, so **Smart Replay** is usually the better choice.

## CSV columns

The CSV file has a header row and one transcript in each row. The columns are:

- `Transcript`
- `Name`, optional
- `Success Criteria`, optional
- `TC_<tool>`, optional, an expected tool call
- `CT_<trait>`, optional, the value of a [trait](/test/simulations/digital-humans#traits)
