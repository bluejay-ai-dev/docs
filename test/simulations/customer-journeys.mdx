## Create a journey

1. Open the **Simulations** page, select the agent, and click **Create**.
2. Select **Customer Journeys**.
3. Click **Add step** for each call. For each step, enter the intent, for example "Book appointment".
4. Drag a step to change the order.
5. Set the number of journeys with the stepper. The range is 1 to 200.
6. Generate the Digital Humans.
7. Run the simulation.

![Customer Journeys card on the Create Simulation dialog](/images/journey-card.png)

![Customer Journeys configuration: steps on the left, preview on the right](/images/journey-config-panel.png)

Total calls = journeys × steps. For example, 10 journeys with 3 steps place 30 calls.

If a call does not connect or drops, Bluejay skips the next steps of that journey with the status `STEP_SKIPPED`.

## Results

On the run page, the calls of one journey group into one row. Expand the row to see each step.
