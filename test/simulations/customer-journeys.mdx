In a Customer Journeys simulation, the same Digital Human contacts your agent several times in a fixed order. Use it to test how your agent treats a customer who comes back.

## Build a journey

A journey is an ordered list of steps. Each step is one conversation (a call or a text thread) with its own intent, for example "Book appointment" followed by "Reschedule". To test a customer who comes back later, set a step to wait before it starts. The Digital Human keeps the same identity across the steps, so later calls test how your agent treats a returning customer.

![Customer Journeys card on the Create Simulation dialog](/images/journey-card.png)

![Customer Journeys configuration: steps on the left, preview on the right](/images/journey-config-panel.png)

If a step ends with one of these statuses, Bluejay cancels the later steps of that journey with the code `STEP_SKIPPED`:

- No Connection
- No Answer
- Call Dropped
- Out of Funds
- System Error

## Results

The calls of one journey group into one row on the run page.
