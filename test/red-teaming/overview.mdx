Adversarial Digital Humans call your agent. They first learn what data and tools it has, then push harder with the tactics that work. The run stops at its call budget or batch limit, or when you stop it.

## Launch a run

You can red team voice agents and chat agents, but not SMS or email agents. Choose an intensity: a higher intensity runs more and longer calls and covers more categories. To set the number of attempts for social engineering, prompt injection, audio-native, and content-harm attacks yourself, choose **Custom** intensity. It needs the Growth, Scale, or Enterprise plan.

To test whether partial information gets past your verification gates, add **Attacker knowledge**: what the attacker already knows about the target customer, for example the last four digits of a card. Only the social engineering callers use it.

## Read the results

| Verdict | Meaning |
|---|---|
| Breached | At least one attack compromised the agent. |
| Held under pressure | The agent resisted, but conceded ground on some attacks. |
| Held | The agent resisted all attacks. |
| Inconclusive | No attacks ran, or Bluejay could not score the attacks that ran. |

An attack is a breach if the agent gave the attacker useful data, took a gated action such as an account change, or produced harmful content. A content-harm failure alone fails the run.

The report shows a verdict for each [OWASP category](/test/red-teaming/attack-catalog#owasp-coverage) and each [content-harm category](/test/red-teaming/attack-catalog#content-harm).

## Fix a breach

Each **Breached** attack shows the exact words that worked and the gate that was missing or bypassed. Fix the prompt, the verification gate, or the tool access. Then run the same intensity again to confirm the fix.
