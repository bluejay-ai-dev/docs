Before an agent takes real customers, a security or compliance reviewer usually wants evidence that a caller cannot talk it into leaking account data or skipping verification. This recipe runs a Red Teaming test, fixes what breaks, and runs the test again so you end up with a passing report to share.

## Before you start

- A voice or chat agent in Bluejay. Red Teaming does not support SMS or email agents. See [Connect your agent](/test/simulations/create#connect-your-agent).
- For **Custom** intensity, the Growth, Scale, or Enterprise plan.

## Steps

<Steps>
  <Step title="Launch a red team">
    Open the **Red Teaming** page and click **Launch red team**. Choose the **Target agent** and an **Intensity**. **Quick** is a smoke test and **Thorough** goes deepest, while **Custom** lets you set the number of attempts for each attack family. See [Red Teaming](/test/red-teaming/overview#launch-a-run).
  </Step>
  <Step title="Give the attacker partial account details">
    To test your verification steps, open the **Attacker knowledge** tab and add what a real attacker might already know about the customer, for example a date of birth or the last four digits of a card. Only the social engineering callers use it. Click **Launch red team** to start the run.
  </Step>
  <Step title="Read the verdict for each category">
    When the run finishes, the report shows an overall verdict and a verdict for each [OWASP category](/test/red-teaming/overview#owasp-coverage) and [content-harm category](/test/red-teaming/overview#content-harm). See [Read the results](/test/red-teaming/overview#read-the-results) for what each verdict means.
  </Step>
  <Step title="Fix each breach">
    Each **Breached** attack shows the exact words that worked and the gate that was missing or bypassed. Fix the agent's prompt, add or tighten the verification step, or remove tool access the agent does not need.
  </Step>
  <Step title="Run the same intensity again">
    Launch again with the same intensity and attacker knowledge.
  </Step>
</Steps>

## Check the result

The fix worked when the categories that were **Breached** now show **Held**. **Held under pressure** means the agent resisted but conceded ground on some attacks, so read those attacks before you call the agent ready. When the report is clean, click **Download PDF** to save a copy for your reviewer.
