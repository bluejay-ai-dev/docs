Use this when you have two agents for the same job, for example on two voice platforms or with two different prompts. Both run against the same Digital Humans and custom metrics, so the agent is the only difference between the runs.

## Before you start

- Connect both agents to Bluejay. See [Connect your agent](/test/simulations/create#connect-your-agent).
- Create the [custom metrics](/test/metrics) you want to compare the agents on.

## Steps

<Steps>
  <Step title="Run agent A">
    Open **Simulations** and create a simulation for the first agent with any [simulation type](/test/simulations/create#create-a-simulation). In **Custom Metric Settings**, select the metrics you want to compare. Then click **Create New Run** and wait for the run to finish.
  </Step>
  <Step title="Run agent B on the same Digital Humans">
    Create a second simulation for the other agent and choose the **Use Previous Digital Humans** type. Select the Digital Humans from the first simulation, so that both agents face the same callers. In **Custom Metric Settings**, select the same metrics as in the first simulation. Then click **Create New Run** and wait for the run to finish.
  </Step>
  <Step title="Compare the two runs">
    In each simulation's **Run History**, select the run and click **Compare Runs**. The tray keeps the runs while you move between simulations, so when it holds both, click **Compare**.
  </Step>
</Steps>

## Check the result

Set **Compare by** to one custom metric at a time to see which agent fails which check. A metric with a free-text or JSON result does not appear in **Compare by**, because its results have no value to compare. The tray lives in memory, so a full page reload clears it; select the runs again if that happens.
