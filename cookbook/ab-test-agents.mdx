When you have two agents for the same job, for example on two voice platforms or with two different prompts, you want to know which one serves callers better. This recipe runs both agents against the same Digital Humans and the same custom metrics, so the only difference between the two runs is the agent, and then puts the runs side by side.

## Before you start

- Connect both agents to Bluejay. See [Connect your agent](/test/simulations/create#connect-your-agent).
- Create the [custom metrics](/test/custom-metrics/overview) you want to compare the agents on.

## Steps

<Steps>
  <Step title="Create a simulation for agent A">
    Open **Simulations** and create a simulation for the first agent with any [simulation type](/test/simulations/create#simulation-types). In **Custom Metric Settings**, select the metrics you want to compare.
  </Step>
  <Step title="Run the simulation for agent A">
    Click **Create New Run** to call every Digital Human in the simulation, and wait for the run to finish.
  </Step>
  <Step title="Create a simulation for agent B with the same Digital Humans">
    Create a second simulation for the other agent and choose the **Use Previous Digital Humans** type. Select the Digital Humans from the first simulation, so that both agents face the same callers. In **Custom Metric Settings**, select the same metrics as in the first simulation. A metric that only one simulation scores has no result to compare against in the other run.
  </Step>
  <Step title="Run the simulation for agent B">
    Click **Create New Run** in the second simulation and wait for the run to finish.
  </Step>
  <Step title="Compare the two runs">
    In the **Run History** tab of each simulation, select the run and click **Compare Runs**. The selected runs collect in a tray at the bottom of the page, and the tray keeps them while you move between simulations. When the tray holds both runs, click **Compare** to open **Compare Runs Across Agents**.
  </Step>
</Steps>

## Check the result

The comparison shows one card for each run with its pass rate and its count of passed and failed calls. Use **Compare by** to switch from the overall outcome to one custom metric, so you can see which agent fails which check. A metric with a free-text or JSON result does not appear in **Compare by**, because its results have no value to compare. The tray lives in memory, so a full page reload clears it; select the runs again if that happens.
