## Connect a channel

Connect each channel you want once, then turn it on for the alerts that should use it. Slack connects once for the whole organization. PagerDuty and Better Stack keys are saved per [workspace](/administration/workspaces#what-a-workspace-holds), so add them in each workspace whose alerts should page your team.

<Tabs>
<Tab title="Slack">
1. In Bluejay, connect Slack on the **Slack** tab of the Integrations settings.
2. Approve the permissions in Slack.

Each alert then picks its own Slack channel.

![Slack tab of the Integrations settings showing Slack connected to Bluejay, with a Disconnect button](/images/integrations-slack-connect.png)
</Tab>
<Tab title="PagerDuty">
1. In PagerDuty, open the service that receives Bluejay incidents.
2. Under **Integrations**, add an **Events API V2** integration and copy its **Integration Key**.
3. In Bluejay, paste the key into **Routing Key** on the **PagerDuty** tab of the Integrations settings.

![PagerDuty tab of the Integrations settings with a Routing Key field holding a sample key](/images/integrations-pagerduty.png)
</Tab>
<Tab title="Better Stack">
1. In Better Stack, open **API tokens**, then **Team-based tokens**.
2. Select the team whose on-call rotation receives Bluejay incidents.
3. Under **Uptime API tokens**, create a token and copy it.
4. In Bluejay, paste the token into **API token** on the **Better Stack** tab of the Integrations settings. Bluejay checks the token with Better Stack when you save it.

![Better Stack tab of the Integrations settings with a saved, masked API token](/images/integrations-better-stack.png)
</Tab>
<Tab title="Email">
Email needs no connection.

![Notify section of the Create Alert dialog with Email Notifications on and the Recipients menu open, showing All Team Members and Specific People](/images/alert-notify-email.png)
</Tab>
</Tabs>

To send alerts to your own endpoint, or to start an automated flow when an alert fires, subscribe a [webhook](/api-reference/webhooks#events) to the alert events.
