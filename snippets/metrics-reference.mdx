### Tool call fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | The tool name. |
| <Code>start_offset_ms</Code> | integer | Yes | Milliseconds from the start of the conversation. |
| `description` | string | No | What the tool does. |
| `parameters` | object | No | The input to the tool. |
| `output` | any | No | The value the tool returned. |

### Event fields

An event marks a moment in the conversation, for example an escalation or a hold.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | Yes | The event name. |
| <Code>start_offset_ms</Code> | integer | Yes | Milliseconds from the start of the conversation. |
| <Code>end_offset_ms</Code> | integer | No | When the event ended. |
| `description` | string | No | Details of the event. |
| `tags` | string[] | No | Tags for the event. |
| `metadata` | object | No | Extra data for the event. |
