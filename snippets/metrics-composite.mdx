Use a composite metric to roll several metrics into one score or label. For example, combine a clarity score and a Pass/Fail check into one Scheduling Quality score.

A composite metric reads results that the other metrics already produced, so it makes no LLM call. It can read only metrics that always run, so a conditional metric cannot be one of its inputs.

## Create a composite metric

<Steps>
  <Step title="Open the form">
    On the **Metrics** page, click **Create**, then **Create manually**, and set **Type** to **Composite**.
  </Step>
  <Step title="Add the metrics">
    Under **Metrics**, click **Add metric** for each metric to combine. A formula needs numbers, so for a Yes/No or Pass/Fail metric, set the number that each result counts as, for example 1 for yes and 0 for no.
  </Step>
  <Step title="Set the output">
    Set **Output** to one of these:

    - **Numerical**: write a formula over the metrics. Start typing a metric name and pick it from the list. **Min value** and **Max value** cap the result.
    - **Categorical**: add an option for each label, with the conditions that select it. Bluejay uses the first option whose conditions match. If none match, the result is not applicable.
