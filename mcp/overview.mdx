The Bluejay MCP server gives an AI assistant tools to manage agents, Digital Humans, simulations, metrics, and monitoring in your Bluejay organization.

## Connect

The endpoint is `https://api.getbluejay.ai/mcp`. It uses the Streamable HTTP transport in stateless mode.

To get an API key, open **Settings**, then **API Keys**, and click **Create API Key**. Copy the key. Send it in the `X-API-Key` header. `Authorization: Bearer <api_key>` also works.

<Tabs>
<Tab title="Claude Code">

```bash
claude mcp add --transport http bluejay https://api.getbluejay.ai/mcp \
  --header "X-API-Key: <your_api_key>"
```

</Tab>
<Tab title="Claude Desktop">
Add this to `claude_desktop_config.json`, then restart Claude Desktop. The `mcp-remote` package connects the local client to the remote server.

```json
{
  "mcpServers": {
    "bluejay": {
      "command": "npx",
      "args": ["mcp-remote", "https://api.getbluejay.ai/mcp", "--header", "X-API-Key:<your_api_key>"]
    }
  }
}
```

</Tab>
<Tab title="Cursor">
Add this to `~/.cursor/mcp.json` or `.cursor/mcp.json` in your project.

```json
{
  "mcpServers": {
    "bluejay": {
      "url": "https://api.getbluejay.ai/mcp",
      "headers": { "X-API-Key": "<your_api_key>" }
    }
  }
}
```

</Tab>
<Tab title="Windsurf">
Add this to `~/.codeium/windsurf/mcp_config.json`.

```json
{
  "mcpServers": {
    "bluejay": {
      "serverUrl": "https://api.getbluejay.ai/mcp",
      "headers": { "X-API-Key": "<your_api_key>" }
    }
  }
}
```

</Tab>
<Tab title="Other clients">
Add a remote MCP server with URL `https://api.getbluejay.ai/mcp` and header `X-API-Key: <your_api_key>`.
</Tab>
</Tabs>

If authentication fails, the server returns `{ "error": "Unauthorized", "detail": "<reason>" }`.

| Status | Meaning |
|---|---|
| `401` | The credential is missing, not valid, expired, or revoked. |
| `403` | The user has no organization. |

## Test

Ask your assistant: "List my agents." The assistant calls `list_agents` and shows the agents in your organization. For a longer task, ask: "Create a simulation called Regression Test for Support Bot, generate 5 Digital Humans, and run it."
