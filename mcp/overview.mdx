For example, Claude Code or Cursor creates simulations, runs them, and reads the results for you. To add the server to your client, see [Connect a client](/mcp/connect).

## Test the connection

Ask your assistant: "List my agents." The assistant calls `list_agents` and shows the agents in your organization.

## Confirm before a change

Some tools change your agent at the provider, start long runs, or delete graph parts. These tools first return a preview with `needs_confirmation`. The assistant must show you the preview and call the tool again with `confirmed=true` only after you approve. The tool tables mark these tools.
