For example, Claude Code or Cursor creates simulations, runs them, and reads the results for you.

## Server URL

The endpoint is `https://api.getbluejay.ai/mcp`.

## Authentication

Create an API key in Settings → API Keys. Send it in the `X-API-Key` header. `Authorization: Bearer <api_key>` also works. The server reads your organization from the API key.

## Test the connection

Ask your assistant: "List my agents." The assistant calls `list_agents` and shows the agents in your organization.
