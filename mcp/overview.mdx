The Bluejay MCP server lets an AI assistant such as Claude Code or Cursor work in Bluejay for you. You ask in plain language, and the assistant creates simulations, runs them, and reads the results. To add the server to your client, see [Connect a client](/mcp/connect).

## Test the connection

To check that the connection works, ask your assistant: "List my agents." The assistant calls `list_agents` and shows the agents in your organization.

## Confirm before a change

Some tools change your agent at the provider, start long runs, or delete parts of a graph. So that none of this happens without your approval, these tools first return a preview with `needs_confirmation`. The assistant must show you the preview, and call the tool again with `confirmed=true` only after you approve. In the tool tables, these tools say "Asks for confirmation."
