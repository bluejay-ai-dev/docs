The tools cover folders, labels, phone numbers, and voice platforms.

## Folders

| Tool | Description |
|---|---|
| `create_folder` | Create a folder. |
| `get_folder` | Get one folder. |
| `list_folders` | List folders. |
| `update_folder` | Update a folder. |
| `delete_folder` | Delete a folder. |
| `move_agent_to_folder` | Move an agent to a folder or to the root. |

## Labels

| Tool | Description |
|---|---|
| `create_label` | Create a label on an agent. |
| `get_label` | Get one label. |
| `list_labels` | List the labels of an agent. |
| `update_label` | Update a label. |
| `delete_label` | Delete a label. |

## Other

| Tool | Description |
|---|---|
| `add_phone_number` | Buy a phone number. |
| `list_phone_numbers` | List phone numbers. |
| `release_phone_number` | Release a phone number. |
| `translate_transcript` | Translate a transcript. |

## Voice platforms

| Tool | Description |
|---|---|
| `sync_vapi_agents` | Sync Vapi assistants and squads into Bluejay. |
| `create_vapi_squad` | Create a Vapi squad. |
| `list_vapi_tools` | List Vapi tools. |
| `list_vapi_assistant_tools` | List the tools on a Vapi assistant. |
| `add_vapi_assistant_tool` | Add a tool to a Vapi assistant. |
| `remove_vapi_assistant_tool` | Remove a tool from a Vapi assistant. |
| `list_elevenlabs_agents` | List ElevenLabs agents. |
| `list_elevenlabs_branches` | List the branches of an ElevenLabs agent. |
| `merge_elevenlabs_branches` | Merge one ElevenLabs branch into another. |
| `list_bland_pathways` | List Bland pathways. |
| `sync_bland_knowledge_bases` | Pull knowledge bases from Bland again. |
| `get_bland_knowledge_base_changes` | List Bland knowledge bases that changed on a sync. |
