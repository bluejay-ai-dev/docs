## Folders

Ask your assistant to sort your agents into folders.

| Tool | Description |
|---|---|
| <Code>create_folder</Code> | Create a folder. |
| `get_folder` | Get one folder. |
| <Code>list_folders</Code> | List folders. |
| <Code>update_folder</Code> | Update a folder. |
| <Code>delete_folder</Code> | Delete a folder. |
| <Code>move_agent_to_folder</Code> | Move an agent to a folder or to the root. |

## Labels

Ask your assistant to add labels to an agent, or change or delete them.

| Tool | Description |
|---|---|
| <Code>create_label</Code> | Create a label on an agent. |
| `get_label` | Get one label. |
| `list_labels` | List the labels of an agent. |
| <Code>update_label</Code> | Update a label. |
| <Code>delete_label</Code> | Delete a label. |

## Phone numbers

Ask your assistant to buy a phone number, list your numbers, or release a number you no longer need.

| Tool | Description |
|---|---|
| <Code>add_phone_number</Code> | Buy a phone number. |
| <Code>list_phone_numbers</Code> | List phone numbers. |
| <Code>release_phone_number</Code> | Release a phone number. |

## Transcripts

| Tool | Description |
|---|---|
| <Code>translate_transcript</Code> | Translate a transcript. |

## Voice platforms

Ask your assistant to sync your Vapi agents into Bluejay, manage the tools on a Vapi assistant, merge ElevenLabs branches, or work with Bland pathways and knowledge bases.

| Tool | Description |
|---|---|
| <Code>sync_vapi_agents</Code> | Sync all Vapi assistants and squads into Bluejay. Synced agents get the current Vapi name, prompt, and workflow. Asks for confirmation. |
| <Code>create_vapi_squad</Code> | Create a Vapi squad. |
| <Code>list_vapi_tools</Code> | List Vapi tools. |
| <Code>list_vapi_assistant_tools</Code> | List the tools on a Vapi assistant. |
| <Code>add_vapi_assistant_tool</Code> | Add a tool to a Vapi assistant. |
| <Code>remove_vapi_assistant_tool</Code> | Remove a tool from a Vapi assistant. |
| <Code>list_elevenlabs_agents</Code> | List ElevenLabs agents. |
| <Code>list_elevenlabs_branches</Code> | List the branches of an ElevenLabs agent. |
| <Code>merge_elevenlabs_branches</Code> | Merge one ElevenLabs branch into another. Asks for confirmation. |
| <Code>list_bland_pathways</Code> | List Bland pathways. |
| <Code>sync_bland_knowledge_bases</Code> | Pull knowledge bases from Bland again. |
| <Code>get_bland_knowledge_base_changes</Code> | List Bland knowledge bases that changed on a sync. |
