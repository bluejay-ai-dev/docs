## Monitor

| Tool | Description |
|---|---|
| `list_conversations` | Query production conversations. |
| `get_conversation` | Get one conversation with its transcript, tool calls, and errors. |
| `list_traces` | List recent traces. |
| `get_trace` | Get one trace. |
| `get_span` | Get one span. |
| `create_alert` | Create an alert. |
| `list_alerts` | List alerts. |
| `update_alert` | Update an alert. |
| `delete_alert` | Delete an alert. |
| `get_alert_results` | List the recent triggers of an alert. |

## Uptime monitors

| Tool | Description |
|---|---|
| `create_uptime_monitor` | Create an uptime monitor. |
| `get_uptime_monitor` | Get one uptime monitor. |
| `list_uptime_monitors` | List uptime monitors. |
| `update_uptime_monitor` | Update an uptime monitor. |
| `delete_uptime_monitor` | Delete an uptime monitor. |
| `get_uptime_monitor_series` | Get uptime and latency over time for a monitor. |

## Dashboards

| Tool | Description |
|---|---|
| `create_dashboard` | Create an empty dashboard. |
| `get_dashboard` | Get a dashboard with its widgets and layout. |
| `list_dashboards` | List dashboards. |
| `update_dashboard` | Rename a dashboard or change its description. |
| `update_dashboard_layout` | Set the widget positions on a dashboard. |
| `duplicate_dashboard` | Copy a dashboard and its widgets. |
| `delete_dashboard` | Delete a dashboard and its widgets. You cannot delete a default dashboard. |
| `create_widget` | Create a chart widget on a dashboard. |
| `get_widget` | Get one widget. |
| `list_widgets` | List widgets. |
| `update_widget` | Replace the configuration of a widget. |
| `duplicate_widget` | Copy a widget. |
| `delete_widget` | Delete a widget. |

## Schedules
