## Monitor

Ask your assistant to find production conversations and traces, read a conversation's transcript, tool calls, and errors, or set up alerts and see when they triggered.

| Tool | Description |
|---|---|
| <Code>list_conversations</Code> | Query production conversations. |
| <Code>get_conversation</Code> | Get one conversation with its transcript, tool calls, and errors. |
| `list_traces` | List recent traces. |
| `get_trace` | Get one trace. |
| `get_span` | Get one span. |
| <Code>create_alert</Code> | Create an alert. |
| `list_alerts` | List alerts. |
| <Code>update_alert</Code> | Update an alert. |
| <Code>delete_alert</Code> | Delete an alert. |
| <Code>get_alert_results</Code> | List the recent triggers of an alert. |

## Uptime monitors

Ask your assistant to set up uptime monitors and report a monitor's uptime and latency over time.

| Tool | Description |
|---|---|
| <Code>create_uptime_monitor</Code> | Create an uptime monitor. |
| <Code>get_uptime_monitor</Code> | Get one uptime monitor. |
| <Code>list_uptime_monitors</Code> | List uptime monitors. |
| <Code>update_uptime_monitor</Code> | Update an uptime monitor. |
| <Code>delete_uptime_monitor</Code> | Delete an uptime monitor. |
| <Code>get_uptime_monitor_series</Code> | Get uptime and latency over time for a monitor. |

## Dashboards

Ask your assistant to build a dashboard, add chart widgets to it, and arrange them.

| Tool | Description |
|---|---|
| <Code>create_dashboard</Code> | Create an empty dashboard. |
| <Code>get_dashboard</Code> | Get a dashboard with its widgets and layout. |
| <Code>list_dashboards</Code> | List dashboards. |
| <Code>update_dashboard</Code> | Rename a dashboard or change its description. |
| <Code>update_dashboard_layout</Code> | Set the widget positions on a dashboard. |
| <Code>duplicate_dashboard</Code> | Copy a dashboard and its widgets. |
| <Code>delete_dashboard</Code> | Delete a dashboard and its widgets. You cannot delete a default dashboard. |
| <Code>create_widget</Code> | Create a chart widget on a dashboard. |
| `get_widget` | Get one widget. |
| <Code>list_widgets</Code> | List widgets. |
| <Code>update_widget</Code> | Replace the configuration of a widget. |
| <Code>duplicate_widget</Code> | Copy a widget. |
| <Code>delete_widget</Code> | Delete a widget. |

## Schedules

Ask your assistant to run a simulation on a schedule, or change or delete a schedule.

| Tool | Description |
|---|---|
| <Code>create_schedule</Code> | Create a schedule. |
| <Code>get_schedule</Code> | Get one schedule. |
| <Code>list_schedules</Code> | List schedules. |
| <Code>update_schedule</Code> | Update a schedule. |
| <Code>delete_schedule</Code> | Delete a schedule. |
