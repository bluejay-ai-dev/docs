---
title: "Connect a client to the Bluejay MCP server"
description: "Connect Claude Code, Claude Desktop, Cursor, or Windsurf to the Bluejay MCP server with your API key."
sidebarTitle: "Connect a client"
icon: "plug"
---

Add the Bluejay MCP server to your client with one of these configurations. Replace `<your_api_key>` with your Bluejay API key.

<Tabs>
<Tab title="Claude Code">

```bash
claude mcp add --transport http bluejay https://api.getbluejay.ai/mcp \
  --header "X-API-Key: <your_api_key>"
```

</Tab>
<Tab title="Claude Desktop">
Add this to `claude_desktop_config.json`, then restart Claude Desktop. The `mcp-remote` package connects the local client to the remote server.

```json
{
  "mcpServers": {
    "bluejay": {
      "command": "npx",
      "args": ["mcp-remote", "https://api.getbluejay.ai/mcp", "--header", "X-API-Key:<your_api_key>"]
    }
  }
}
```

</Tab>
<Tab title="Cursor">
Add this to `~/.cursor/mcp.json` or `.cursor/mcp.json` in your project.

```json
{
  "mcpServers": {
    "bluejay": {
      "url": "https://api.getbluejay.ai/mcp",
      "headers": { "X-API-Key": "<your_api_key>" }
    }
  }
}
```

</Tab>
<Tab title="Windsurf">
Add this to `~/.codeium/windsurf/mcp_config.json`.

```json
{
  "mcpServers": {
    "bluejay": {
      "serverUrl": "https://api.getbluejay.ai/mcp",
      "headers": { "X-API-Key": "<your_api_key>" }
    }
  }
}
```

</Tab>
<Tab title="Other clients">
Add a remote MCP server with URL `https://api.getbluejay.ai/mcp` and header `X-API-Key: <your_api_key>`.
</Tab>
</Tabs>
