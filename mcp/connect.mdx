## Supported clients

- Claude Code
- Claude Desktop
- Cursor
- Windsurf
- Any other client that can add a remote MCP server

## Get an API key

Your client signs in to Bluejay with an API key. To create one, see [Make your first request](/api-reference/introduction#make-your-first-request). The key's [scope](/administration/workspaces#api-keys) decides which workspaces your assistant can work in.

## Add the server to your client

Pick your client below. Replace `<your_api_key>` with your API key.

<Tabs>
<Tab title="Claude Code">

```bash
claude mcp add --transport http bluejay https://api.getbluejay.ai/mcp \
  --header "X-API-Key: <your_api_key>"
```

</Tab>
<Tab title="Claude Desktop">
Add this to `claude_desktop_config.json`, then restart Claude Desktop.

```json
{
  "mcpServers": {
    "bluejay": {
      "command": "npx",
      "args": ["mcp-remote", "https://api.getbluejay.ai/mcp", "--header", "X-API-Key:<your_api_key>"]
    }
  }
}
```

</Tab>
<Tab title="Cursor">
Add this to `~/.cursor/mcp.json` or `.cursor/mcp.json` in your project.

```json
{
  "mcpServers": {
    "bluejay": {
      "url": "https://api.getbluejay.ai/mcp",
      "headers": { "X-API-Key": "<your_api_key>" }
    }
  }
}
```

</Tab>
<Tab title="Windsurf">
Add this to `~/.codeium/windsurf/mcp_config.json`.

```json
{
  "mcpServers": {
    "bluejay": {
      "serverUrl": "https://api.getbluejay.ai/mcp",
      "headers": { "X-API-Key": "<your_api_key>" }
    }
  }
}
```

</Tab>
<Tab title="Other clients">
Add a remote MCP server with these values:

- URL: `https://api.getbluejay.ai/mcp`
- Header: `X-API-Key: <your_api_key>`

If your client cannot set a custom header, send `Authorization: Bearer <your_api_key>` instead.
</Tab>
</Tabs>
