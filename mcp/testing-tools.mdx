## Agents

Ask your assistant to add the agents you test, look them up, change them, or delete them.

| Tool | Description |
|---|---|
| `add_agent` | Create an agent. |
| `get_agent` | Get one agent. |
| `list_agents` | List agents. |
| `update_agent` | Update an agent. |
| `delete_agent` | Delete an agent. |

## Agent versions

Ask your assistant to save a new version of your agent, find an earlier version, or label a version.

| Tool | Description |
|---|---|
| `create_prompt_version` | Create an agent version. |
| `get_prompt_version` | Get an agent version by version number. |
| `get_prompt` | Get an agent version by ID. |
| `list_prompt_versions` | List agent versions. |
| `list_prompts` | List agent versions, with an optional label filter. |
| `delete_prompt_version` | Delete an agent version by version number. |
| `delete_prompt` | Delete an agent version by ID. |
| `add_prompt_version_labels` | Add labels to an agent version. |
| `get_prompt_version_labels` | Get the labels on an agent version. |
| `delete_prompt_version_labels` | Remove labels from an agent version. |

## Digital Humans

Ask your assistant to write or generate Digital Humans, add them to simulations, and check how a Digital Human did in past calls. It can also manage your background noises and communities.

| Tool | Description |
|---|---|
| `create_digital_humans` | Create one or more Digital Humans. |
| `generate_digital_humans` | Generate Digital Humans with AI. |
| `get_digital_human` | Get one Digital Human. |
| `list_digital_humans` | List Digital Humans. |
| `update_digital_humans` | Update one or more Digital Humans. |
| `delete_digital_human` | Delete a Digital Human. |
| `duplicate_digital_human` | Copy a Digital Human. |
| `bulk_set_digital_human_simulations` | Set the simulations of up to 100 Digital Humans. |
| `get_digital_human_run_history` | List all calls of one Digital Human. |
| `get_voice_options` | List the valid languages, accents, and genders. |
| `create_custom_background_noise_upload_url` | Get a signed URL to upload a background noise file. |
| `create_custom_background_noise` | Add an uploaded noise to the library. |
| `list_custom_background_noises` | List the background noise library. |
| `create_community` | Create a community. |
| `get_community` | Get one community. |
| `list_communities` | List communities. |
| `update_community` | Update a community. |
| `delete_community` | Delete a community. |

## Simulations

Ask your assistant to set up a simulation, run it, and read the results and transcripts. In an HTTP Webhook conversation, it can also send the agent's messages.

| Tool | Description |
|---|---|
| `create_simulation` | Create a simulation. |
| `get_simulation` | Get one simulation. |
| `list_simulations` | List simulations. |
| `update_simulation` | Update a simulation. |
| `delete_simulation` | Delete a simulation. |
| `queue_simulation_run` | Run a simulation. |
| `queue_email_simulation_run` | Run an email simulation. |
| `get_simulation_runs` | List the runs of a simulation. |
| `get_simulation_results` | Get one page of the results of a run. |
| `get_simulation_result` | Get one result. |
| `get_simulation_transcript` | Get the transcript of one simulation conversation. |
| `send_http_text_message` | Send an agent message in an HTTP Webhook conversation. |
| `end_conversations` | End running conversations. |

## Metrics

Ask your assistant to write custom metrics, start one from a metric library template, or send a call or chat for evaluation.

| Tool | Description |
|---|---|
| `create_custom_metrics` | Create one or more custom metrics. |
| `get_custom_metric` | Get one custom metric. |
| `list_custom_metrics` | List custom metrics. |
| `update_custom_metric` | Update a custom metric. |
| `delete_custom_metrics` | Delete one or more custom metrics. |
| `list_custom_metric_templates` | List metric library templates. |
| `get_custom_metric_template` | Get one metric library template. |
| `evaluate` | Send a call or chat for evaluation. |

## Labs

Ask your assistant to set up a Metrics Lab for a custom metric, add conversations and metrics to it, and test new revisions of the metric.

| Tool | Description |
|---|---|
| `create_lab` | Create a Metrics Lab for one custom metric. |
| `get_lab_detail` | Get the full state of a lab. |
| `list_labs` | List labs. |
| `update_lab` | Rename a lab or change its description. |
| `delete_lab` | Delete a lab. |
| `add_conversations_to_lab` | Add conversations to a lab. |
| `add_metrics_to_lab` | Add metrics to a lab. |
| `create_metric_revision` | Create a metric revision in a lab. |
| `evaluate_conversation` | Evaluate one conversation. |

## Red team

Ask your assistant to start a red team simulation against an agent, follow its progress, and read the report.

| Tool | Description |
|---|---|
| `start_red_team_simulation` | Start a red team simulation against one agent. Asks for confirmation. |
| `get_red_team_simulation` | Get the status, Digital Human tree, and report. |
| `list_red_team_simulations` | List red team simulations. |
| `stop_red_team_simulation` | Stop a red team simulation. |

## Self-Improve

Ask your assistant to start a Self-Improve run for an agent and follow its pass rates.

| Tool | Description |
|---|---|
| `start_self_improve_run` | Start a Self-Improve run for one agent. Asks for confirmation. |
| `get_self_improve_run` | Get the status, pass rates, and history of a run. |
| `list_self_improve_runs` | List Self-Improve runs. |
| `stop_self_improve_run` | Stop a Self-Improve run. |

## Scenarios

Ask your assistant to build or change a Scenario Builder graph one node or edge at a time, and to check a graph before saving it. The tool names say workflow because the API calls each scenario graph a workflow.

| Tool | Description |
|---|---|
| `create_workflow` | Create a scenario. |
| `get_workflow` | Get one scenario. |
| `list_workflows` | List scenarios. |
| `update_workflow` | Update a scenario. |
| `duplicate_workflow` | Copy a scenario. |
| `delete_workflow` | Delete a scenario. |
| `validate_workflow_definition` | Check a scenario graph without saving it. |
| `list_scenario_nodes` | List the nodes and edges of a scenario. |
| `create_scenario_node` | Add a node. |
| `update_scenario_node` | Update a node. |
| `delete_scenario_node` | Remove a node and its edges. Asks for confirmation. |
| `add_scenario_edge` | Add an edge. |
| `delete_scenario_edge` | Remove an edge. Asks for confirmation. |

## Workflows

Ask your assistant to pull your agent workflow from the provider, edit its nodes and edges, and push it back. Pushing makes the workflow live, so the assistant asks you first.

| Tool | Description |
|---|---|
| `sync_agent_workflow` | Pull the latest workflow from the provider. Asks for confirmation. |
| `push_agent_workflow` | Push the stored workflow to the provider. This makes it live. Asks for confirmation. |
| `get_workflow_summary` | Get the workflow graph. |
| `list_workflow_paths` | List the paths through the workflow. |
| `add_workflow_node` | Add a node. |
| `update_workflow_node` | Update a node. |
| `delete_workflow_node` | Remove a node and its edges. |
| `add_workflow_edge` | Add an edge. |
| `delete_workflow_edge` | Remove an edge. |
