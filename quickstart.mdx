A simulation tests your agent before real customers reach it. Bluejay sends Digital Humans to call or message your agent, then scores each conversation with custom metrics, so you can see where the agent fails. In this guide you connect your agent, run a simulation, and read the results.

To follow along, you need a Bluejay account at [app.getbluejay.ai](https://app.getbluejay.ai). If you do not have one, [book a demo](https://cal.com/rohanv/15min).

## Connect your agent

Bluejay needs to know how to reach your agent before it can test it. To add the agent, click **+** in the sidebar header. Pick the mode and connection type that match how your customers reach the agent, so the test conversations take the same path as real ones. [Modes and connections](/key-concepts/agents/overview#modes-and-connections) lists the types, and each integration page lists the fields to fill in. If the connection shows **Save & Sync**, Bluejay imports your agents from the platform.

## Run a simulation

A simulation holds the Digital Humans that test your agent. Create a simulation with the **Generate from Natural Language** type, then describe the callers and goals you want to test, and Bluejay generates the Digital Humans from your description. Review them before you start the run, because each Digital Human places a conversation.

## Read the results

When the run finishes, the run page shows each conversation with its result and custom metric results. Open the failed conversations first, because they show what to fix. A scored conversation looks like this:

<Transcript
  turns={[
    { role: "agent", t: "00:01", text: "Thanks for calling Northside Dental. How can I help?" },
    { role: "human", t: "00:04", text: "I need to move my cleaning from Tuesday to Thursday." },
    { role: "agent", t: "00:09", text: "I can do that. Thursday at 10 AM or 2 PM?" },
    { role: "human", t: "00:13", text: "2 PM, please." },
    { role: "agent", t: "00:16", text: "Done. Your cleaning is now Thursday at 2 PM." }
  ]}
  verdict={{ metric: "Appointment Rescheduled", pass: true, reason: "Agent moved the appointment and confirmed the new time." }}
/>

To learn what each status and error code means, see [Simulation Results](/test/simulations/simulation-results).
