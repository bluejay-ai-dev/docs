The Bluejay REST API takes and returns JSON. For a list of all endpoints, see the [cheat sheet](/api-reference/cheat-sheet).

## Base URL

```bash
https://api.getbluejay.ai
```

All endpoint paths start with `/v1`.

## Authentication

Send your API key in the `X-API-Key` header of each request.

```bash
curl https://api.getbluejay.ai/v1/all-agents \
  -H "X-API-Key: YOUR_API_KEY"
```

1. Sign in to [Bluejay](https://app.getbluejay.ai).
2. Open the [API Keys page](https://app.getbluejay.ai/settings/api-keys).
3. Create a key.

An API key belongs to one workspace. Requests with that key read and write only in that workspace. The key ignores the `X-Organization-Id` header.

## Errors

Errors return an HTTP status code and a JSON body with `detail`.

```json
{ "detail": "Agent not found" }
```

| Status | Meaning |
|---|---|
| 400 | The request is not valid for the current state, for example a delete that a rule blocks. |
| 401 | The API key is missing, not valid, or revoked. |
| 402 | The organization needs a payment method. `code` is `NO_PAYMENT_METHOD` or `RED_TEAMING_PAYMENT_METHOD_REQUIRED`. |
| 403 | The resource is not in your organization or workspace. `code` is `INSUFFICIENT_CREDITS` or `SPEND_ALERT_REACHED` when billing blocks the request. |
| 404 | The resource does not exist. |
| 409 | The request conflicts with current data, for example a duplicate. |
| 422 | A field failed validation. `detail` is a list of items with `loc`, `msg`, and `type`. |
| 429 | The rate limit is exceeded. The body is `{"error": "Rate limit exceeded: ..."}`. |
| 503 | Authentication is not available for a short time. Send the request again. |

Billing errors put `code` next to `detail`:

```json
{ "detail": "...", "code": "INSUFFICIENT_CREDITS" }
```

## Pagination

List endpoints use one of three styles. Each endpoint page shows its parameters, defaults, and maximum values.

| Style | Parameters | Example endpoints |
|---|---|---|
| Page | `page` (starts at 1) and `page_size` | [Get All Digital Humans](/api-reference/endpoint/get-all-digital-humans), [List Conversations](/api-reference/endpoint/list-conversations) |
| Offset | `limit` and `offset` | [List Issues](/api-reference/endpoint/list-issues), [Retrieve Simulation Results](/api-reference/endpoint/retrieve-simulation-results) |
| Limit | `limit` only | [List Traces](/api-reference/endpoint/list-traces), [List Agent Versions](/api-reference/endpoint/list-prompt-versions) |

Other list endpoints return all rows in one response.

## Rate limits

Most endpoints allow 100 requests per minute for each client IP address. An endpoint with a different limit shows it at the end of its page.

[Evaluate](/api-reference/endpoint/evaluate) counts requests for each organization. It allows 100 requests per minute, or 500 for enterprise accounts.

A request over the limit returns 429. Wait until the next minute, then send the request again.
