### Simulations

| Method | Path | Description |
|---|---|---|

| <Method>GET</Method> | [`/v1/get-all-simulations`](/api-reference/endpoint/get-all-simulations) | Returns all simulations in your organization, for all agents. |
| <Method>GET</Method> | [`/v1/get-simulations-by-agent/{agent_id}`](/api-reference/endpoint/get-simulations-by-agent) | Returns the simulations for one agent. |
| <Method>DELETE</Method> | [`/v1/simulation/{simulation_id}`](/api-reference/endpoint/delete-simulation) | Deletes a simulation by `simulation_id`. |
| <Method>POST</Method> | [`/v1/queue-http-text-simulation-run`](/api-reference/endpoint/queue-http-text-simulation-run) | Starts a text run for an HTTP agent and returns `simulation_run_id` and `simulation_result_ids`. |
