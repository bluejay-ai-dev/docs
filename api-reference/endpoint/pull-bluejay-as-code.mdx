Exports a bundle with these lists:

- `agents`
- `simulations`
- `digital_humans`
- `custom_metrics`

Each item has a `bluejay_as_code_id`.

Supported values for `root_type` include:

- `simulation`
- `agent`
- `digital-human`
- `custom-metric`

`root_id` is the Bluejay ID or the `bluejay_as_code_id` of the root.

Commit the `bluejay_as_code_id` values to your config. Do not create new values for each push.

To get YAML, add the query parameter `format=yaml` or send the header `Accept: application/yaml`. Without either, the response is JSON.

```bash
curl "https://api.getbluejay.ai/v1/bluejay-as-code/simulation/$SIM_ID?format=yaml" \
  --header "X-API-Key: $BLUEJAY_API_KEY" \
  --output simulation.yaml
```
