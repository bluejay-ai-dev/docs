## Delete Agent Version: DELETE /v1/agents/{agent_id}/versions/{version}

> **What this endpoint does:** delete a specific prompt version; cannot delete production; cannot delete only version. if deleting latest, reassign latest to highest remaining version. returns metadata about the deletion.

**Endpoint:** DELETE `https://api.getbluejay.ai/v1/agents/{agent_id}/versions/{version}`
**Auth:** `X-API-Key` header

import requests

def delete_agent_version(agent_id: int, version: int, api_key: str) -> dict:

Deletes one agent version.

- You cannot delete the version with the `production` label. Move the label first.
- You cannot delete the only version.
- If you delete the `latest` version, the label moves to the highest remaining version.

`DELETE /v1/agents/{agent_id}/prompts/versions/{version}` is the deprecated path of this endpoint.
