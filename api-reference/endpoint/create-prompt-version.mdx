````
## Create Agent Version — POST /v1/agents/{agent_id}/versions

> **What this endpoint does:** create a new agent version under /agents/{agent_id}/versions.

**Endpoint:** POST `https://api.getbluejay.ai/v1/agents/{agent_id}/versions`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| agent_id | integer |  |
| X-API-Key | string | API key required to authenticate requests. |

`prompt_text` is optional. Omit it to copy the current prompt (the agent's latest version) and increment the version. Send `""` to store a blank prompt.

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/create-prompt-version and include any optional parameters (e.g., `prompt_text`, `commit_message`, `labels`, `override_label`, `metadata`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.

### Request Body
```json
{
  "prompt_text": "You are a helpful assistant."
}
```

Refer to the full schema at https://docs.getbluejay.ai/api-reference/endpoint/create-prompt-version. Include optional fields that serve the goal of setting up for testing and monitoring on Bluejay.

### Example
**POST with body:**
```python
import requests

def create_prompt_version(agent_id: int, payload: dict, api_key: str) -> dict:
    url = f"https://api.getbluejay.ai/v1/agents/{agent_id}/versions"
    headers = {"X-API-Key": api_key}
    response = requests.post(url, headers=headers, json=payload)
    response.raise_for_status()
    return response.json()
````
