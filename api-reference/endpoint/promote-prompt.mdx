## Promote Agent Version — POST /v1/agents/{agent_id}/versions/promote

> **What this endpoint does:** move the production label to the latest agent version, or to the version identified by the `version` query parameter. `prompt_id` (the version uuid) is a deprecated alias and is ignored when `version` is set.

**Endpoint:** POST `https://api.getbluejay.ai/v1/agents/{agent_id}/versions/promote`
**Auth:** `X-API-Key` header

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| agent_id | integer |  |
| X-API-Key | string | API key required to authenticate requests. |

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/promote-prompt and include any optional parameters (e.g., `version`, or the deprecated `prompt_id`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.

### Example
**POST (optional `version` query):**
```python
import requests

def promote_version(agent_id: int, api_key: str, version=None) -> dict:
    url = f"https://api.getbluejay.ai/v1/agents/{agent_id}/versions/promote"
    headers = {"X-API-Key": api_key}
    params = {"version": version} if version is not None else None
    response = requests.post(url, headers=headers, params=params)
    response.raise_for_status()
    return response.json()
```
