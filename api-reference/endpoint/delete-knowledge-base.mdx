````
## Delete Knowledge Base — DELETE /v1/knowledge-base/{knowledge_base_id}

> **What this endpoint does:** Delete a knowledge base and all of its documents.

**Endpoint:** DELETE `https://api.getbluejay.ai/v1/knowledge-base/{knowledge_base_id}`
**Auth:** `X-API-Key` header

### Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| knowledge_base_id | string (uuid) | **Required.** The knowledge base to delete. |

### Example
```python
import requests

def delete_knowledge_base(kb_id: str, api_key: str) -> None:
    r = requests.delete(f"https://api.getbluejay.ai/v1/knowledge-base/{kb_id}", headers={"X-API-Key": api_key})
    r.raise_for_status()
````
