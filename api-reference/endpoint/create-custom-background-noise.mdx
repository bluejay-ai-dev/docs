Adds an uploaded file to the background noise library. Get `storage_path` from [Create Background Noise Upload URL](/api-reference/endpoint/create-custom-background-noise-upload-url).

- An organization can have 20 custom background noises. The 21st returns 400.
- The same file twice returns 409.

Rate limit: 30 requests per minute.
