Queues an SMS run of a simulation.

- If `terminate_overlapping_simulations` is `true`, Bluejay ends running conversations that use the same pair of phone numbers.
- `runs_per_digital_human` overrides the simulation setting for this run. The default is 1.
- `prompt_id` is deprecated. Use `agent_version_id`. If you send both and they differ, the response is 400.
