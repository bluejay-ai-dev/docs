## Get Uptime Series: GET /v1/uptime/monitors/{monitor_id}/series

> **What this endpoint does:** Per-bucket outcome counts, uptime % and response-latency p50/p90/p95/p99 over the last `days`. Forwards to the dashboard's series route, which owns the one query behind both this endpoint and the chart. That route authenticates the caller's Supabase token, so an API-key caller has no identity to forward and is rejected here.

**Endpoint:** GET `https://api.getbluejay.ai/v1/uptime/monitors/{monitor_id}/series`
**Auth:** `X-API-Key` header

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| monitor_id | string |  |

### Example
**Simple GET:**
```python
import requests

def get_uptime_series(monitor_id: str, api_key: str) -> dict:
    url = f"https://api.getbluejay.ai/v1/uptime/monitors/{monitor_id}/series"
    headers = {"X-API-Key": api_key}
    response = requests.get(url, headers=headers)
    response.raise_for_status()
    return response.json()
```
