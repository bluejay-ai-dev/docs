## Get Dashboard: GET /v1/dashboards/{dashboard_id}

> **What this endpoint does:** Get a dashboard with its widgets (including each widget's metrics and layout), ordered by layout position.

**Endpoint:** GET `https://api.getbluejay.ai/v1/dashboards/{dashboard_id}`
**Auth:** `X-API-Key` header

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| dashboard_id | string |  |
| X-API-Key | string | API key required to authenticate requests. |

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/get-dashboard and include any optional parameters (e.g., `X-Organization-Id`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.

### Example
**Simple GET:**
```python
import requests

def get_dashboard(dashboard_id: str, api_key: str) -> dict:
    url = f"https://api.getbluejay.ai/v1/dashboards/{dashboard_id}"
    headers = {"X-API-Key": api_key}
    response = requests.get(url, headers=headers)
    response.raise_for_status()
    return response.json()
```
