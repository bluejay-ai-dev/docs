<Note>
  SCIM endpoints authenticate with a SCIM token from **Settings → Security → User provisioning (SCIM)**, sent as `Authorization: Bearer <token>`. A Bluejay API key does not work here. Identity providers like Okta and Entra call these for you; see [SSO and User Provisioning](/administration/sso-and-provisioning).
</Note>
