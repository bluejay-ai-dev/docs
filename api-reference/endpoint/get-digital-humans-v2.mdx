Returns the Digital Humans in your organization, newest first. `page_size` is 20 by default and 100 at most. Read `total_pages` to know when to stop.

- Repeat `digital_human_id` to read specific Digital Humans. An unknown ID returns an empty list. Repeat `simulation_id` to read the Digital Humans linked to specific simulations. An unknown or unreadable `simulation_id` returns 404.
- A Digital Human must match every filter you send, including `type` and `tags`, and any one of the values within a filter.
- Each item lists the `simulation_ids` it belongs to.
- `digital_human_id` and `simulation_id` take up to 100 values each.

`?simulation_id=` replaces [`/v1/digital-humans-by-simulation`](/api-reference/endpoint/get-digital-humans-by-simulation). It returns `total_count` and paged results, newest first.
