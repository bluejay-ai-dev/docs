## Create Alert: POST /v1/create-alert

> **What this endpoint does:** Create a new alert with optional agent associations

**Endpoint:** POST `https://api.getbluejay.ai/v1/create-alert`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

Creates an alert. `source_scope` selects the data: `observability`, `simulation`, or `all`.

- For `observability`, `threshold_time_interval` is a window in seconds. The default is 600. `min_events` defaults to 10.
- For `simulation`, `threshold_time_interval` is the number of recent completed runs. The default is 1. `min_events` is not used.
- `sample_size` evaluates the last N conversations instead of a time window. The minimum is 30. The alert does not fire with fewer than N conversations.
