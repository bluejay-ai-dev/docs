````
## List Amelia Agents: GET /v1/integrations/amelia/agents

> **What this endpoint does:** Cognitive agent names in one domain, for the picker on the Amelia connection form. `status` is the latest revision's, and is reported only so the form can show it: on a live tenant almost every agent reads UNDEPLOYED while still serving traffic, so it must not be used to filter the list.

**Endpoint:** GET `https://api.getbluejay.ai/v1/integrations/amelia/agents`
**Auth:** `X-API-Key` header

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| domain_code | string | Amelia domain code the agent points at |
| X-API-Key | string | API key required to authenticate requests. |

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/list-amelia-agents and include any optional parameters (e.g., `base_url`, `X-Organization-Id`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.

### Example
**Simple GET:**
```python
import requests

def list_amelia_agents(api_key: str) -> dict:
    url = "https://api.getbluejay.ai/v1/integrations/amelia/agents"
    headers = {"X-API-Key": api_key}
    response = requests.get(url, headers=headers)
    response.raise_for_status()
    return response.json()
````
