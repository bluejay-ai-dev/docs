**Auth:** `X-API-Key` header

### Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |

### Example
```python
import requests

def list_knowledge_bases(api_key: str) -> list:
    r = requests.get("https://api.getbluejay.ai/v1/knowledge-base", headers={"X-API-Key": api_key})
    r.raise_for_status()
    return r.json()
```
