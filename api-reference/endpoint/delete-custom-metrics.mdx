````
## Bulk Delete Custom Metrics: POST /v1/delete-metrics

> **What this endpoint does:** Delete multiple custom metrics by ID. All IDs must exist and belong to the caller's organization (same rules as single delete).

**Endpoint:** POST `https://api.getbluejay.ai/v1/delete-metrics`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| custom_metric_ids | array[string] | UUIDs of custom metrics to delete |

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/delete-custom-metrics and include any optional parameters (e.g., `X-Organization-Id`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.

**POST with body:**
```python

def bulk_delete_custom_metrics(payload: dict, api_key: str) -> dict:
````
