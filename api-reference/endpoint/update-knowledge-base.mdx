## Update Knowledge Base — PUT /v1/knowledge-base/{knowledge_base_id}

> **What this endpoint does:** Rename or re-describe a knowledge base.

**Endpoint:** PUT `https://api.getbluejay.ai/v1/knowledge-base/{knowledge_base_id}`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| knowledge_base_id | string (uuid) | **Required.** The knowledge base to update. |
| name | string | New name. |
| description | string | New description. |

### Request Body
```json
{
  "name": "Support FAQs (v2)",
  "description": "Updated grounding content"
}
```

### Example
```python
import requests

def update_knowledge_base(kb_id: str, payload: dict, api_key: str) -> dict:
    r = requests.put(f"https://api.getbluejay.ai/v1/knowledge-base/{kb_id}", headers={"X-API-Key": api_key}, json=payload)
    r.raise_for_status()
    return r.json()
```

### Constraints
- Minimal changes — only add/change files needed for this integration.
- Match existing codebase patterns (naming, file structure, error handling).
- Handle 404 (not found / not in your organization) and 422 (validation error).
