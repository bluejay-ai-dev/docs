Retrieves the call log for a specific call identified by `call_id`. The response includes evaluations, hallucinations, redundancy, custom evaluation metrics, and `credits_used`.

`credits_used` is the credits burned by this call. It is `null` until usage has landed and can be priced.

## Path

`GET /v1/retrieve-call-log/{call_id}`

| Name | In | Type | Required | Description |
|------|----|------|----------|-------------|
| call_id | path | string | yes | ID of the call |
| X-API-Key | header | string | yes | API key |
| X-Organization-Id | header | string | no | Organization to scope the request |

## Response

```json
{
  "call_log": {},
  "credits_used": 0.018,
  "status": "200"
}
```

| Field | Type | Description |
|-------|------|-------------|
| call_log | object | The call, including evaluations |
| credits_used | number or null | Credits burned by this call. Null until usage has landed and can be priced. |
| status | string | `"200"` on success |
