<Warning>
  This endpoint is deprecated. Use [List Agent Versions](/api-reference/endpoint/list-prompt-versions) with `label`.
</Warning>

Returns one version by `label`.

- No `label` returns 400.
- A label with no version returns 404.
- A label on more than one version returns 400. `latest` is always on one version.
