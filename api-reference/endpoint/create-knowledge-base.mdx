## Create Knowledge Base — POST /v1/knowledge-base

> **What this endpoint does:** Create a knowledge base for your organization.

**Endpoint:** POST `https://api.getbluejay.ai/v1/knowledge-base`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| name | string | **Required.** Name of the knowledge base. |
| description | string | Optional description. |

### Request Body
```json
{
  "name": "Support FAQs",
  "description": "Grounding content for the support agent"
}
```

### Example
```python
import requests

def create_knowledge_base(payload: dict, api_key: str) -> dict:
    r = requests.post("https://api.getbluejay.ai/v1/knowledge-base", headers={"X-API-Key": api_key}, json=payload)
    r.raise_for_status()
    return r.json()
```

- Handle 404 (not found / not in your organization) and 422 (validation error).
