## Get Lab: GET /v1/metrics-lab/lab/{lab_id}

> **What this endpoint does:** Get a lab's full state: conversations, metrics, AI annotations, human labels, and metric revisions with their AI evaluations. This is the read side of the iterate loop: poll it after queueing evaluations to observe results (each evaluation carries a ``status`` of QUEUED/EVALUATING/COMPLETED/…) and to compare a revision's results against the base metric and human labels.

**Endpoint:** GET `https://api.getbluejay.ai/v1/metrics-lab/lab/{lab_id}`
**Auth:** `X-API-Key` header

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| lab_id | string |  |

### Example
**Simple GET:**
```python
import requests

def get_lab(lab_id: str, api_key: str) -> dict:
    url = f"https://api.getbluejay.ai/v1/metrics-lab/lab/{lab_id}"
    headers = {"X-API-Key": api_key}
    response = requests.get(url, headers=headers)
    response.raise_for_status()
    return response.json()
```
