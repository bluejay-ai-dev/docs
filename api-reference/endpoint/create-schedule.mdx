Creates a schedule for a simulation. The response returns the schedule as `cron_expression`.

`schedule.frequency` selects the shape of `schedule`: every N minutes, every N hours, daily, weekly, monthly, or cron. `timezone` is an IANA name. If it is null, the schedule uses UTC.
