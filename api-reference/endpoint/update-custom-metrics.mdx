## Bulk Update Custom Metrics: PUT /v1/update-metrics

> **What this endpoint does:** Bulk update custom metrics: apply the same patch to each metric in metric_ids. Only keys present in updates are applied; each key's value (including null) is written.

**Endpoint:** PUT `https://api.getbluejay.ai/v1/update-metrics`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| metric_ids | array[string] | UUIDs of custom metrics to update |
| updates | object | Patch payload; only keys that are present are applied; each value (including null) is written. |

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/update-custom-metrics and include any optional parameters (e.g., `X-Organization-Id`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.
