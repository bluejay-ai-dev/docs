## Duplicate Widget: POST /v1/widgets/{widget_id}/duplicate

> **What this endpoint does:** Duplicate a widget ('Copy of <name>') with its metrics onto a dashboard, which may be a different one from the source's.

**Endpoint:** POST `https://api.getbluejay.ai/v1/widgets/{widget_id}/duplicate`
**Auth:** `X-API-Key` header
