Returns `upload_url` and `storage_path`.

1. Send the file bytes to `upload_url` with HTTP PUT.
2. Send `storage_path` to [Create Custom Background Noise](/api-reference/endpoint/create-custom-background-noise).

The file name must end in `.mp3` or `.wav`. Other types return 400.

Rate limit: 30 requests per minute.
