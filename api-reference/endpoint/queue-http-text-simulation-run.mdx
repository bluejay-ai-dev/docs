## Queue HTTP Text Simulation Run: POST /v1/queue-http-text-simulation-run

> **What this endpoint does:** Queue a new simulation run and test results for HTTP text agent. Takes simulation_id, optional prompt_id, knowledge_base_id, and digital_human_ids. If digital_human_ids is not provided, uses all digital humans for the simulation. Returns simulation_run_id (experiment_run_id) and simulation_result_ids (array of test result IDs).

**Endpoint:** POST `https://api.getbluejay.ai/v1/queue-http-text-simulation-run`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

Starts a text run for an HTTP agent and returns `simulation_run_id` and `simulation_result_ids`.

1. Queue the run with this endpoint.
2. Receive each Digital Human message at the webhook in the agent settings.
3. Send each agent reply with [Send HTTP Text Message](/api-reference/endpoint/send-http-text-message).

If you omit `digital_human_ids`, all Digital Humans in the simulation run. `knowledge_base_id` is ignored. `prompt_id` is deprecated. Use `agent_version_id`.
