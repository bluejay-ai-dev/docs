## Set Simulation Personalities: PUT /v1/simulations/{simulation_id}/personalities

> **What this endpoint does:** Replace the selection. Each run then queues one conversation per digital human per selected personality; an empty selection is one conversation per digital human.

**Endpoint:** PUT `https://api.getbluejay.ai/v1/simulations/{simulation_id}/personalities`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| simulation_id | integer |  |
