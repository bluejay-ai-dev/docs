Creates one or many custom metrics. `metrics` takes one metric object or a list of them, and the response is always a list. `summary` is the short description shown with a metric. Link a metric to agents with `agent_ids`.

```json
{ "metrics": { "name": "Greeting", "prompt": "Did the agent greet the caller?", "response_type": "pass_fail" } }
```
