Creates one or many Digital Humans. `digital_humans` takes one Digital Human object or a list of them, and the response is always a list. Items that fail validation return per-item errors in `errors`. The other items are created.

```json
{ "digital_humans": { "test_name": "Booking caller", "intent": "Book a table for two" } }
```

The `tag` value and playback fields change which fields are required. The `errors` list names the field that failed. `success_criteria` is one string with a bullet per line.

Pass `persona_ids` to have a Digital Human run once as each of those [personas](/test/simulations/personas). Without them it runs once as the baseline.

If you omit `allow_silence_tool` and `silence_tool_instructions`, they are `false` and `"default"`.

Rate limit: 20 requests per minute.
