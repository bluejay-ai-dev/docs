## Create Widget: POST /v1/widgets

> **What this endpoint does:** Create a widget with its metrics on a dashboard. A widget belongs to exactly one dashboard.

**Endpoint:** POST `https://api.getbluejay.ai/v1/widgets`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| name | string |  |
| chart_type | string (enum: line, bar, pie, table, kpi, pivot_table, histogram) |  |
| dashboard_id | string | Dashboard the widget belongs to; a widget lives on exactly one dashboard |

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/create-widget and include any optional parameters (e.g., `X-Organization-Id`, `description`, `chart_mode`, `data_type`, `bar_mode`, `aggregation`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.
