## Unresolve Check: POST /v1/uptime/monitors/{monitor_id}/checks/{check_id}/unresolve

> **What this endpoint does:** Reopen a resolved incident (undo a mistaken resolve): the check counts as an incident again.

**Endpoint:** POST `https://api.getbluejay.ai/v1/uptime/monitors/{monitor_id}/checks/{check_id}/unresolve`
**Auth:** `X-API-Key` header
