## Get Knowledge Base — GET /v1/knowledge-base/{knowledge_base_id}

> **What this endpoint does:** Fetch a knowledge base with its documents and ingestion status.

**Endpoint:** GET `https://api.getbluejay.ai/v1/knowledge-base/{knowledge_base_id}`
**Auth:** `X-API-Key` header

### Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| knowledge_base_id | string (uuid) | **Required.** The knowledge base to fetch. |

### Example
```python
import requests

def get_knowledge_base(kb_id: str, api_key: str) -> dict:
    r = requests.get(f"https://api.getbluejay.ai/v1/knowledge-base/{kb_id}", headers={"X-API-Key": api_key})
    r.raise_for_status()
    return r.json()
```
