## List Conversations: GET /v1/observability/conversations

> **What this endpoint does:** Query production conversations for this organization. Omit `group_by` for rows, newest first, each with `metric_results`. Set it for counts per group: by status, agent, label, day, interface, direction, ended_by, a `metadata_path`, or `metric_value` for how a metric came out. Filters apply either way, so one narrowing answers both "show me" and "how many".

**Endpoint:** GET `https://api.getbluejay.ai/v1/observability/conversations`
**Auth:** `X-API-Key` header

`page_size` is 20 by default and 100 at most.
