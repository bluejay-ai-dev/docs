Returns the simulations in your organization, newest first, with their `settings`.

- Repeat `simulation_id` to read specific simulations. Repeat `agent_id` to read the simulations of specific agents.
- `simulation_id` and `agent_id` take up to 100 values each.
- A simulation must match every filter you send, and any one of the values within a filter.
- If nothing matches, the response is 200 with an empty list.
