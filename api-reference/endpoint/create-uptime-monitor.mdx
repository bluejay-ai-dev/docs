Creates an uptime monitor and the simulation and schedule that run it. `active_window` limits the days and hours. If it is null, the monitor runs at all times.

## Checks

Each item in `checks` is one health check that a run grades:

```json
{
  "id": "latency",
  "label": "Latency",
  "enabled": true,
  "isTemplate": true,
  "checkType": "latency",
  "config": { "latency_threshold_ms": 3000, "alert_after_failures": 3 }
}
```

- A template check has `isTemplate: true` and a `checkType` of `connection`, `agent_malfunction`, or `latency`.
- A custom check has `isTemplate: false` and a `customMetricId` with a `condition` of `data_type`, `operator`, and `comparison_value`.
- A `digitalHumanId` check changes the caller to that Digital Human. See [Custom caller](/monitor/uptime/overview#custom-caller).

At least one enabled check must have a `checkType` or a `customMetricId`. If not, the response is 400.
