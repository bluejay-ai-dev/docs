## Add Agent: POST /v1/add-agent

> **What this endpoint does:** Add a new agent to the system.

**Endpoint:** POST `https://api.getbluejay.ai/v1/add-agent`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| name | string | Name of the agent |
| system_prompt | string | System prompt for the agent |
| goals | array[string] | List of goals for the agent |

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/add-agent and include any optional parameters (e.g., `X-Organization-Id`, `bluejay_as_code_id`, `phone_number`, `type`, `connection_type`, `mode`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.
