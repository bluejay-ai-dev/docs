Generates Digital Humans for an agent and links them to the simulation. To generate from a graph, see [Create Scenario](/api-reference/endpoint/create-scenario).

This request does not accept `allow_silence_tool` or `silence_tool_instructions`. To set them, use [Update Digital Human](/api-reference/endpoint/update-digital-human).
