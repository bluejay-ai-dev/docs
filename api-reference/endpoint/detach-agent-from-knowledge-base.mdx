## Detach Agent from Knowledge Base — DELETE /v1/knowledge-base/{knowledge_base_id}/agents/{agent_id}

> **What this endpoint does:** Remove an agent's access to a knowledge base.

**Endpoint:** DELETE `https://api.getbluejay.ai/v1/knowledge-base/{knowledge_base_id}/agents/{agent_id}`
**Auth:** `X-API-Key` header

### Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| knowledge_base_id | string (uuid) | **Required.** The knowledge base. |
| agent_id | integer | **Required.** The agent to detach. |

### Example
```python
import requests

def detach_agent(kb_id: str, agent_id: int, api_key: str) -> None:
    r = requests.delete(f"https://api.getbluejay.ai/v1/knowledge-base/{kb_id}/agents/{agent_id}", headers={"X-API-Key": api_key})
    r.raise_for_status()
```
