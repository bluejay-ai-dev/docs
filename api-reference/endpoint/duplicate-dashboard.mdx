````
## Duplicate Dashboard: POST /v1/dashboards/{dashboard_id}/duplicate

> **What this endpoint does:** Duplicate a dashboard: new dashboard named '<name> (Copy)' with its own copy of every widget, laid out the same way.

**Endpoint:** POST `https://api.getbluejay.ai/v1/dashboards/{dashboard_id}/duplicate`
**Auth:** `X-API-Key` header

### Required Parameters

```python
import requests
````
