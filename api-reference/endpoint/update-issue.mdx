Updates an issue. A field you do not send does not change. A field you send as `null` is cleared.

- `status`: `open`, `in_progress`, `resolved`, or `ignored`.
- `priority`: `low`, `medium`, `high`, or `urgent`. It is empty until someone sets it.
- `assignee_id`: a user in your organization.
- `due_date`: `YYYY-MM-DD`.

Bluejay writes the title and the attached calls. You cannot edit them. `PUT /v1/issues/{issue_id}` is the deprecated path of this endpoint.
