````
## Delete Personality: DELETE /v1/personalities/{personality_id}

> **What this endpoint does:** Removes it from the library and from every simulation selecting it. Past runs keep their results: a conversation records the personality it ran as by id.

**Endpoint:** DELETE `https://api.getbluejay.ai/v1/personalities/{personality_id}`
**Auth:** `X-API-Key` header

### Example
**DELETE request:**
```python
import requests

def delete_personality(personality_id: str, api_key: str) -> dict:
    url = f"https://api.getbluejay.ai/v1/personalities/{personality_id}"
    headers = {"X-API-Key": api_key}
    response = requests.delete(url, headers=headers)
    response.raise_for_status()
    return response.json()
````
