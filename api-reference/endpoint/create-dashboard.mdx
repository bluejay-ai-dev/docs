## Create Dashboard: POST /v1/dashboards

> **What this endpoint does:** Create an empty dashboard. Add widgets with POST /v1/widgets, passing this dashboard's id.

**Endpoint:** POST `https://api.getbluejay.ai/v1/dashboards`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| name | string | Dashboard name |

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/create-dashboard and include any optional parameters (e.g., `X-Organization-Id`, `description`, `data_type`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.

### Request Body (required fields)
```json
{
  "name": "example_name"
}
```

Refer to the full schema at https://docs.getbluejay.ai/api-reference/endpoint/create-dashboard. Include optional fields that serve the goal of setting up for testing and monitoring on Bluejay.

### Example
**POST with body:**
```python
import requests

def create_dashboard(payload: dict, api_key: str) -> dict:
    url = "https://api.getbluejay.ai/v1/dashboards"
    headers = {"X-API-Key": api_key}
    response = requests.post(url, headers=headers, json=payload)
    response.raise_for_status()
    return response.json()
```
