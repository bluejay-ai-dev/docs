## Start Self-Improve Run: POST /v1/self-improve/runs

> **What this endpoint does:** Start a self-improve run. Confirm-gated: call once to preview, then again with confirmed=true.

**Endpoint:** POST `https://api.getbluejay.ai/v1/self-improve/runs`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| agent_id | integer | VAPI agent to self-improve in place (prompt iterated; one new 'latest' version written at the end). |
| simulation_id | integer | Simulation (digital humans + metrics) to run each round against the agent. |

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/start-self-improve-run and include any optional parameters (e.g., `X-Organization-Id`, `target_pass_rate`, `max_iterations`, `min_improvement`, `metric_count`, `success_metric_ids`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.

### Request Body (required fields)

Starts a loop that changes the agent prompt, pushes it to the provider, and runs the simulation to score it. At the end, Bluejay saves the best prompt as one new `latest` version. The previous version stays. The `production` label does not move.

## Confirm the run

1. Send the request without `confirmed`. The response has `needs_confirmation: true` and a `preview` text. Nothing runs.
2. Send the same request with `confirmed: true`. The response has `run_id`.

## Limits

- The agent must be a Vapi, ElevenLabs, or Retell agent with a provider ID. Other agents return 400.
- `max_iterations` is 5 by default and 20 at most.
- `metric_count` is 5 by default and 20 at most.
- One agent can have one active run. A second run returns 409.

Rate limit: 30 requests per minute.
