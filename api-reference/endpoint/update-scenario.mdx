## Update Scenario: PUT /v1/scenario/{workflow_id}

> **What this endpoint does:** Update name, description, agent links, and/or definition (React Flow graph).

**Endpoint:** PUT `https://api.getbluejay.ai/v1/scenario/{workflow_id}`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

Updates a scenario. Fields you do not send do not change.

- `agent_ids` replaces all agent links. `[]` removes all links.
- `definition` replaces the full graph. Bluejay validates it the same as [Create Scenario](/api-reference/endpoint/create-scenario).
