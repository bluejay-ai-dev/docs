## Bulk Create Digital Humans: POST /v1/create-digital-humans

> **What this endpoint does:** Bulk create digital humans. All database operations are batched to O(1) round-trips regardless of input size. Items that fail validation are reported in `errors`; the rest proceed to creation.

**Endpoint:** POST `https://api.getbluejay.ai/v1/create-digital-humans`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters

| X-API-Key | string | API key required to authenticate requests. |
| digital_humans | array[object] | list of digital humans to create (min 1, max 100) |

Creates many Digital Humans in one request. Each item in `digital_humans` takes the same fields as [Create Digital Human](/api-reference/endpoint/create-digital-human). Items that fail validation return per-item errors. The other items are created.

If you omit them, `allow_silence_tool` is `false` and `silence_tool_instructions` is `"default"`.

Rate limit: 20 requests per minute.
