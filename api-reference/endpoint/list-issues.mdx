An issue is a problem that Bluejay finds across your calls. A single failure that does not repeat is not an issue.

- `non_deterministic` (Pattern in the dashboard): Bluejay groups similar failures. It shows when the same problem occurs again across calls.
- `deterministic` (Error in the dashboard): an error that Bluejay recognizes at once, such as a tool call that returns 500.

Results are newest first by last seen. `limit` is 50 by default and 200 at most. Use `offset` for the next page.

`GET /v1/issues` is the deprecated path of this endpoint.
