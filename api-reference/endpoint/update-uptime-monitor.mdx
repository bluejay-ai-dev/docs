Updates an uptime monitor. Only the fields you send change.

- `checks` replaces the full list. Send every check you want to keep. For the shapes, see [Create Uptime Monitor](/api-reference/endpoint/create-uptime-monitor).
- A change to `checks` or `agent_id` rebuilds the simulation of the monitor. Notification, pause, and resume changes do not.
