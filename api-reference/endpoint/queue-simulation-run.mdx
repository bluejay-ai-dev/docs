Queues a run of a simulation and returns the run ID. The calls run after the response. Poll [Retrieve Simulation Results](/api-reference/endpoint/retrieve-simulation-results) for results.

- Send `simulation_id`, or the `bluejay_as_code_id` of the simulation.
- If you omit `digital_human_ids`, all Digital Humans in the simulation run.
- `phone_number`, `sip_uri`, and the provider agent IDs override the agent values for this run only.
- `prompt_id` is deprecated. Use `agent_version_id`. If you send both and they differ, the response is 400.
