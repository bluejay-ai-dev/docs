````
## Evaluate: POST /v1/evaluate

> **What this endpoint does:** Submit a call or chat for evaluation.

**Endpoint:** POST `https://api.getbluejay.ai/v1/evaluate`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| agent_id | string | ID of the agent associated with the call |
| start_time_utc | string | When the call started, in UTC ([python] log: datetime.now(timezone.utc) at call start) |
| participants | array[object] | List of call participants |

The body is one of: Call Request Using Bluejay Agent ID, Call Request Using External Agent ID. The table and example below use Call Request Using Bluejay Agent ID.

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/evaluate and include any optional parameters (e.g., `X-Organization-Id`, `recording_url`, `recording_base64`, `call_direction`, `interface`, `transcript_url`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.

**POST with body:**
```python
import requests

def evaluate(payload: dict, api_key: str) -> dict:
````

Sends one production conversation for evaluation. Identify the agent with `agent_id` or `external_agent_id`. `POST /v1/evaluate-call` is the same endpoint.

- Key-value pairs in `metadata` are available as [dynamic variables](/key-concepts/custom-metrics/prompting-guide) in custom metrics.
- If you omit `version`, Bluejay uses the version with the `production` label. An unknown `version` uses the production version and returns a `warning`.
- An unknown `label` is created and attached to the production version. With `external_agent_id`, `label` defaults to `production`.
- If the agent has no production version, the request succeeds and `warning` says so.

Rate limit: 100 requests per minute for each organization, or 500 for enterprise accounts.
