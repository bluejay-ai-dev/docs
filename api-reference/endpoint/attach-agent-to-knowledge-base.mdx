## Attach Agent to Knowledge Base — POST /v1/knowledge-base/{knowledge_base_id}/agents/{agent_id}

> **What this endpoint does:** Give an agent access to a knowledge base.

**Endpoint:** POST `https://api.getbluejay.ai/v1/knowledge-base/{knowledge_base_id}/agents/{agent_id}`
**Auth:** `X-API-Key` header

### Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| knowledge_base_id | string (uuid) | **Required.** The knowledge base. |
| agent_id | integer | **Required.** The agent to attach. |

### Example
```python
import requests

def attach_agent(kb_id: str, agent_id: int, api_key: str) -> dict:
    r = requests.post(f"https://api.getbluejay.ai/v1/knowledge-base/{kb_id}/agents/{agent_id}", headers={"X-API-Key": api_key})
    r.raise_for_status()
    return r.json()
```
