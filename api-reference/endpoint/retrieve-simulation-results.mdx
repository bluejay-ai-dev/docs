## Retrieve Simulation Results: GET /v1/retrieve-simulation-results/{simulation_run_id}

> **What this endpoint does:** Retrieve the results of a simulation run. Returns the simulation run details and one page of its results, oldest first.

Returns a simulation run and one page of its results, oldest first. Each result includes evaluations and custom metric results.

`limit` is 100 by default and 100 at most. Use `offset` to get the next page. Use `issue_ids` to keep only results linked to those simulation issues.
