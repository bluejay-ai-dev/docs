Returns a simulation run and one page of its results, oldest first. Each result includes evaluations and custom metric results. A result's `status` is one of the [call statuses](/test/simulations/reference#call-statuses).

`limit` is 100 by default and 100 at most. Use `offset` to get the next page. Use `issue_ids` to keep only results linked to those simulation issues.
