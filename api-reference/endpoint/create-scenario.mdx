Creates a scenario. `definition` is a React Flow graph with `nodes`, `edges`, and an optional `viewport`. Each node and its `data` must match the typed schemas in the playground.

To generate Digital Humans from a scenario, see [Scenario Adherence](/test/simulation-types/scenario-adherence).
