Deletes the version that has the `label` you send.

- `production` returns 400. Move the label first.
- A label with no version returns 404. A label on more than one version returns 400.
- You cannot delete the only version.
- If you delete the `latest` version, the label moves to the highest remaining version.

`DELETE /v1/agents/{agent_id}/prompts/versions` is the deprecated path of this endpoint.
