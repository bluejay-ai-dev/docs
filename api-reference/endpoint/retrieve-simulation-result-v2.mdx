---
title: Retrieve Simulation Result v2
description: Graded success-criteria bullets and pass rate for one result
---

<Note>
Same path as [Retrieve Simulation Result](/api-reference/endpoint/retrieve-simulation-result), under `/v2`. `/v1` is unchanged and does not include `criteria` or `criteria_pass_rate`.
</Note>

**Endpoint:** `GET https://api.getbluejay.ai/v2/retrieve-simulation-result/{test_result_id}`
**Auth:** `X-API-Key` header

The result includes the v1 payload plus:

| Field | Type | Description |
| --- | --- | --- |
| `criteria_pass_rate` | number \| null | Share of success-criteria bullets that passed, `0`–`100`. |
| `criteria` | object[] | Per-bullet grade: `id`, `text`, `passed`, `reasoning`. |

`goal_success` is `true` only when every bullet passed. After a human override, these fields reflect the effective grade.

```python
import requests

def retrieve_simulation_result_v2(test_result_id: str, api_key: str) -> dict:
    url = f"https://api.getbluejay.ai/v2/retrieve-simulation-result/{test_result_id}"
    response = requests.get(url, headers={"X-API-Key": api_key})
    response.raise_for_status()
    return response.json()
```

```json
{
  "simulation_result": {
    "id": "184201",
    "criteria_pass_rate": 75.0,
    "criteria": [
      {
        "id": "greet",

        "reasoning": "Caller name and account were confirmed on the first turn."

        "passed": false,
        "reasoning": "Caller asked for a person; the agent stayed in self-serve."
      }
    ]
  },

}
```
