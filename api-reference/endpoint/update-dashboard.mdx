## Update Dashboard: PUT /v1/dashboards/{dashboard_id}

> **What this endpoint does:** Rename a dashboard or change its description (empty string clears it).

**Endpoint:** PUT `https://api.getbluejay.ai/v1/dashboards/{dashboard_id}`
**Auth:** `X-API-Key` header
**Content-Type:** application/json
