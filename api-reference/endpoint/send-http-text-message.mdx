## Send HTTP Text Message: POST /v1/send-http-text-message

> **What this endpoint does:** Receive a text message via HTTP, process it through the lambda, and send response to webhook. Uses simulation_result_id (sim_conversation_id) for Redis operations and evaluations.

**Endpoint:** POST `https://api.getbluejay.ai/v1/send-http-text-message`
**Auth:** `X-API-Key` header
**Content-Type:** application/json

### Required Parameters
| Name | Type | Description |
|------|------|-------------|
| X-API-Key | string | API key required to authenticate requests. |
| simulation_result_id | string | ID of the simulation result (test result) |
| message | string | Text message to send |

The body is one of: HttpTextAgentUserMessageRequest, HttpTextAgentToolCallRequest. The table and example below use HttpTextAgentUserMessageRequest.

Review the full parameter list at https://docs.getbluejay.ai/api-reference/endpoint/send-http-text-message and include any optional parameters (e.g., `X-Organization-Id`, `end_conversation`, `end_turn`, `message_id`, `type`) that serve your integration's use case and align with Bluejay's testing and monitoring capabilities.

## Fields

| Field | Type | Description |
|---|---|---|
| `simulation_result_id` | string | Required. The simulation result to send to. |
| `type` | string | `message` (default) or `tool_call`. |
| `message` | string | Required when `type` is `message`. The agent text. |
| `name` | string | Required when `type` is `tool_call`. The tool name. |
| `parameters` | object | Tool parameters. |
| `output` | any | Tool output. |
| `end_turn` | boolean | Default `true`. If `false`, Bluejay holds the message and waits for more. |
| `end_conversation` | boolean | Default `false`. If `true`, Bluejay ends and evaluates the conversation. |
| `message_id` | string | Unique ID. Bluejay drops a repeated ID in the same conversation. |
