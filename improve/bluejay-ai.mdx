## Open Bluejay AI

To open Bluejay AI, press `Cmd+J` (Mac) or `Ctrl+J` (Windows). Bluejay AI reads the page you are on, so first open the simulation run or the Logs page you want to ask about. Your questions can then say "this run" or "these calls".

## Find what to improve

<Tabs>
  <Tab title="Test">
    After a simulation run, ask:

    - "Why did the failed calls in this run fail?"
    - "Which Digital Humans failed, and what do they have in common?"
    - "What should I fix first on my agent?"
  </Tab>
  <Tab title="Monitor">
    For production conversations, ask:

    - "Why did my calls fail this week?"
    - "What percent of inbound calls failed today, and which agent is worst?"
    - "Show me example calls where the caller asked for a human."
  </Tab>
</Tabs>

## Act on the answer

- **Edit the prompt.** Ask Bluejay AI to rewrite your agent's prompt to fix one failure pattern, then update your agent with the new prompt.
- **Start Self-Improve.** Ask Bluejay AI to improve the agent against a simulation. Bluejay AI shows a preview, and the run starts when you confirm it. See [Self-Improve](/key-concepts/self-improve/overview).
- **Add a test.** Ask Bluejay AI to create Digital Humans for the failure, linked to your simulation. See [Digital Humans](/key-concepts/digital-humans/overview).
- **Measure it.** Ask Bluejay AI to create a custom metric that grades the failure on every call. See [custom metrics](/key-concepts/custom-metrics/overview).
