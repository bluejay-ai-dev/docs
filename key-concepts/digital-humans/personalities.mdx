A Personality changes how the Digital Humans in a simulation sound and act, for example a fast talker or a caller with a bad connection, so you can test the same goals with different callers. When you select Personalities on a simulation, each Digital Human in the run calls once as itself and once for each Personality. Two Digital Humans and two Personalities give six conversations.

## How a Personality works

Start from a preset, for example **Fast talker**, and change only the fields you need.

A Personality changes only the fields that you set on it, for example the **Personality** text (`role_description`), voice, background noise, or the [behavior fields](/key-concepts/digital-humans/overview#behavior). All other fields come from the Digital Human. A Personality never changes the intent or the success criteria, so each call still tests the same goal.

The simulation saves its Personality selection, so the next run uses the same set.

## Limits

- A [customer journey](/test/simulations/customer-journeys) does not run once for each Personality.
- A change to a Personality applies to future runs only.
- If you delete a Personality, Bluejay removes it from each simulation that selects it. Past conversations show "Personality no longer exists".
