Examples are a fast talker or a caller with a bad connection.

Each Digital Human in the run calls once as itself and once for each Personality. Two Digital Humans and two Personalities give six Conversations.

## Add Personalities to a run

1. Open **Create New Run** or **Create Simulation**.
2. Click **Select Personalities** above the Digital Humans list.
3. Select the Personalities for this run.
4. Click **Done**.

The simulation saves the selection, so the next run uses the same set.

## Create a Personality

1. In the **Personalities for this run** dialog, click **New personality**.
2. Enter the Personality name.
3. Optional: click **Start from** and select a [preset](#presets).
4. Set the fields to change.
5. Click **Create**.

## Fields a Personality can set

A Personality changes only the fields that you set on it. All other fields come from the Digital Human. A Personality never changes the intent or the success criteria.

You can set **Personality** (it replaces the Digital Human description), **Voice**, **Background noise**, **Voice speed**, **Audio quality**, **Dropouts**, **Fluency**, **Verbosity**, **Patience**, **Silence timeout**, **Creativity**, and **Interruptions**. See [Configuration](/key-concepts/digital-humans/overview#behavior) for the values.

## Presets

A preset fills the fields of a new Personality, for example **Fast talker** or **Bad connection**. You can change the fields before you click **Create**.

## Limits

- A [customer journey](/test/simulations/customer-journeys) does not run once for each Personality.
- A change to a Personality applies to future runs only.
- If you delete a Personality, Bluejay removes it from each simulation that selects it. Past conversations show "Personality no longer exists".
