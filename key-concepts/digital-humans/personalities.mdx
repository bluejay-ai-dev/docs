Each Digital Human in the run calls once as itself and once for each Personality.

For each Digital Human, the number of conversations is `num_runs` × (1 + Personalities). For example, two Digital Humans with `num_runs` 1 and two Personalities give six conversations.

## Add Personalities to a run

1. Open **Create New Run** or **Create Simulation**.
2. Click **Select Personalities** above the Digital Humans list.
3. Select the Personalities for this run.
4. Click **Done**.

Personalities belong to your organization, so any simulation can use them. The simulation saves the selection, so the next run, including a scheduled run, uses the same set.

## Create a Personality

1. In the **Personalities for this run** dialog, click **New personality**.
2. Enter the Personality name.
3. Optional: click **Start from** and select a [preset](#presets).
4. Set the fields to change.
5. Click **Create**.

## Fields a Personality can set

A Personality changes only the fields that you set on it. All other fields come from the Digital Human. A Personality never changes `intent`, `success_criteria`, `traits`, or `scripted_responses`.

| Field | Label |
|---|---|
| `role_description` | Personality. It replaces the description of the Digital Human. |
| `language`, `accent`, `gender` | Voice. You set the three as one group. |
| `background_noise`, `background_noise_volume`, `custom_background_noise_url` | Background noise |
| `voice_speed` | Voice speed |
| `audio_quality` | Audio quality |
| `connection_quality` | Dropouts |
| `fluency` | Fluency |
| `verbosity` | Verbosity |
| `endpointing_delay` | Patience |
| `silence_timeout` | Silence timeout |
| `temperature` | Creativity |
| `interruption_configs` | Interruptions |

See [Configuration](/key-concepts/digital-humans/overview#behavior) for the values.

## Presets

A preset fills the fields of a new Personality. Bluejay saves nothing until you click **Create**, so you can change the name and fields first.

| Preset | Sets |
|---|---|
| Background noise | Traffic at 0.8 volume |
| Interruptions | High probabilistic interruptions, patience 0.5 seconds |
| Poor audio | Low audio quality |
| Bad connection | Medium dropouts |
| Second language | Intermediate fluency, slow speed |
| Fast talker | Fast speed, high verbosity |
| Long pauses | Patience 5 seconds, slow speed |
| Unpredictable | Creativity 1.5, high verbosity |

## Limits

- A [customer journey](/test/simulations/customer-journeys) does not run once for each Personality.
- A change to a Personality applies to future runs only.
- If you delete a Personality, Bluejay removes it from each simulation that selects it. Past conversations show "Personality no longer exists".

## API

| Method | Path | Action |
|---|---|---|
| `GET` | `/v1/personalities` | List the Personalities of your organization. |
| `POST` | `/v1/personalities` | Create one or more Personalities. |
| `PATCH` | `/v1/personalities/{personality_id}` | Update a Personality. |
| `DELETE` | `/v1/personalities/{personality_id}` | Delete a Personality. |
| `GET` | `/v1/simulations/{simulation_id}/personalities` | Read the selection of a simulation. |
| `PUT` | `/v1/simulations/{simulation_id}/personalities` | Replace the selection with `personality_ids`. An empty list runs each Digital Human once, as itself. |
