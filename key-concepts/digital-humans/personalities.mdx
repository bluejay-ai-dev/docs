Examples are a fast talker or a caller with a bad connection.

Each Digital Human in the run calls once as itself and once for each Personality. Two Digital Humans and two Personalities give six Conversations.

## Add Personalities to a run

1. Open **Create New Run** or **Create Simulation**.
2. Click **Select Personalities** and select the Personalities for this run.

The simulation saves the selection, so the next run uses the same set.

## Create a Personality

1. In the Personalities dialog, click **New personality**.
2. Enter a name. Optional: start from a preset, for example **Fast talker**.
3. Set the fields to change, then click **Create**.

A Personality changes only the fields that you set on it, for example voice, background noise, or the [behavior fields](/key-concepts/digital-humans/overview#behavior). All other fields come from the Digital Human. A Personality never changes the intent or the success criteria.

## Limits

- A [customer journey](/test/simulations/customer-journeys) does not run once for each Personality.
- A change to a Personality applies to future runs only.
- If you delete a Personality, Bluejay removes it from each simulation that selects it. Past conversations show "Personality no longer exists".
