Upload a CSV file to create many Digital Humans in a simulation at once.

![Upload Custom Digital Humans card on the Create Simulation modal](/images/upload-dh-card.png)

<Steps>
  <Step title="Open the upload panel">
    Go to **Simulations > Create Simulation**, select the agent, and select **Upload Digital Humans**.
  </Step>
  <Step title="Get the template">
    Click **Sample CSV** to download `sample_digital_humans.csv`.
  </Step>
  <Step title="Fill in the rows">
    Add one Digital Human for each row. A blank cell uses the simulation default.
  </Step>
  <Step title="Upload">
    Drop the `.csv` file on the upload area, or click to browse.
  </Step>
</Steps>

![CSV upload area with the Sample CSV button](/images/upload-dh-dropzone.png)

The first row that is not empty is the header. Header matching ignores case. Bluejay ignores columns that it does not know and skips blank rows.

| Column | Sets | Values |
|---|---|---|
| `Name` | `name` | If blank, Bluejay generates a name. |
| `Intent` | `intent` | Text |
| `Success Criteria` | `success_criteria` | Text |
| `Role Description` | `role_description` | Text |
| `Phone Number` or `Caller Number` | `phone_number` | A number your organization owns. Otherwise Bluejay skips the row. |
| `Scripted Responses` | `scripted_responses` | A JSON object or array |
| `Scripted Responses In Order` | `scripted_responses_ordered` | `true` or `false` |
| `Creativity` | `creativity` | 0 to 1 |
| `Patience` | `endpointing_delay` | Seconds, 0 or more |
| `No Response Timeout` | `silence_timeout` | Seconds, 0 or more |
| `Voice` | Voice | A voice key, for example `en_british_feminine` |
| `Voice Speed` | `voice_speed` | As in [Behavior](/key-concepts/digital-humans/overview#behavior) |
| `Background Noise` | `background_noise` | As in [Behavior](/key-concepts/digital-humans/overview#behavior) |
| `Background Noise Volume` | `background_noise_volume` | 0 to 1 |
| `Audio Quality` | `audio_quality` | As in [Behavior](/key-concepts/digital-humans/overview#behavior) |
| `Dropouts` | `connection_quality` | As in [Behavior](/key-concepts/digital-humans/overview#behavior) |
| `Verbosity` | `verbosity` | As in [Behavior](/key-concepts/digital-humans/overview#behavior) |
| `Fluency` | `fluency` | As in [Behavior](/key-concepts/digital-humans/overview#behavior) |
| `Interruptions` | `interruptions` | JSON, see below |
| `Speaks First` | `speaks_first_config` | JSON, for example `{"speaks_first": true, "mode": "custom", "message": "Hi, I am calling about my bill."}` |
| `TC_<tool>` | An expected tool call | A string is the expected output. A JSON object can have `output` and `parameters`. |
| `CT_<trait>` | A [trait](/key-concepts/digital-humans/overview#traits) | The trait value |

The `Interruptions` cell is a JSON object with `interruptions_type`:

- `{"interruptions_type": "none"}`
- `{"interruptions_type": "probabilistic", "probability_of_default_interrupt": 0.5}`, with a value from 0 to 1.
- `{"interruptions_type": "keyword", "keyword_responses": {"refund": {"response": "Yes, the refund!", "probability": 0.8}}}`
- `{"interruptions_type": "llm", "llm_prompt": {"user_prompt": "Interrupt when the agent talks too long."}}`

You cannot add `audio` scripted responses with a CSV. Add them in the editor after the upload.

Bluejay reports row errors and imports the rows that are valid. If a JSON cell does not parse, Bluejay tries to repair quotes and line breaks.

<Warning>
  A repaired JSON cell can have the wrong value. If Bluejay shows a "verify these rows" warning, check those Digital Humans before you run the simulation.
</Warning>
