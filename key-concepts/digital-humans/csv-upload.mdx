To create many Digital Humans at once, upload a CSV file. Each row becomes one Digital Human.

![Upload Custom Digital Humans card on the Create Simulation modal](/images/upload-dh-card.png)

Start from the **Sample CSV** template in the upload panel. A blank behavior cell uses your **Default Generation Settings**.

![CSV upload area with the Sample CSV button](/images/upload-dh-dropzone.png)

## Columns

Column headers are not case-sensitive, and Bluejay ignores columns that it does not know.

| Column | Values |
|---|---|
| `Name` | If blank, Bluejay generates a name. |
| `Intent`, `Success Criteria`, `Role Description` | Text |
| `Phone Number` | A number your organization owns. If the number is not owned or cannot be read, Bluejay skips the row. If blank, Bluejay assigns a number. |
| `Scripted Responses` | A JSON object or array |
| `Scripted Responses In Order` | `true` or `false` |
| `Creativity` | 0 to 1 |
| `Patience`, `No Response Timeout` | Seconds |
| `Voice` | A voice key, for example `en_british_feminine` |
| `Voice Speed`, `Background Noise`, `Background Noise Volume`, `Audio Quality`, `Dropouts`, `Verbosity`, `Fluency` | As in [Behavior](/key-concepts/digital-humans/overview#behavior) |
| `Interruptions` | JSON, see below |
| `Speaks First` | JSON, for example `{"speaks_first": true, "mode": "custom", "message": "Hi, I am calling about my bill."}` |
| `TC_<tool>` | An expected tool call. A string is the expected output. |
| `CT_<trait>` | The value of a [trait](/key-concepts/digital-humans/overview#traits) |

The `Interruptions` cell is a JSON object with `interruptions_type`:

- `{"interruptions_type": "none"}`
- `{"interruptions_type": "probabilistic", "probability_of_default_interrupt": 0.5}`, with a value from 0 to 1.
- `{"interruptions_type": "keyword", "keyword_responses": {"refund": {"response": "Yes, the refund!", "probability": 0.8}}}`
- `{"interruptions_type": "llm", "llm_prompt": {"user_prompt": "Interrupt when the agent talks too long."}}`

You cannot add `audio` scripted responses with a CSV. Add them in the editor after the upload.

If a cell has a value that is not valid, Bluejay reports an error and imports the row without that field.

<Warning>
  If a cell has unescaped quotes, Bluejay repairs it and shows an "Auto-corrected" warning. A repaired cell can have the wrong value. Check the scripted responses of those Digital Humans before you run the simulation.
</Warning>
