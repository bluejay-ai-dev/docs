Each metric checks one rule, for example that the agent verified identity before it shared account data. Metrics run on simulation and production Conversations.

## Create a Custom Metric

1. Open the **Metrics** page and click **Create**. Write the metric yourself, generate it, or add it from the library.
2. Select the metric type. For **LLM as a Judge**, select the response type and write the prompt.
3. Connect the metric to one or more agents.

To test a metric against labeled Conversations before you use it, use the [Metrics Lab](/key-concepts/metrics-lab/overview).

## Metric types

| Type (UI label) | `metric_type` | How it scores |
|---|---|---|
| LLM as a Judge | `llm_judge` | An LLM scores the Conversation against your prompt. |
| Composite | `composite` | Combines the results of other metrics into one score or label. |
| Tool Call | `tool_call` | Passes when the agent called the tools you name. |
| Phrase Match | `transcript_regex` | Checks whether specific words were said. |
| Transfer Landed | `transfer_landed` | Passes when the agent transferred the call to one of your Digital Humans, and that Digital Human answered. |

Tool Call, Phrase Match, and Transfer Landed always return Pass/Fail. A Composite formula refers to a metric by its ID in double quotes, for example `round(100 * ("<metric_id>" / 5))`.

## Response types

The response type sets the shape of an LLM as a Judge result.

| Response type (UI label) | `response_type` | Example |
|---|---|---|
| Pass/Fail | `pass_fail` | Did the agent verify identity before it shared account details? |
| Yes/No | `yes_no` | Did the customer ask for a human? |
| Number | `quantitative` | Rate the clarity of the explanation from 1 to 5. |
| Text | `qualitative` | Summarize the objections the customer raised. |
| Categorical | `enum` | Classify the call as `resolved`, `escalated`, or `unresolved`. |
| Structured JSON | `json` | Return `identity_verified` (boolean) and `flags` (string array). |

Text results do not roll up into a number. If you need a trend, add a Pass/Fail or Number metric next to the Text metric.

## Fields

| Field | Description |
|---|---|
| `prompt` | The judge prompt. Required for `llm_judge`. |
| `scoring_guidance` | Extra grading rules for the judge. |
| `eval_segment` | The side of the Conversation to evaluate: `agent`, `user`, or `all` (default). |
| `scope` | Where the metric runs: `observability`, `simulations`, or `all` (default). |
| `allow_not_applicable` | If `true`, the judge can return `Not Applicable` when the criterion does not apply to the Conversation. Default `false`. |
| `settings.use_knowledge_base` | If `true`, the judge can search the agent's [Knowledge Base](/key-concepts/knowledge-base/overview). Default `false`. |

To put call-specific values into `prompt` or `scoring_guidance`, use [dynamic variables](/key-concepts/custom-metrics/prompting-guide#dynamic-variables).
