A dashboard shows simulation data or production data, not both. For simulation data, open **Simulations → Dashboards**. For production data, open **Observability → Dashboards**.

## Build a dashboard

A dashboard holds widgets. Each widget charts one or more metrics over time.

To share a dashboard outside Bluejay, create a share link.

To get a notification when a metric crosses a value, add an [alert](/key-concepts/alerts/overview).

## Build with Bluejay AI

Ask [Bluejay AI](/improve/bluejay-ai) to build a dashboard for you, for example "Make a dashboard of pass rate by agent for the last month". It can also add, change, and remove widgets.
