A dashboard is a set of widgets that chart your evaluation data over time. Each dashboard holds either simulation data or production data. The two are never mixed.

<Tabs>
  <Tab title="Simulations">
    Open Simulations → Dashboards. Widgets read simulation results. Group a widget by simulation to compare runs of selected simulations.
  </Tab>
  <Tab title="Production">
    Open Observability → Dashboards. Widgets read evaluated production Conversations. Group a widget by a metadata field, for example `experiment_group`, to compare variants.
  </Tab>
</Tabs>

## Create a dashboard

1. Click **Create Dashboard** and enter a name.
2. Click **Add Widget**.
3. Select the chart type and the metrics to show.
4. If you want to split the data, select a group.
5. Save the widget. Drag it to arrange the layout.

To share a dashboard outside Bluejay, create a share link. You can revoke the link later.

## Widget fields

| Field | Values |
|-------|--------|
| Chart type | Line, bar, pie, table, KPI, pivot table, histogram. |
| Mode | Time series or categorical. |
| Aggregation | Count, average, sum, percent of total, p50, p90, p95, p99. |
| Time bucket | Hour, day, week, month. |
| Group by | Agent, labels, tool call, age, gender, simulation, or a metadata field. |
| Filters | Limit the conversations the widget counts. These add to the dashboard's agents, labels, and time range. |

To get a notification when a metric crosses a value, add an [alert](/key-concepts/alerts/overview).
