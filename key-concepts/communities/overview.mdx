A Community is a saved group of Digital Humans that you can reuse in any simulation.

## Create a Community

1. Open the **Digital Humans** page.
2. Click **Create Community**.
3. Enter a **Title**, an optional **Description**, and optional **Digital Humans**.
4. Save.

To add Digital Humans later, select them in the list and click **Add to Community**. Then select an **Existing Community** or create one.

## Run a Community

1. Go to **Simulations > Create Simulation**.
2. Select **Use Previous Digital Humans**.
3. Select the Community in the **Communities** list.

## Grow the suite

When an agent fails on a real Conversation, create a Digital Human that copies the failure and add it to the Community. The next run then tests for that failure again.
