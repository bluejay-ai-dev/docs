A Community is a saved group of Digital Humans that you can reuse in any simulation.

## Use a Community as a suite

Group the Digital Humans that cover one agent or one flow into a Community. Select the Community when you create a simulation, so each agent version runs against the same callers and the results compare directly.

## Grow the suite

When an agent fails on a real conversation, create a Digital Human that copies the failure and add it to the Community. The next run then tests for that failure again.
