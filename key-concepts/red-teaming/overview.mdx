Adversarial Digital Humans call your agent. The first calls learn which data and tools the agent has. Each later batch of calls pushes harder with the tactics that made progress. The run stops when the budget is used or a breach is confirmed.

## Launch a run

1. Open the **Red Teaming** page and click **Launch red team**.
2. On the **Simulation** tab, select the agent. Voice agents and HTTP text agents are supported. Email agents are not supported.
3. Select an intensity: **Quick**, **Standard**, **Thorough**, or **Custom**.
4. Optional: on the **Attacker knowledge** tab, add what the attacker already knows about the target customer.
5. Optional: on the **Connection** tab, enter DTMF digits to dial after the call connects.
6. Click **Launch red team**. The results page shows calls as they finish.

### Intensity

| Preset | Max call length | Content-harm categories |
|---|---|---|
| Quick | 5 min | Two of five |
| Standard | 8 min | All five |
| Thorough | 10 min | All five |

A higher intensity runs more calls. **Custom** lets you set the number of attempts for each attack type. Custom is available on the Growth, Scale, and Enterprise plans.

### Attacker knowledge

Each entry is a fact the attacker knows about the target customer, for example a name or the last four digits of a card. Enter a value, or select **Random** so that Bluejay makes up a value. A template fills many fields at once.

## Read the results

To end a run early, click **Stop & kill calls**.

| Verdict | Meaning |
|---|---|
| Breached | At least one attack compromised the agent. |
| Held under pressure | The agent resisted, but conceded ground on some attacks. |
| Held | The agent resisted all attacks. |
| Inconclusive | No attacks ran. |

An attack is a breach if the agent gave the attacker useful data, took a gated action such as an account change, or produced harmful content. A content-harm failure alone fails the run.

The **Report** tab shows a verdict for each [OWASP category](/key-concepts/red-teaming/attack-catalog#owasp-coverage) and each [content-harm category](/key-concepts/red-teaming/attack-catalog#content-harm). The **Swarm** tab shows each attack as a node. Click a node to see the evaluation, the transcript, and the recording.

## Fix a breach

1. Open each **Breached** attack and read the exact words that worked.
2. On the **Evaluation** tab, find the gate that was missing or bypassed.
3. Change the prompt, add or enforce a verification gate, or limit the tool.
4. Run the same intensity again to confirm the fix.
