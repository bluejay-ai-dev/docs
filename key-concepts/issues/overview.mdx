Bluejay groups similar failures into one Issue, so you triage one problem in place of many failed calls.

Simulations and production each have their own Issues list. Fix the Issue with the most conversations first.

## Track an Issue

Set the status to track the work: `open`, `in_progress`, `resolved`, or `ignored`. Set the priority to `low`, `medium`, `high`, or `urgent` to order the work across the team. A new Issue has no priority.

## Issue types

| UI label | API `type` | Meaning |
|----------|------------|---------|
| Agent Failure | `non_deterministic` | Bluejay grouped similar failures into one Issue. |
| System Error | `deterministic` | Bluejay matched a known error, for example a [call error code](/test/simulations/simulation-results#error-codes). |
