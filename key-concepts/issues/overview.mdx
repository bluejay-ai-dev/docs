Bluejay groups similar failures into one Issue, so you triage one problem in place of many failed calls.

<Tabs>
  <Tab title="Simulations">
    Open Simulations → Issues.
  </Tab>
  <Tab title="Production">
    Open Observability → Issues.
  </Tab>
</Tabs>

## Issue types

| UI label | API `type` | Meaning |
|----------|------------|---------|
| Agent Failure | `non_deterministic` | Bluejay grouped similar failures into one Issue. |
| System Error | `deterministic` | Bluejay matched a known error. |

## Triage an Issue

You can change these fields from the list or the Issue page:

| Field | Values |
|-------|--------|
| Status | Open, In Progress, Resolved, Ignored. |
| Priority | Urgent, High, Medium, Low. Empty until someone sets it. |
| Assignee | A member of your organization. |
| Due date | A date, or empty. |
