Bluejay groups similar failures into one Issue, so you triage one problem in place of many failed calls.

Simulations and production each have their own Issues list. Fix the Issue with the most conversations first, and use the status to track which Issues are still open.

## Issue types

| UI label | API `type` | Meaning |
|----------|------------|---------|
| Agent Failure | `non_deterministic` | Bluejay grouped similar failures into one Issue. |
| System Error | `deterministic` | Bluejay matched a known error. |
