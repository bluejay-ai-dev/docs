Bluejay can also generate Digital Humans that ask about those facts.

## Add documents

Connect a Knowledge Base to the agents that use it. Add the same sources your agent uses: files, pasted text, or web page URLs. A new document shows **Processing**. Bluejay uses it only after its status is **Ready**. If the status is **Failed**, add the document again.

## Limits

| Source | Supported types | Maximum size |
|---|---|---|
| File | PDF (`.pdf`), text (`.txt`), Markdown (`.md`, `.markdown`) | 100 MB for each file |
| File | HTML (`.html`, `.htm`) | 10 MB for each file |
| Text | Typed or pasted text | 1 MB. For more, upload a file. |
| URL | One web page | None |

Bluejay rejects other file extensions.

## How Bluejay uses a Knowledge Base

| Feature | Use |
|---|---|
| Success evaluation | When a success criterion depends on facts, the judge searches the Knowledge Bases of the agent. |
| Hallucination check | If your organization turns it on, Bluejay checks the agent's answers against its Knowledge Bases. |
| Custom Metrics | If a metric has `settings.use_knowledge_base` set to `true`, the judge can search the Knowledge Base. See [Custom Metrics](/key-concepts/custom-metrics/overview#fields). |
| Simulations | The **Generate from Knowledge Base** type makes Digital Humans across the topics in a Knowledge Base. See [Simulations](/test/simulations/overview#simulation-types). |
