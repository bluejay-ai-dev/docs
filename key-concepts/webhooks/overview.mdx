Bluejay sends a signed `POST` request with a JSON body to your URL when it evaluates a conversation, ends a simulation, or fires an alert. The [Events Webhook reference](/api-reference/webhook/events-webhook) has the payload schemas.

## Create a webhook

1. Open Settings → Webhooks.
2. Add your URL. Use HTTPS.
3. Select the events.
4. If you want only some agents, select agents or folders. A folder includes every agent in it.
5. Generate the signing key and copy it to your receiver.

If you select no agents and no folders, the webhook fires for all agents in the workspace.

## Events

| UI label | `type` in the body | Fires when |
|----------|--------------------|------------|
| Simulation evaluated | `simulation_result_evaluated` | A simulation result finishes evaluation. |
| Simulation ended | `simulation_ended` | A simulated conversation ends, before evaluation. |
| Outbound simulation started | `outbound_simulation_started` | An outbound simulation run starts. |
| Observability log evaluated | `observability_call_evaluated` | A production conversation finishes evaluation. |
| Observability alert triggered | `observability_alert_triggered` | An observability [alert](/key-concepts/alerts/overview) enters or leaves alarm. |
| Simulation alert triggered | `simulation_alert_triggered` | A simulation alert fires for a run. |

## Verify the signature

Each request has an `X-Bluejay-Signature` header. The value is the hex HMAC-SHA256 of the raw body, signed with your webhook's signing key.

1. Read the raw request body. Do not parse and serialize the JSON again, because the signature uses the exact bytes.
2. Compute `HMAC-SHA256(body, signing_key)` as a hex digest.
3. Compare it to `X-Bluejay-Signature` with a constant-time comparison.
4. If the values do not match, reject the request.

```python
import hmac, hashlib

def is_valid(body: bytes, signature: str, signing_key: str) -> bool:
    expected = hmac.new(signing_key.encode(), body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature)
```

## Delivery

- Requests come from `api.getbluejay.ai`. If you use an allowlist, allow that host.
- Bluejay sends each event once and does not retry.

## Troubleshooting

If a webhook does not fire, do these checks:

1. Make sure the webhook is enabled.
2. Make sure the event is selected.
3. Make sure the agent is in the selected agents or folders.
4. Make sure the agent and the webhook are in the same workspace.
5. Make sure your URL is reachable from the internet.
