The Metrics Lab compares the verdicts of a Custom Metric with verdicts from your reviewers, and helps you change the metric until the two agree. The Metrics Lab is the **Lab** tab on the **Metrics** page.

## Create a lab

1. Open the **Metrics** page, then open the **Lab** tab.
2. Click **Create Lab**.
3. Enter a name.
4. Under **Metrics**, select one or more Custom Metrics.
5. Under **Conversations**, select Conversations from your agent or from a simulation run.
6. Click **Create Lab**.

If a selected Conversation already has an evaluation, the lab uses it.

![The Metrics Lab landing page with the Create Lab button](/images/metrics-lab-landing.png)

![The Create Lab dialog with the name, metrics, and Conversations steps](/images/metrics-lab-create-dialog.png)

### Select a sample

The tuned metric is only as good as the sample. Select 20 to 50 Conversations for each metric. Include clear passes, clear fails, and unclear cases. Include each Digital Human intent or production scenario that you care about.

## Label the Conversations

1. Open the **Annotate** tab. Each metric has an AI column and a Human column.
2. Click a row. The **Transcript** tab shows the Conversation. The **Details** tab shows each metric.
3. In **Details**, set the human verdict. The input matches the response type:
   - Pass/Fail and Yes/No: buttons.
   - Number: a value in the metric range.
   - Categorical: a list of the `enum_options`.
   - Text and Structured JSON: free text.
4. Optional: enter a note in **Human reasoning**.
5. Click **Save**. Use **Previous** and **Next**, or the arrow keys, to go to the next row.

The header shows **Annotated X/Y**. To set the same verdict on many rows, select the rows and use **Bulk Annotate**.

![The Annotate tab with AI and Human columns](/images/metrics-lab-annotate-table.png)

<Note>
Label every Conversation before you read the alignment score. The score compares only rows that have a human verdict.
</Note>

## Improve the metric

1. Open the **Optimize** tab and select a metric. The header shows **Alignment**, the percentage of rows where the AI verdict and the human verdict match.
2. Change the metric. Do one of these:
   - Click **Improve**. Bluejay writes a new prompt from the rows where the verdicts do not match. You can add instructions. Review the diff, then accept or discard it.
   - Edit the prompt, model, evaluation route (`AUTO`, `TEXT`, or `AUDIO`), or temperature by hand.
3. Click **Run**. Bluejay saves a new revision and evaluates all rows again.
4. Compare the alignment score. Use **Previous** and **Next** to compare revisions.
5. When the score is high enough, click **Publish**. The revision becomes the live metric for all simulations and production evaluations.

![The Optimize tab with a prompt diff, Improve, and Published status](/images/metrics-lab-optimize-table.png)

## Settings

| Setting | Description |
|---|---|
| Fuzzy Alignment | If on, Number verdicts match when they are close. |
| Numerical Score Threshold | The largest difference, in points, that counts as a match. With a threshold of 1, an AI score of 2 and a human score of 3 match. Default 1. |

## Keep the lab current

- **Add Conversations** adds new Conversations to the lab.
- **Add Metrics** adds another metric to the lab.
- **Re-evaluate** scores all rows again with the current metric definitions.

When production shows new cases, add them, label them, check the alignment score, and publish again.
