## Create a lab

1. On the **Metrics** page, open the **Lab** tab and click **Create Lab**.
2. Enter a name and select one or more Custom Metrics.
3. Select Conversations from your agent or from a simulation run.

![The Metrics Lab landing page with the Create Lab button](/images/metrics-lab-landing.png)

![The Create Lab dialog with the name, metrics, and Conversations steps](/images/metrics-lab-create-dialog.png)

### Select a sample

The tuned metric is only as good as the sample. Select 20 to 50 Conversations for each metric. Include clear passes, clear fails, and unclear cases.

## Label the Conversations

1. Open the **Annotate** tab. Each metric shows the AI verdict next to the human verdict.
2. Open each row, read the Conversation, and set the human verdict for each metric.

To set the same verdict on many rows, select the rows and annotate them in bulk.

![The Annotate tab with AI and Human columns](/images/metrics-lab-annotate-table.png)

<Note>
Label every Conversation before you read the alignment score. The score compares only rows that have a human verdict.
</Note>

## Improve the metric

1. Open the **Optimize** tab and select a metric. The header shows **Alignment**, the percentage of rows where the AI verdict and the human verdict match.
2. Change the metric. Do one of these:
   - Click **Improve**. Bluejay writes a new prompt from the rows where the verdicts do not match. Review the diff, then accept or discard it.
   - Edit the prompt or model by hand.
3. Click **Run**. Bluejay saves a new revision and evaluates all rows again.
4. Compare the alignment score with the previous revision.
5. When the score is high enough, click **Publish**. The revision becomes the live metric for all simulations and production evaluations.

![The Optimize tab with a prompt diff, Improve, and Published status](/images/metrics-lab-optimize-table.png)

For Number metrics, turn on **Fuzzy Alignment** to count close scores as a match.

## Keep the lab current

When production shows new cases, click **Add Conversations**, label them, check the alignment score, and publish again.
