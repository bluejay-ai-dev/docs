## Build a lab

A lab pairs one or more Custom Metrics with a sample of Conversations from an agent or a simulation run. The tuned metric is only as good as the sample. Select 20 to 50 Conversations for each metric. Include clear passes, clear fails, and unclear cases.

![The Metrics Lab landing page with the Create Lab button](/images/metrics-lab-landing.png)

![The Create Lab dialog with the name, metrics, and Conversations steps](/images/metrics-lab-create-dialog.png)

## Label the Conversations

Your label is the human verdict. The metric's result is the AI verdict. Label in bulk when many rows share the same verdict.

![The Annotate tab with AI and Human columns](/images/metrics-lab-annotate-table.png)

<Note>
Label every Conversation before you read the alignment score. The score compares only rows that have a human verdict.
</Note>

## Improve the metric

**Alignment** is the percentage of labeled rows where the AI verdict and the human verdict match. **Improve** rewrites the prompt from your labeled rows. You can also edit the prompt or model by hand. Each run saves a new revision, so you can compare alignment across revisions. **Fuzzy Alignment** is a lab setting that counts close number scores as a match.

![The Optimize tab with a prompt diff, Improve, and Published status](/images/metrics-lab-optimize-table.png)

Publishing makes the revision the live metric for all simulations and production evaluations.

## Keep the lab current

When production shows new cases, add them to the lab, label them, and publish again if alignment improves.
