---
title: "Self-Improve"
description: "Use Self-Improve to fix a failing agent prompt without manual trial and error."
icon: wand-magic-sparkles
---

Bluejay finds why calls fail, rewrites the prompt, and keeps a change only if the pass rate goes up.

## Requirements

Self-Improve pushes each new prompt to your voice platform, so the agent must be synced from a platform that supports it. The integration page for your platform says if it supports Self-Improve.

## Start a run

Ask **Bluejay AI** to improve an agent against a simulation. For example:

> Improve my "Billing Support" agent against the "Billing regression suite" simulation until it passes 90% of calls.

Bluejay AI shows a preview of the agent, simulation, target, and rounds. Confirm the preview to start the run.

| Setting | Default | Range |
|---|---|---|
| Target pass rate | 0.9 | 0 to 1 |
| Maximum rounds | 5 | 1 to 20 |
| Minimum improvement to keep a fix | 0.02 | 0 to 1 |
| Number of generated metrics | 5 | 1 to 20 |

Bluejay generates metrics for the run. To use your own metrics in their place, name them in your request.

## Each round

1. Metrics: Bluejay generates Pass/Fail metrics from the agent goals and tools, or uses the metrics you named.
2. Baseline: the current prompt runs the full simulation. If the pass rate already meets the target, the run ends with no change.
3. Diagnose: Bluejay reads the failed calls and finds one failure pattern.
4. Fix: Bluejay writes a new prompt for that pattern and pushes it to your provider.
5. Verify: the simulation runs again. If the pass rate goes up by at least the minimum improvement, Bluejay keeps the fix. If not, Bluejay reverts it and does not try that pattern again.

The run stops when the pass rate meets the target, the round limit is reached, two rounds in a row give no gain, or Bluejay finds no new fix.

## Result

If the run beats the baseline, Bluejay saves the best prompt as a new Agent Version on the agent with the `latest` label.

To see progress, ask Bluejay AI for the run status.

## Limits

- An agent can have one active run. A second run on the same agent is rejected until the first run ends or stops.
- To stop a run, ask Bluejay AI. Bluejay reverts changes that it did not verify.
- Each round runs the full simulation and costs the same as a manual run.
