## Export traces to Bluejay

To send traces to Bluejay, point an OTLP over HTTP exporter at `https://otlp.getbluejay.ai/v1/traces` and send your API key in the `X-API-KEY` header. Any OpenTelemetry-compatible library works, for example OpenInference, OpenLLMetry, or Langfuse.

```python
from opentelemetry.sdk import trace as trace_sdk
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace.export import SimpleSpanProcessor
from opentelemetry.sdk.resources import SERVICE_NAME, Resource

tracer_provider = trace_sdk.TracerProvider(
    resource=Resource.create({SERVICE_NAME: "<your_service_name>"})
)
tracer_provider.add_span_processor(SimpleSpanProcessor(OTLPSpanExporter(
    "https://otlp.getbluejay.ai/v1/traces",
    headers={"X-API-KEY": "<BLUEJAY_API_KEY>"},
)))

# Example: instrument the OpenAI client
from opentelemetry.instrumentation.openai import OpenAIInstrumentor
OpenAIInstrumentor().instrument(tracer_provider=tracer_provider)
```

If your agent runs on a voice framework, its integration page can show a framework-specific setup.

## Link a trace

To show a trace next to its conversation, send Bluejay the trace ID for that conversation.

<Tabs>
  <Tab title="Simulations">
    1. Read the `X-Simulation-Result-Id` that Bluejay sends with each simulated call. It arrives as a SIP header, a WebSocket upgrade header, or in a form that your integration page describes.
    2. Collect the trace IDs that your agent creates during the call.
    3. After the call ends, call `tracer_provider.force_flush()`. If you skip this, the trace can be missing.
    4. Send `simulation_result_id` and `trace_ids` to [`POST /v1/update-simulation-result`](/api-reference/endpoint/update-simulation-result).

    ```python
    import httpx

    async def link_traces(simulation_result_id, trace_ids, api_key):
        async with httpx.AsyncClient(timeout=10) as client:
            await client.post(
                "https://api.getbluejay.ai/v1/update-simulation-result",
                json={"simulation_result_id": simulation_result_id, "trace_ids": trace_ids},
                headers={"X-API-Key": api_key},
            )
    ```
  </Tab>
  <Tab title="Production">
    Add `trace_id` to your [`POST /v1/evaluate`](/api-reference/endpoint/evaluate) request.
  </Tab>
</Tabs>
