Bluejay tests and monitors voice, text, and email agents. Pick the channel your customers use, then open the page for how your agent runs.

## Voice

A Voice agent talks with customers on a call. Digital Humans call your agent, or your agent calls them, and Bluejay records, transcribes, and grades each call.

### Your own agent

- [Phone Number](/integrations/phone-number): call an agent that answers a phone number.
- [SIP](/integrations/sip): connect an agent over SIP.
- [WebSocket](/integrations/websockets): stream call audio to an agent over WebSocket.
- [LiveKit](/integrations/livekit): connect an agent that runs as a LiveKit Agents worker.
- [Pipecat](/integrations/pipecat): test an agent on Pipecat Cloud.
- [OpenAI Realtime](/integrations/openai-realtime): test an agent built on OpenAI Realtime.

### Voice platforms

- [Vapi](/integrations/vapi): test Vapi assistants and score live calls.
- [Retell](/integrations/retell): test Retell agents and score live calls.
- [ElevenLabs](/integrations/eleven-labs): test ElevenLabs agents and score live calls.
- [Bland](/integrations/bland): test Bland pathways and score live calls.
- [Sierra](/integrations/sierra): test Sierra voice agents.
- [Amelia](/integrations/amelia), [Google CES](/integrations/google-ces), and [Dialogflow CX](/integrations/google-dfcx): test by voice or by chat, depending on the agent's mode.

## Text

A Text agent talks with customers in chat or SMS. Digital Humans message your agent, and Bluejay grades each conversation.

### Your own agent

- [Chat Completions](/integrations/openai-compatible): test an agent that answers OpenAI-style requests.
- [HTTP Webhook](/integrations/http-webhooks): test any other chat agent on your own server.
- [Phone Number](/integrations/phone-number): test an SMS agent with the **SMS** connection type.

### Chatbot platforms

- [Kore.ai](/integrations/kore): test a Kore.ai chatbot.
- [Amelia](/integrations/amelia), [Google CES](/integrations/google-ces), and [Dialogflow CX](/integrations/google-dfcx): test by voice or by chat, depending on the agent's mode.

## Email

An Email agent answers messages sent to its inbox. Digital Humans email your agent, and Bluejay grades whether the replies pass authentication and arrive.

- [Email](/integrations/email): connect the agent's inbox. Your inbox must [accept mail from Bluejay](/integrations/email#allow-bluejays-mail) first.

[Red Teaming](/test/red-teaming/overview) is not available for email agents yet.
