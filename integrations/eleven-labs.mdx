Connect ElevenLabs to test your agents with simulated callers and to score your live ElevenLabs calls. Bluejay syncs your agents and their workflows.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/elevenlabs-simulations-walkthrough.mp4"></video>

## Connect

Bluejay needs two values from ElevenLabs:

| Field | Value |
|---|---|
| Webhook Secret | The HMAC secret of your ElevenLabs post-call webhook. See [Monitor](#monitor). |
| ElevenLabs API Key | Your ElevenLabs API key. Bluejay uses it to sync agents, open calls, and get tool calls. |

1. In ElevenLabs, open **Developers > API Keys** and get an API key.
2. In Bluejay, enter it as **ElevenLabs API Key** on the **Eleven Labs** tab of the Integrations settings.
3. Click **Sync Agents from ElevenLabs** to import every agent with its prompt and workflow.
4. To keep Bluejay current when you change agents in ElevenLabs, turn on **Autosync from ElevenLabs**.

To connect one agent by hand instead of syncing, open its **Connection Settings**, choose the **ElevenLabs** tile, and set **ElevenLabs Agent ID**.

To edit a synced workflow, open the **Workflow** tab of the agent, where you can pull changes from ElevenLabs, push your edits back, and merge a branch into Main.

## Test

<Tabs>
<Tab title="Websocket">

Bluejay opens a live web call to the agent over websocket, so no phone number is necessary. The **ElevenLabs** tile is inbound only.

For a multi-agent workflow, **Generate From Workflow** makes Digital Humans for each path, so every branch of the workflow gets a test.

Simulations always use the Main branch, so merge other branches to Main before you test them.

<Tab title="Phone">

Bluejay dials the ElevenLabs phone number like a real caller. Use this path to test carrier audio, DTMF, and the real number. Tool calls are not linked to the result.

Use an Inbound Voice agent with the [Phone connection type](/test/simulations/create#connect-your-agent) and the ElevenLabs number.

## Monitor

ElevenLabs sends each production call to Bluejay through a post-call webhook.

1. In ElevenLabs settings, find **Post-Call Webhook** and click **Select Webhook > Create Webhook**.
2. Set the URL to `https://api.getbluejay.ai/v1/integrations/ElevenLabs`.
3. Keep **Webhook Auth Method** as **HMAC** and click **Create**.
4. Copy the webhook secret into **Webhook Secret** in Bluejay.
5. In each ElevenLabs agent, open **Security > Post Call Webhook** and select the webhook.

<video controls muted playsInline preload="metadata" poster="/images/elevenlabs-1-webhook.jpg" src="/images/elevenlabs-1-webhook.mp4" aria-label="Set up the ElevenLabs webhook" />

If your own service relays the ElevenLabs payload to Bluejay, send it with a Bluejay API key instead. A payload that your service changed no longer matches the ElevenLabs signature, so Bluejay cannot verify it with the webhook secret.

```bash
curl -X POST https://api.getbluejay.ai/v1/integrations/ElevenLabs \
  -H "X-API-Key: $BLUEJAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d @elevenlabs-post-call-body.json
```

To attach your own fields, add a top-level `metadata` object to the payload. You can then use each field in a [metric prompt](/test/custom-metrics/overview#prompting-guide), for example as `{{member_id}}`.

```json
{
  "type": "post_call_transcription",
  "data": { },
  "metadata": { "member_id": 124356, "clinic": "Bluejay Clinic" }
}
```

Bluejay sets these metadata keys itself and overwrites any value you send for them:

- `eleven_labs_conversation_id`
- `eleven_labs_user_id`
- `eleven_labs_agent_id`
- `organization_id`
- `call_duration_secs`
- `termination_reason`
- `cost`
- `main_language`
- `original_webhook_data`

## Limits

| Symptom | Cause |
|---|---|
| Run fails with a missing integration error | No API key is saved. Bluejay needs the key at run time. |
| **No Connection** with `CUSTOMER_CONCURRENCY_LIMIT` | The run is over the concurrency of your ElevenLabs plan. Lower the max concurrency in Bluejay. |
| Edits do not show in the call | The edits are on a branch other than Main. |
| **No Connection** with `ELEVEN_LABS_AUTH_FAILED`, `MISSING_ELEVEN_LABS_INTEGRATION`, or `MISSING_ELEVEN_LABS_AGENT_ID` | The key is rejected, no key is saved, or the agent has no **ElevenLabs Agent ID**. |
| **No Connection** with `ELEVEN_LABS_BRIDGE_CONNECT_FAILED` or `ELEVEN_LABS_SESSION_SETUP_FAILED` | ElevenLabs accepted the connection but did not start a session. Run the call again. |
| **Call Dropped** with `ELEVEN_LABS_AGENT_ERROR`, `ELEVEN_LABS_AGENT_START_FAILED`, or `ELEVEN_LABS_MONITORING_ERROR` | The agent reported an error, did not start its turn, or Bluejay lost the monitoring connection. |
| Tool calls missing or partial | Bluejay gets them after the call. Long calls can return partial results. |
