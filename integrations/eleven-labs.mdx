The ElevenLabs integration syncs your ElevenLabs agents and their workflows into Bluejay and runs simulations against them. It also sends production calls to Bluejay through the post-call webhook.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/elevenlabs-simulations-walkthrough.mp4"></video>

## Connect

Get an API key in ElevenLabs under **Developers > API Keys**. Then go to **Settings > Integrations > Eleven Labs** in Bluejay.

| Field | Value |
|---|---|
| Webhook Secret | The HMAC secret of your ElevenLabs post-call webhook. See [Monitor](#monitor). |
| ElevenLabs API Key | Your ElevenLabs API key. Bluejay uses it to sync agents, open calls, and get tool calls. |
| Sync Agents from ElevenLabs | Imports every agent with its name, prompt, and workflow into the **Synced from ElevenLabs** folder. |
| Autosync from ElevenLabs | Syncs agents again on a schedule. |

To connect one agent by hand, open its **Connection Settings**, choose the **ElevenLabs** tile, and set **ElevenLabs Agent ID**.

Synced workflows show in the **Workflow** tab of the agent. **Sync** pulls the latest workflow, and **Push** sends your edits back. You can also change the branch or merge a branch to Main.

## Test

<Tabs>
<Tab title="Websocket">

Bluejay opens a live web call to the agent over websocket. No phone number is necessary. The agent `first_message` and the Digital Human settings decide who speaks first. Bluejay gets tool calls from the ElevenLabs conversation history after the call.

1. Create a simulation on the **Simulations** page and select the agent.
2. Add Digital Humans. For a multi-agent workflow, choose **Generate From Workflow** to make Digital Humans for each path.
3. Click **Create New Run**, then **Run N calls**.

Simulations always use the Main branch. Merge other branches to Main before you test them.

<video controls muted playsInline preload="metadata" poster="/images/elevenlabs-sim-generate.jpg" src="/images/elevenlabs-sim-generate.mp4" aria-label="Generate Digital Humans from a synced workflow" />

</Tab>
<Tab title="Phone">

Bluejay dials the ElevenLabs phone number like a real caller. Use this to test carrier audio, DTMF, and the real number. Tool calls are not linked to the result.

1. Create an agent with type **Inbound**, mode **Voice**, and the **Phone** connection type.
2. Set **Your Agent's Phone Number** in E.164 format, for example `+15551234567`.
3. Create and run a simulation.

</Tab>
</Tabs>

## Monitor

ElevenLabs sends each production call to Bluejay through a post-call webhook.

1. In ElevenLabs settings, find **Post-Call Webhook** and click **Select Webhook > Create Webhook**.
2. Set the URL to `https://api.getbluejay.ai/v1/integrations/ElevenLabs`.
3. Keep **Webhook Auth Method** as **HMAC** and click **Create**.
4. Copy the webhook secret into **Webhook Secret** in Bluejay.
5. In each ElevenLabs agent, open **Security > Post Call Webhook** and select the webhook.

<video controls muted playsInline preload="metadata" poster="/images/elevenlabs-1-webhook.jpg" src="/images/elevenlabs-1-webhook.mp4" aria-label="Set up the ElevenLabs webhook" />

If you relay the ElevenLabs payload through your own service, send it with a Bluejay API key. A changed payload no longer matches the ElevenLabs signature.

```bash
curl -X POST https://api.getbluejay.ai/v1/integrations/ElevenLabs \
  -H "X-API-Key: $BLUEJAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d @elevenlabs-post-call-body.json
```

Add a top-level `metadata` object to attach your own fields. You can group widgets by them, filter the **Logs** page, use them in alerts, and use them as `{{member_id}}` in a [metric prompt](/key-concepts/custom-metrics/prompting-guide).

```json
{
  "type": "post_call_transcription",
  "data": { },
  "metadata": { "member_id": 124356, "clinic": "Bluejay Clinic" }
}
```

Bluejay overwrites these metadata keys: `eleven_labs_conversation_id`, `eleven_labs_user_id`, `eleven_labs_agent_id`, `organization_id`, `call_duration_secs`, `termination_reason`, `cost`, `main_language`, and `original_webhook_data`.

## Limits

| Symptom | Cause |
|---|---|
| Run fails with a missing integration error | No API key is saved. Bluejay needs the key at run time. |
| `NO_CONNECTION` with an auth error | The API key is not valid. |
| `NO_CONNECTION` with a concurrency error | The run is over the concurrency of your ElevenLabs plan. |
| Edits do not show in the call | The edits are on a branch other than Main. |
| Tool calls missing or partial | Bluejay gets them after the call. Long calls can return partial results. |
