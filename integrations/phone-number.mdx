Each test goes over the real carrier path, between your agent's number and a number that each Digital Human owns.

## Voice calls

Create a Voice agent with the **Phone** connection type, and enter your agent's phone number in E.164 format, for example `+15551234567`. An Outbound agent with an **Outbound Trigger Webhook URL** does not need a number. The agent type sets who places the call:

- **Inbound**: your agent answers calls. When a run starts, each Digital Human calls your agent's number.
- **Outbound**: your agent places calls. Each Digital Human waits on its own number until your agent calls it. See [Outbound agents](#outbound-agents) for how your agent learns when to call.

Bluejay sends the result ID that links tool calls and traces to the result in a SIP header, but the public phone network usually drops custom SIP headers before they reach your agent. If you need that link, connect the agent over [SIP](/integrations/sip) or through your voice platform's integration page.

## SMS

Create a Text agent with the **SMS** connection type and your agent's phone number. The agent type sets who texts first:

- **Inbound**: each Digital Human texts your agent's number.
- **Outbound**: your agent texts each Digital Human first. Bluejay matches the messages to the test by your agent's number and the Digital Human's number, so make sure your agent texts from the number saved on the agent.

Bluejay grades the run from the transcript. To start an SMS run from the API, use [Queue SMS Simulation Run](/api-reference/endpoint/queue-sms-simulation-run).

## Outbound agents

An Outbound agent places the call or sends the first text, so give each Digital Human a phone number. The Digital Humans wait on their lines until your agent reaches them or the run times out, so your agent needs to know when a run starts and which numbers to contact. Use one of these two triggers:

- **Outbound Trigger Webhook URL** on the agent. Bluejay sends one `POST` for each conversation, and your system then calls or messages the Digital Human. See [Outbound trigger webhook](/test/simulations/reference#outbound-trigger-webhook) for the body, headers, and retries.
- **`outbound_simulation_started` event** on a [webhook](/api-reference/webhooks). For a voice agent, Bluejay sends one event per run with the numbers to call. The [event payload](/api-reference/webhook/events-webhook) lists the numbers.

## Digital Human numbers

Each Digital Human calls or texts from its own number on the Digital Human **Connection** tab. Buy numbers in the [workspace](/administration/workspaces) where your Digital Humans live, because a number stays in the workspace you buy it in. See [Connection](/test/simulations/digital-humans#connection) for buying numbers.

## Example

Say your support line is an inbound voice agent at `+15551234567`, and you want to test it before you ship a prompt change.

<Steps>
<Step title="Create the agent">
Create a Voice agent with type **Inbound** and the **Phone** connection type, and enter `+15551234567` as its phone number.
</Step>
<Step title="Run a simulation">
[Create a simulation](/test/simulations/create) for the agent with Digital Humans, and run it. Each Digital Human calls `+15551234567` from its own number and talks to your agent as a customer would.
</Step>
<Step title="Read the results">
Bluejay records, transcribes, and grades each call against your success criteria and custom metrics. See [Simulation Results](/test/simulations/create#read-the-results).
</Step>
</Steps>

## Limits

If a call fails to connect because the number is not valid, the result shows `SIP_DIAL_FAILED`. If the caller ID is not verified, it shows `UNUSABLE_CALLER_ID`. If a newer simulation reuses a Digital Human's number while a test is running, Bluejay stops the older test with `SIP_TRUNK_RECYCLED`. See [Error codes](/test/simulations/reference#error-codes) for what to do.
