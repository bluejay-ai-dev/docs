The Bland integration syncs your Bland pathways into Bluejay as agents, runs simulations against them, and sends production Bland calls to Bluejay through a webhook.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/bland-walkthrough.mp4"></video>

## Connect

Go to **Settings > Integrations > Bland** in Bluejay.

| Field | Value |
|---|---|
| Webhook Secret | The webhook signing secret from the **General** tab of your Bland organization settings. Bluejay uses it to verify webhooks. |
| API Key | Your Bland API key. Bluejay uses it to pull pathways and push changes back. |
| Sync Agents from Bland | Imports every pathway as an agent in the **Synced from Bland** folder. Needs the API key. |
| Autosync from Bland | Syncs pathways again on a schedule. |

On each agent, the **Bland** tile has one more field:

| Field | Value |
|---|---|
| Call settings (Optional) | JSON with the same call parameters you send to Bland in production. Bluejay sends them with every simulated call. Keys you leave out keep the Bland default. |

## Test

Sync picks the voice path for each pathway. A pathway with a Bland web agent uses the websocket path. A pathway without one uses the phone path.

<Tabs>
<Tab title="Websocket">

Bluejay opens a Bland web-agent session over websocket. No phone number is necessary. The pathway must have a web agent.

1. Sync your pathways, or choose the **Bland** voice tile on the agent.
2. Create a simulation on the **Simulations** page and add Digital Humans.
3. Click **Create New Run**, then **Run N calls**.

</Tab>
<Tab title="Phone">

Bland places a real phone call from the pathway to the Digital Human. Bluejay starts the call through the Bland API and tags it `environment: staging` so it stays out of your production reports.

1. Set the agent type to **Outbound**.
2. Give each Digital Human a phone number.
3. Create and run the simulation.

To have Bluejay dial a Bland number instead, create an agent with the **Phone** connection type and set **Your Agent's Phone Number** in E.164 format.

</Tab>
<Tab title="Chat">

Bluejay sends text turns to the pathway through the Bland chat API.

1. Set the agent mode to **Text**.
2. Choose the **Bland** text tile.
3. Create and run the simulation.

</Tab>
</Tabs>

## Monitor

Bland sends production calls to Bluejay through the phone number webhook. Bluejay matches each call to an agent by its phone number or pathway ID.

1. In Bland, open your phone number settings.
2. In the **Advanced** section, set the webhook URL to `https://api.getbluejay.ai/v1/integrations/bland`.
3. Save the inbound call changes.
4. In Bluejay, make sure the agent has the same phone number, or is synced from the same pathway.
