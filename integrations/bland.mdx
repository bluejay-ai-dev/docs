## Connect

Enter these on the **Bland** tab of the Integrations settings in Bluejay.

| Field | Value |
|---|---|
| Webhook Secret | The webhook signing secret from the **General** tab of your Bland organization settings. Bluejay uses it to verify webhooks. |
| API Key | Your Bland API key. Bluejay uses it to pull pathways and push changes back. |

**Sync Agents from Bland** imports every pathway as an agent. Turn on **Autosync from Bland** to keep Bluejay current when you change pathways in Bland.

In the **Workflow** tab of a synced agent, pull a pathway version from Bland, push your edits back, and publish a version.

On each agent, the **Bland** tile has one more field:

| Field | Value |
|---|---|
| Call settings (Optional) | JSON with the same call parameters you send to Bland in production. Bluejay sends them when Bland places a phone call. Websocket and chat runs do not use them. Keys you leave out keep the Bland default. Bluejay rejects unknown keys, and it sets `phone_number`, `pathway_id`, `pathway_version`, `from`, `metadata`, `request_data`, `webhook`, and `webhook_events` itself. |

## Test

Sync picks the voice path for each pathway. A pathway with a Bland web agent uses the websocket path. A pathway without one uses the phone path.

<Tabs>
<Tab title="Websocket">

Bluejay opens a Bland web-agent session over websocket. No phone number is necessary. The pathway must have a web agent. Use this path to iterate on pathway logic.

</Tab>
<Tab title="Phone">

Bland places a real phone call from the pathway to the Digital Human. Bluejay tags it `environment: staging` so it stays out of your production reports. The agent type must be **Outbound**, and each Digital Human needs a phone number.

To have Bluejay dial a Bland number instead, create an agent with the **Phone** connection type and set **Your Agent's Phone Number** in E.164 format.

</Tab>
<Tab title="Chat">

Set the agent mode to **Text** and choose the **Bland** text tile. Bluejay sends text turns to the pathway through the Bland chat API.

</Tab>
</Tabs>

## Monitor

Bland sends production calls to Bluejay through the phone number webhook.

1. In Bland, open your phone number settings.
2. In the **Advanced** section, set the webhook URL to `https://api.getbluejay.ai/v1/integrations/bland`.
3. Save the inbound call changes.
4. In Bluejay, make sure the agent has the same phone number, or is synced from the same pathway.

For an [uptime monitor](/monitor/uptime/overview) on an Outbound agent, Bluejay tells Bland to place each check call. You do not need an outbound trigger webhook.
