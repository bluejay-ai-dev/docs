Bluejay syncs your CES agents.

## Connect

CES uses the same **Google Agents** credential as [Dialogflow CX](/integrations/google-dfcx#connect). Set it up there. For keyless access, run the setup script with `--ces`.

The service account needs all three roles.

| Use | Permissions | Predefined role |
|---|---|---|
| Sync | `ces.apps.get`, `ces.apps.list`, `ces.deployments.get`, `ces.deployments.list` | `roles/ces.viewer` |
| Run simulations | `ces.sessions.runSession`, `ces.sessions.bidiRunSession` | `roles/ces.client` |
| Quota | `serviceusage.services.use` | `roles/serviceusage.serviceUsageConsumer` |

Turn on the `ces.googleapis.com` API in the project. Then click **Sync Agents from Google** in **Settings > Integrations > Google Agents**. Sync creates one agent for each CES app it finds.

To connect one agent by hand, open its **Connection Settings** and choose the **Google CES** tile.

| Field | Value |
|---|---|
| CES Deployment Path | `apps/<app>/deployments/<deployment>`. In CX Agent Studio, open **Deployed channels** and copy the **Deployment ID**. |

## Test

The connection type decides the path.

<Tabs>
<Tab title="Voice">

Bluejay streams audio between the Digital Human and the agent in real time. No phone number is necessary. This is inbound only.

1. Choose the **Google CES** voice tile.
2. Create a simulation and add Digital Humans.
3. Click **Create New Run**, then **Run N calls**.

</Tab>
<Tab title="Chat">

Bluejay sends text turns to the agent.

1. Set the agent mode to **Text** and choose the **Google CES** text tile.
2. Create and run a simulation.

</Tab>
</Tabs>

## Limits

- Bluejay always replies `{"status": "ok"}` to client-side tool calls. You cannot set a different tool response.
- Bluejay cannot push edits to CES agents.
- Without `serviceusage.services.use`, each run fails with `USER_PROJECT_DENIED`.
