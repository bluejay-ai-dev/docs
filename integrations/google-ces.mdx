Connect Google CES to test your CES agents with simulated calls and chats before you release a change. Bluejay syncs your CES agents, so you do not set up each one by hand.

## Connect

1. Set up the **Google Agents** credential as described in [Dialogflow CX](/integrations/google-dfcx#connect). CES uses the same credential. For keyless access, run the setup script with `--ces`.
2. Give the service account all three roles in the table below.
3. Turn on the `ces.googleapis.com` API in the project.
4. Click **Sync Agents from Google**. It creates one agent for each CES app it finds.

| Use | Permissions | Predefined role |
|---|---|---|
| Sync | `ces.apps.get`, `ces.apps.list`, `ces.deployments.get`, `ces.deployments.list` | `roles/ces.viewer` |
| Run simulations | `ces.sessions.runSession`, `ces.sessions.bidiRunSession` | `roles/ces.client` |
| Quota | `serviceusage.services.use` | `roles/serviceusage.serviceUsageConsumer` |

To connect one agent by hand instead of syncing, open its **Connection Settings** and choose the **Google CES** tile.

| Field | Value |
|---|---|
| CES Deployment Path | `apps/<app>/deployments/<deployment>`. In CX Agent Studio, open **Deployed channels** and copy the **Deployment ID**. |

## Test

The connection type you choose decides whether Bluejay tests by voice or by chat.

<Tabs>
<Tab title="Voice">

Choose the **Google CES** voice tile. Bluejay streams audio between the Digital Human and the agent in real time, so no phone number is necessary. This path is inbound only.

</Tab>
<Tab title="Chat">

Set the agent mode to **Text** and choose the **Google CES** text tile. Bluejay sends text turns to the agent.

</Tab>
</Tabs>

## Limits

- Bluejay always replies `{"status": "ok"}` to client-side tool calls. You cannot set a different tool response.
- Bluejay cannot push edits to CES agents.
- Without `serviceusage.services.use`, each run fails with `USER_PROJECT_DENIED`.
