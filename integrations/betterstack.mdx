Connect Better Stack to open an incident when a Bluejay alert triggers or an uptime monitor goes DOWN, and to resolve it when the monitor recovers. Bluejay posts to a Better Stack incoming webhook; you tell Better Stack how to read the payload once, then turn on Better Stack on any alert or monitor.

### Prerequisites

- **A Bluejay account** with access to Organization Settings
- **A Better Stack team** where you can add integrations

### 1. Create an incoming webhook in Better Stack

1. In Better Stack, open **Integrations** and choose **Incoming webhook**
2. Name it (for example `Bluejay`) and save
3. Copy the **Webhook URL**. It looks like `https://uptime.betterstack.com/api/v1/incoming-webhook/...`

### 2. Map the payload

Bluejay sends this JSON on every event:

```json
{
  "event_action": "trigger",
  "dedup_key": "uptime-monitor-8c5d...",
  "severity": "error",
  "title": "Uptime Monitor Down",
  "description": "Booking Agent is down. Failed checks: Agent Responds",
  "summary": "Uptime Monitor Down: Booking Agent is down. Failed checks: Agent Responds",
  "links": [{ "href": "https://app.getbluejay.ai/monitor/alerts/...", "text": "View Alert: Booking Agent" }],
  "source": "bluejay-notification-service"
}
```

Set the webhook rules in Better Stack so incidents open and close on their own:

| Rule | Field | Value |
| --- | --- | --- |
| Start incident when | `event_action` | equals `trigger` |
| Resolve incident when | `event_action` | equals `resolve` |
| Alert ID | `dedup_key` | |
| Title | `title` | |
| Cause | `description` | |

Use the **Sample webhook data** box in Better Stack with the JSON above to check the rules before saving.

### 3. Paste the URL into Bluejay

1. Log into your **Bluejay Dashboard**
2. Click your **Organization** in the bottom left corner
3. Select **Integrations**, then open the **Better Stack** tab
4. Paste the webhook URL and click **Save**

### 4. Turn it on for alerts and monitors

- **Alerts**: create or edit an alert under **Monitor → Alerts** and switch on **Better Stack Notifications**. Use **Send test notification** to open a test incident.
- **Uptime monitors**: create or edit a monitor under **Monitor → Uptime** and switch on **Better Stack Notifications**. DOWN opens an incident, recovery resolves it.

### How incidents are keyed

Every uptime monitor uses one stable alert ID, so a DOWN and its recovery land on the same incident. Simulation alerts trigger only, one incident per run, and never resolve automatically.
