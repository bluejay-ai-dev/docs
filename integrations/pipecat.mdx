## Connect

<Steps>
<Step title="Deploy the agent">
Deploy your agent to Pipecat Cloud with the [Pipecat quickstart](https://docs.pipecat.ai/getting-started/quickstart). Note the agent name in `pcc-deploy.toml`.
</Step>
<Step title="Add a public API key">
In the Pipecat dashboard, open **API Keys** and create a key on the **Public** tab. Paste it on the **Pipecat** tab of the Integrations settings. A private key does not work: Bluejay needs a key that starts with `pk_`.
</Step>
<Step title="Create the agent">
Create an Inbound Voice agent with the **Pipecat** connection type, and enter the agent name as **Pipecat Agent Name**. The **Pipecat** connection supports inbound agents only.
</Step>
</Steps>

## Fields

For each simulated call, Bluejay starts a session for your agent in a Daily room and joins the room as a Digital Human. After you create the agent, you can set two more fields in its **Connection Settings**:

- **Pipecat Agent Configuration**: JSON that Bluejay sends to your agent as `body` on start.
- **Pipecat Room Properties**: JSON that Bluejay merges into the Daily room properties.

To report tool calls from a simulation, have your bot read its result ID from `args.body`. Bluejay adds the simulation IDs (`X-Simulation-Result-Id` and the other `X-` keys) to the `body` it sends on start. Then send the tool calls to [`/v1/update-simulation-result`](/api-reference/endpoint/update-simulation-result).

## Troubleshooting

| Symptom | Fix |
|---|---|
| **No Connection** with <Code>PIPECAT_CONNECTION_FAILED</Code> | The Pipecat session stopped before audio started. Make sure the saved key starts with `pk_`. |
| Run fails at start | Save a Pipecat key, and set **Pipecat Agent Name** on the agent. |
