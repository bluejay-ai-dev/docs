Connect PagerDuty to open an incident when a Bluejay alert triggers or an uptime monitor goes DOWN, and to resolve it when the monitor recovers. Bluejay sends PagerDuty Events API v2 events using a routing key from your PagerDuty service.

### Prerequisites

- **A Bluejay account** with access to Organization Settings
- **A PagerDuty service** you can add integrations to

### 1. Get a routing key

1. In PagerDuty open the service that should receive Bluejay incidents
2. Under **Integrations**, add an **Events API V2** integration
3. Copy the **Integration Key** (the routing key)

### 2. Paste it into Bluejay

1. Log into your **Bluejay Dashboard**
2. Click your **Organization** in the bottom left corner
3. Select **Integrations**, then open the **PagerDuty** tab
4. Paste the routing key and click **Save**

### 3. Turn it on for alerts and monitors

- **Alerts**: create or edit an alert under **Monitor → Alerts** and switch on **PagerDuty Notifications**. Use **Send test notification** to open a test incident.
- **Uptime monitors**: create or edit a monitor under **Monitor → Uptime** and switch on **PagerDuty Notifications**. DOWN triggers an incident, recovery resolves it.

### How incidents are keyed

Every uptime monitor uses one stable dedup key, so a DOWN and its recovery land on the same incident. Simulation alerts trigger only, one incident per run, and never resolve automatically.
