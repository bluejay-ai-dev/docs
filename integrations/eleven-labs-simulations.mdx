Sync your ElevenLabs agents into Bluejay and run simulations against them. Multi-agent workflows render as an editable graph, and you can generate digital humans that cover every path through the flow.

<video controls className="w-full aspect-video rounded-xl" src="/videos/elevenlabs-simulations-walkthrough.mp4"></video>

### Ways to connect

| You want to test... | How | Tool calls captured? |
|---|---|---|
| The agent's conversation behavior | The setup below, **recommended**. A WebSocket web call, direction-agnostic | Yes |
| The agent over its **real phone number** | [Phone connection](#phone-connection): Bluejay dials it like a real caller | No |

### How it connects

Bluejay places a live web call to your ElevenLabs agent over a WebSocket, so no phone number is needed and there's no inbound/outbound setup to choose: the same connection tests agents that answer calls and agents that place them. Whether the agent or the digital human speaks first is controlled by the agent's `first_message` and the persona's speaks-first setting. Tool calls are pulled from ElevenLabs' conversation history after the call ends.

Simulations always run against whatever is **live** on the agent (the Main branch). Edits on another branch don't affect the call until you merge to Main.

### Prerequisites

- An ElevenLabs API key
- At least one ElevenLabs agent
- A Bluejay account

## Setup

### 1. Save your ElevenLabs API key

In Bluejay, go to **Settings**, then **Integrations**, then the **Eleven Labs** tab. Paste your API key and save. It's stored once for your whole org.

<Note>
  You can attach an agent with just its Agent ID, but the API key is required at **run** time to open the call. Without it the run fails with a missing-integration error.
</Note>

### 2. Attach your ElevenLabs agent

Two options, and both import the agent's name, prompt, and workflow:

- **Sync all your agents**: in the same Integrations tab, click **Sync Agents from ElevenLabs**. Every agent in your account imports at once.
- **Pick one**: in **Create Agent**, choose the **ElevenLabs** connection type and select the agent from your account's list.

### 3. Create a simulation

1. Go to the **Simulations** page, click **Create Simulation** in the top left, and select your synced agent.
2. Add or auto-generate digital human personas.
3. If your agent uses a multi-agent workflow, choose **Generate From Workflow** instead: Bluejay lists every distinct path through the graph, and you pick how many digital humans to generate per path. Each one gets an intent that drives the agent down its assigned path.

<video autoPlay muted loop playsInline className="w-full rounded-xl" src="/videos/create-simulation.mp4"></video>

![Generate digital humans from a synced workflow](/images/elevenlabs-sim-generate.gif)

### 4. Run it

1. In the **Simulations** tab, click **Run** on the simulation you want to run.
2. Click **Run Calls**. Bluejay runs one call per digital human in the simulation.
3. When the runs finish, review the transcript, tool calls, and metric scores for each call.

## Editing the workflow in Bluejay

Synced multi-agent workflows appear in the **Workflows** tab of Agent Settings as an editable graph.

- **Sync** pulls the latest workflow from ElevenLabs; **Push** sends your edits back; **Branches** switches branches and merges to Main.
- Click any node to edit its voice, model, tools, and edge conditions in a side panel.
- Drag between two nodes to draw a new edge, then click the **Add condition** pill to set its trigger.

![The Workflows tab in Bluejay](/images/elevenlabs-sim-workflows-tab.gif)

## Phone connection

If your ElevenLabs agent is attached to a phone number (through ElevenLabs' Twilio or SIP trunk telephony), you can also test it the way a real caller reaches it.

1. Create an agent in Bluejay with type **Inbound**, mode **Voice**, and the **Phone** connection type.
2. Paste the agent's phone number in full international format (e.g. `+15551234567`).
3. Create a simulation and run it. Bluejay dials the number and the digital human holds the conversation.

Use this when you specifically want to exercise the real telephony path: carrier audio, DTMF, the exact number your customers dial. The tradeoff: tool calls aren't linked to the result over a plain phone call, so results cover the conversation itself (transcript, recording, metrics). For tool call capture, use the WebSocket setup above.

### Troubleshooting

| Problem | Cause | Fix |
|---|---|---|
| Run fails with a missing-integration error | No org API key saved | Save the key in Settings, then Integrations, then Eleven Labs |
| `NO_CONNECTION`, auth failed | Invalid API key | Re-enter the key |
| `NO_CONNECTION`, concurrency limit | Too many concurrent calls for your ElevenLabs plan | Raise your plan concurrency or lower Bluejay's max-concurrent |
| Agent not found | The Agent ID isn't on your account, or is blank | Check the ElevenLabs Agent ID on the connection |
| Edits aren't reflected in the call | You edited a non-Main branch | Merge to Main; simulations always hit the live agent |
| Tool calls missing or partial | They're fetched from ElevenLabs after the call | Expected on long calls; a valid API key is required to fetch them |
