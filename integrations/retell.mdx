The Retell integration syncs your Retell agents into Bluejay and runs simulations against them in both directions. It also sends production Retell calls to Bluejay through a webhook.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/retell-walk-through.mp4"></video>

## Connect

Create an API key in Retell under **Settings > API Keys**. The key must have the **Webhook** badge, because Bluejay uses it to verify webhook signatures. Then go to **Settings > Integrations > Retell** in Bluejay.

| Field | Value |
|---|---|
| API Key | Your Retell API key with the **Webhook** badge. |
| Sync Agents from Retell | Imports every Retell agent as an agent in the **Synced from Retell** folder. |
| Autosync from Retell | Syncs agents again on a schedule. |

Set the webhook on each agent in Retell:

1. Open the agent and click **Webhook Settings**.
2. Set **Agent Level Webhook URL** to `https://api.getbluejay.ai/v1/integrations/retell`.
3. Keep the events `call_started`, `call_ended`, and `call_analyzed` on.
4. Save and publish the agent.

<video controls muted playsInline preload="metadata" className="w-full rounded-xl" src="/videos/retell-sim-3.mp4"></video>

To connect one agent by hand, open its **Connection Settings**, choose the **Retell** tile, and set **Retell Agent ID**. The **+** menu at the top left also has a **Retell** option that saves the key and syncs in one step.

## Test

The agent **type** selects the path. Tool calls show in the **Tool Adherence** tab for inbound and outbound.

<Tabs>
<Tab title="Inbound">

Bluejay calls the agent through the Retell web-call bridge. No phone number is necessary.

1. Set the agent type to **Inbound**.
2. Create a simulation on the **Simulations** page and add Digital Humans.
3. Click **Create New Run**, then **Run N calls**.

<video controls muted playsInline preload="metadata" className="w-full rounded-xl" src="/videos/retell-sim-6.mp4"></video>

</Tab>
<Tab title="Outbound">

Bluejay tells Retell to place the call from the agent's number to each Digital Human.

1. In Retell, open **Phone Numbers** and select your number.
2. Set **Inbound Call Agent** and **Outbound Call Agent** to your agent.
3. In Bluejay, set the agent type to **Outbound**. The **Phone Number** field shows the bound number.
4. Give each Digital Human a phone number.
5. Create and run the simulation.

</Tab>
<Tab title="Phone">

Bluejay dials the Retell phone number like a real caller. Use this to test carrier audio, DTMF, and the real number. Tool calls are not linked to the result.

1. Create an agent with type **Inbound**, mode **Voice**, and the **Phone** connection type.
2. Set **Your Agent's Phone Number** in E.164 format, for example `+15551234567`.
3. Create and run a simulation.

</Tab>
</Tabs>

## Monitor

The same webhook sends each production call to Bluejay. The call shows on the **Logs** page and gets your metrics.

## Limits

| Symptom | Cause |
|---|---|
| Outbound call does not start | No Retell number is bound to the agent. There is no fallback number. |
| Sync or webhook returns 401 | The key is missing or does not have the **Webhook** badge. |
| `NO_CONNECTION` with a concurrency error | Retell returned 429 (inbound) or SIP 503 (outbound). Lower the max concurrency in Bluejay. |
| Tool calls missing | The agent webhook is not set. A backfill poller tries again, but it can miss calls. |
| Older call fails with `SIP_TRUNK_RECYCLED` | Concurrent outbound runs use the same Digital Human number. Give each run different numbers. |
