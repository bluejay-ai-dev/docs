Connect Retell to test your agents with simulated callers and to score your live Retell calls. Bluejay syncs your agents and tests both inbound and outbound calls.

<video controls muted playsInline preload="metadata" className="w-full aspect-video rounded-xl" src="/videos/retell-walk-through.mp4"></video>

## Connect

1. In Retell, open **Settings > API Keys** and create an API key with the **Webhook** badge. Bluejay uses this key to verify webhook signatures, so a key without the badge does not work.
2. In Bluejay, paste the key on the **Retell** tab of the Integrations settings.
3. Click **Sync Agents from Retell** to import every Retell agent.
4. To keep Bluejay current when you change agents in Retell, turn on **Autosync from Retell**.

Then set the webhook on each agent in Retell, so Retell sends each call to Bluejay:

1. Open the agent and click **Webhook Settings**.
2. Set **Agent Level Webhook URL** to `https://api.getbluejay.ai/v1/integrations/retell`.
3. Keep the events `call_started`, `call_ended`, and `call_analyzed` on.
4. Save and publish the agent.

<video controls muted playsInline preload="metadata" className="w-full rounded-xl" src="/videos/retell-sim-3.mp4"></video>

To connect one agent by hand instead of syncing, open its **Connection Settings**, choose the **Retell** tile, and set **Retell Agent ID**.

To work on an agent's graph, open the **Workflow** tab of the synced agent, where you can pull the graph from Retell and push your edits back.

## Test

The agent **type** selects the path. Tool calls show in the **Tool Adherence** tab.

<Tabs>
<Tab title="Inbound">

Bluejay calls the agent through the Retell web-call bridge, so no phone number is necessary. Use this path to iterate on agent logic and tool calls.

<video controls muted playsInline preload="metadata" className="w-full rounded-xl" src="/videos/retell-sim-6.mp4"></video>

</Tab>
<Tab title="Outbound">

Bluejay tells Retell to place the call from the agent's number to each Digital Human.

1. In Retell, open **Phone Numbers** and select your number.
2. Set **Inbound Call Agent** and **Outbound Call Agent** to your agent.
3. Give each Digital Human a phone number.

In Bluejay, the **Phone Number** field of an Outbound agent then shows the bound number.

</Tab>
<Tab title="Phone">

Bluejay dials the Retell phone number like a real caller. Use this path to test carrier audio, DTMF, and the real number. Tool calls are not linked to the result.

Use an Inbound Voice agent with the [Phone connection type](/key-concepts/agents/overview#modes-and-connections) and the Retell number.

</Tab>
</Tabs>

[Self-Improve](/key-concepts/self-improve/overview) supports agents that use the **Retell** connection type.

## Monitor

The webhook you set in [Connect](#connect) also sends each ended call to Bluejay. The call shows on the **Logs** page with its metric results. The call metadata that you set in Retell becomes conversation `metadata`, so custom metrics can use it as [dynamic variables](/key-concepts/custom-metrics/prompting-guide#dynamic-variables).

For an [uptime monitor](/monitor/uptime/overview) on an Outbound agent, Bluejay tells Retell to place each check call. You do not need an outbound trigger webhook.

## Limits

| Symptom | Cause |
|---|---|
| Outbound call fails with `UNUSABLE_CALLER_ID` | No Retell number is bound to the agent. There is no fallback number. |
| Sync or webhook returns 401 | The key is missing or does not have the **Webhook** badge. |
| **No Connection** with `CUSTOMER_CONCURRENCY_LIMIT` | Retell returned `429`. Lower the max concurrency in Bluejay. |
| Tool calls missing | The agent webhook is not set, or the Retell agent is not synced or connected to a Bluejay agent. |
| **No Connection** with `RETELL_AUTH_FAILED`, `MISSING_RETELL_INTEGRATION`, or `MISSING_RETELL_AGENT_ID` | The key is rejected, no key is saved, or the agent has no **Retell Agent ID**. |
| **No Connection** with `RETELL_BRIDGE_CONNECT_FAILED` or `RETELL_SESSION_SETUP_FAILED` | Retell accepted the connection but did not start a session. Run the call again. |
| **Call Dropped** with `RETELL_AGENT_ERROR`, `RETELL_AGENT_START_FAILED`, or `RETELL_MONITORING_ERROR` | The agent reported an error, did not start its turn, or Bluejay lost the monitoring connection. |
| Older call fails with **System Error** and `SIP_TRUNK_RECYCLED` | Concurrent outbound runs use the same Digital Human number. Give each run different numbers. |
