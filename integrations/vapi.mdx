This guide walks you through connecting your Vapi voice agents to Bluejay's observability software, so every production Vapi call streams into Bluejay for monitoring and evaluation.

### Quick Prerequisites

- **Vapi public and private API keys**
- **A Bluejay Account**

### Setting Up the Integration

### 1. Configure Organization Settings

1. Log into your **Bluejay Dashboard**
2. Click **Settings** in the bottom left corner
3. Open the **Integrations** tab and select **Vapi**


![Navigate to Integrations](/images/integrations.png)

### 2. Adding Your Vapi Key

1. Paste your **Public API Key** and **Private API Key** into their fields (both are required; the private key is what lets Bluejay sync your assistants)
2. Click **Save Changes**

![Save API Key](/images/enter-vapi.png)

### 3. Configuring Your Agent in Vapi

1. **Copy the Webhook URL given** in the Webhook configuration dropdown 
2. Navigate to your Vapi Agents dashboard and scroll down to the **Messaging** dropdown
3. **Paste the Webhook URL into the Server URL field**
4. Click **Add Header** and enter **secret** as the header name and your Vapi public API key as the Value

### 4. Configuring Your Agent in Bluejay

1. Open your agent's settings and go to the **Connection Settings** tab
2. Choose the **VAPI** tile under **Voice connection type**
3. Pick your assistant from the **VAPI Assistant ID** field (or paste the ID)
4. Click **Save Changes**
