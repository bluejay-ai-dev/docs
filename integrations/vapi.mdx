## Connect

Get both keys in Vapi under **Settings > API Keys**. Then go to **Settings > Integrations > Vapi** in Bluejay.

| Field | Value |
|---|---|
| Private API Key | Your Vapi private key. Bluejay uses it to sync assistants and open web calls. |
| Public API Key | Your Vapi public key. Vapi sends it in the `secret` header so Bluejay can verify the webhook. |

**Sync Agents from Vapi** imports every assistant. Turn on **Autosync from Vapi** to keep Bluejay current when you change assistants in Vapi.

Set the webhook on each assistant in Vapi:

1. Open the assistant, then **Advanced > Webhook Server**. On the classic UI, open **Messaging**.
2. Set **Server URL** to `https://api.getbluejay.ai/v1/integrations/vapi`.
3. Add a header named `secret` with your public key as the value.
4. Under **Server Messages**, keep only `end-of-call-report`.
5. Click **Publish**.

![Vapi webhook configuration](/images/vapi-sim-webhook.png)

An assistant that uses a Vapi workflow syncs with an empty prompt.

To connect one agent by hand, open its **Connection Settings**, choose the **VAPI** tile, and set **VAPI Assistant ID**.

In the **Workflow** tab of a synced agent, pull the graph from Vapi and push your edits back.

## Test

<Tabs>
<Tab title="Web call">

Bluejay calls the assistant through the Vapi web-call bridge. No phone number is necessary. Tool calls show in the **Tool Adherence** tab.

The web-call bridge is inbound only. The **Outbound** option is disabled on VAPI agents.

</Tab>
<Tab title="Phone">

Bluejay dials the Vapi phone number like a real caller. Use this to test carrier audio, DTMF, and the real number. Tool calls are not linked to the result.

Use an Inbound Voice agent with the **Phone** connection type, and set **Your Agent's Phone Number** in E.164 format, for example `+15551234567`.

</Tab>
<Tab title="SIP">

Bluejay dials a Vapi SIP URI. Use this when you need phone audio and tool calls on the same result.

1. In Vapi, go to **Phone Numbers > Create a new phone number** and choose **Free Vapi SIP**.
2. Set the **Server URL** on the SIP number to your own webhook.
3. In Bluejay, choose the **SIP** connection type and set **SIP URI** to the Vapi SIP URI.
4. In your webhook, read `simulation-result-id` from the `end-of-call-report`.
5. Send the tool calls and metadata to [`/v1/update-simulation-result`](/api-reference/endpoint/update-simulation-result).

```json
{
  "message": {
    "type": "end-of-call-report",
    "assistant": {
      "variableValues": {
        "simulation-run-id": "5678",
        "simulation-result-id": "1234"
      }
    }
  }
}
```

```python
import requests

def update_simulation_result(simulation_result_id, tool_calls, metadata):
    return requests.post(
        "https://api.getbluejay.ai/v1/update-simulation-result",
        headers={"X-API-Key": "<your-api-key>"},
        json={
            "simulation_result_id": simulation_result_id,
            "tool_calls": tool_calls,
            "metadata": metadata,
        },
    ).json()
```

</Tab>
<Tab title="Outbound">

Your assistant dials the Digital Humans. Tool calls are not linked to the result.

1. Create an agent with type **Outbound** and the **Phone** connection type.
2. Give each Digital Human a phone number.
3. Set **Outbound Trigger Webhook URL** on the agent, or subscribe a [webhook](/key-concepts/webhooks/overview) to `outbound_simulation_started`.
4. When the webhook fires, call the Vapi outbound call API once for each Digital Human.
5. Set `customer.number` to the `phone_number` from the payload.

</Tab>
</Tabs>

[Self-Improve](/key-concepts/self-improve/overview) supports agents that use the **VAPI** connection type.

## Monitor

The same webhook sends each production call to Bluejay when the call ends. The call shows on the **Logs** page with its metric results. The call metadata that you set in Vapi becomes Conversation `metadata`, so Custom Metrics can use it as [dynamic variables](/key-concepts/custom-metrics/prompting-guide#dynamic-variables).

## Limits

| Symptom | Cause |
|---|---|
| No tool calls in results | The webhook did not reach Bluejay. Check the Server URL and the `secret` header. |
| Sync runs but agents are missing | The private key is not saved. |
| **No Connection** with `VAPI_AUTH_FAILED`, `MISSING_VAPI_INTEGRATION`, or `MISSING_VAPI_ASSISTANT_ID` | The key is rejected, no key is saved, or the agent has no **VAPI Assistant ID**. |
| **No Connection** with `VAPI_BRIDGE_CONNECT_FAILED` or `VAPI_SESSION_SETUP_FAILED` | Vapi accepted the connection but did not start a session. Run the call again. |
| **Call Dropped** with `VAPI_AGENT_ERROR`, `VAPI_AGENT_START_FAILED`, or `VAPI_MONITORING_ERROR` | The assistant reported an error, did not start its turn, or Bluejay lost the monitoring connection. |
| A tool output says `No result returned` | Vapi reports that your tool timed out. Fix the tool in Vapi. |
