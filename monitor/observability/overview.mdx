Observability evaluates your production conversations against your Custom Metrics and shows the results on the Logs page, dashboards, alerts, and Issues.

## Send conversations

| Method | Use it when |
|--------|-------------|
| [`POST /v1/evaluate`](/api-reference/endpoint/evaluate) | You send conversations from your own backend. |
| [Retell](/integrations/retell), [Vapi](/integrations/vapi), [Bland](/integrations/bland), [ElevenLabs](/integrations/eleven-labs) | Your agent runs on one of these providers. |

Each conversation needs a recording, a transcript, or both. A TEXT agent accepts only a transcript or `transcript_url`.

## Send a conversation with the API

<Steps>
  <Step title="Get your API key">
    Copy a key from Settings → API Keys. Send it in the `X-API-Key` header.
  </Step>
  <Step title="Send the conversation">
    After the call ends, send a `POST` request to `https://api.getbluejay.ai/v1/evaluate`.
  </Step>
  <Step title="Get the results">
    Open the Logs page, or subscribe to the **Observability log evaluated** [webhook](/key-concepts/webhooks/overview). You can also poll [`GET /v1/observability/conversations/{conversation_id}`](/api-reference/endpoint/get-conversation) or [`GET /v1/retrieve-call-log/{call_id}`](/api-reference/endpoint/retrieve-call-log).
  </Step>
</Steps>

Minimal request:

```bash
curl -X POST https://api.getbluejay.ai/v1/evaluate \
  -H "X-API-Key: $BLUEJAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "123",
    "start_time_utc": "2026-07-16T18:00:00Z",
    "participants": [
      { "role": "AGENT", "spoke_first": true },
      { "role": "USER", "spoke_first": false }
    ],
    "recording_url": "https://storage.example.com/call.mp3"
  }'
```

The response contains a `call_id`. Use `external_agent_id` in place of `agent_id` to identify the agent by its provider ID.

## Request fields

| Field | Required | Description |
|-------|----------|-------------|
| `agent_id` or `external_agent_id` | Yes | The Bluejay agent ID, or your provider's agent ID. |
| `start_time_utc` | Yes | When the call started, in UTC. |
| `participants` | Yes | Exactly 2 entries. `role` is `AGENT` or `USER`. Set `spoke_first` on one. |
| `recording_url` / `recording_base64` | One of these, or a transcript | `.mp3`, `.mp4`, `.wav`, or `.m4a`. URL max 5000 characters. |
| `transcript` / `transcript_url` | One of these, or a recording | Entries with `start_offset_ms`, `end_offset_ms`, `speaker`, and `utterance`. |
| `call_direction` | No | `INBOUND` (default) or `OUTBOUND`, from the agent's view. |
| `tool_calls`, `events`, `metadata` | No | See [Tool Calls](/monitor/observability/tool-calls). |
| `trace_id` | No | Links an OpenTelemetry trace. See [Traces](/key-concepts/traces/overview). |
| `custom_metrics`, `custom_metric_tags` | No | Extra Custom Metrics to run on this call, by ID or by tag. |
| `label`, `version` | No | The Agent Version the call ran against. The default is the `production` label. |
| `tags` | No | Tags to filter the call by. |
| `multichannel` | No | Set `true` when each participant is on a separate audio channel. |

The [evaluate reference](/api-reference/endpoint/evaluate) lists all fields.
