With Issues, Bluejay identifies common problems with your agent from production calls.

If you are tracking issues from simulation results, see [Issues](/test/issues).

## How issues work

After Bluejay evaluates a production conversation, it finds where the call went wrong and matches each failure to similar failures from your other conversations.

Each issue has a failure mode:

- **Agent Failure**: the agent had a failure based on its conversations (transcripts).
- **System Error**: a tool call failed, the voice platform reported an error, or the agent got stuck repeating the same tool call.

## Work through an issue

<Steps>
  <Step title="Open the top issue">
    Start with the issue that hits the most conversations, and read a few of its conversations to see what the agent did.
  </Step>
  <Step title="Find the cause">
    Click **Investigate** to ask [Bluejay AI](/improve/bluejay-ai) what to change, or **Fix** to copy a prompt for your coding assistant.
  </Step>
  <Step title="Track the work">
    After your fix ships, monitor the failure with an [alert](/monitor/alerts) on a [custom metric](/monitor/metrics) that checks for it.
  </Step>
</Steps>
