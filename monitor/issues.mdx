Bluejay groups similar failures in your production calls into one issue, so you triage one problem in place of many failed calls. Production has its own issues list, separate from simulations.

If you are tracking issues from simulation results, see [Issues](/test/issues).

![The production Issues list with one row for each issue, showing its priority, status, failure mode, conversation count, and percent of conversations](/images/issues-list-monitor.png)

## Track an issue

To track the work on an issue, set its status. Supported statuses include:

- **Open**
- **In Progress**
- **Resolved**
- **Ignored**

To order the work across the team, set a priority. A new issue shows **No priority**. Supported priorities include:

- **Low**
- **Medium**
- **High**
- **Urgent**

## Issue types

| Type | Meaning |
|---|---|
| Agent Failure | Bluejay grouped similar failures into one issue. |
| System Error | Bluejay matched a known error, for example a [call error code](/test/simulations/reference#error-codes). |
