Bluejay groups similar failures in your production calls into one Issue, so you triage one problem in place of many failed calls. Production has its own Issues list, separate from simulations. Fix the Issue with the most conversations first.

If you are tracking issues from simulation results, see [Issues](/test/issues).

## Track an Issue

To track the work on an Issue, set its status. Supported statuses include:

- `open`
- `in_progress`
- `resolved`
- `ignored`

To order the work across the team, set a priority. A new Issue has no priority. Supported priorities include:

- `low`
- `medium`
- `high`
- `urgent`

## Issue types

| Type | Meaning |
|---|---|
| Agent Failure | Bluejay grouped similar failures into one Issue. |
| System Error | Bluejay matched a known error, for example a [call error code](/test/simulations/simulation-results#error-codes). |
