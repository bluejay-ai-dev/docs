## Set up a metric

<Steps>
  <Step title="Start a new metric">
    On the **Metrics** page, click **Create**, then **Create automatically**. Review the drafts and save the ones you want.

    For a hand-written metric, choose **Create manually** and use the [prompting guide](#prompting-guide).
  </Step>
  <Step title="Choose what it grades">
    ![The Create Metric dialog with a name and prompt filled in, and the Agents, Evaluates, and Runs on fields set](/images/metric-create-dialog.png)

    - **Agents**: the agents it applies to.
    - **Runs on**: production conversations, simulations, or both.
    - **Evaluates**: which side of the conversation it reads.

    **Runs on** and **Evaluates** default to everything.
  </Step>
</Steps>

## Tool calls, events, and metadata

A transcript does not show which tools your agent called. To grade tool calls, send them to Bluejay with the conversation. You can send events and metadata in the same way. `metadata` is a free-form JSON object for the whole conversation, and its keys fill a metric's [dynamic variables](#dynamic-variables).

### Send tool calls

Put `tool_calls`, `events`, and `metadata` in the same [`POST /v1/evaluate`](/api-reference/endpoint/evaluate) request as the transcript or recording, because you cannot add them later.

```json
{
  "agent_id": "123",
  "start_time_utc": "2026-07-16T18:00:00Z",
  "participants": [
    { "role": "AGENT", "spoke_first": true },
    { "role": "USER", "spoke_first": false }
  ],
  "recording_url": "https://storage.example.com/call.mp3",
  "tool_calls": [
    {
      "name": "check_order_status",
      "start_offset_ms": 2000,
      "description": "Look up order status by order ID",
      "parameters": { "order_id": "ORD-2024-001" },
      "output": { "status": "in_transit" }
    }
  ],
  "metadata": { "customer_tier": "premium" }
}
```
