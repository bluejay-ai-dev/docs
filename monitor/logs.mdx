## Get conversations into Logs

| Source | How conversations arrive |
|--------|--------------------------|
| [Retell](/integrations/retell) | Retell sends each ended call to the Bluejay webhook. |
| [Vapi](/integrations/vapi) | Vapi sends each ended call to the Bluejay webhook. |
| [Bland](/integrations/bland) | Bland sends each ended call to the Bluejay webhook. |
| [ElevenLabs](/integrations/eleven-labs) | ElevenLabs sends each post-call transcript to the Bluejay webhook. |
| [LiveKit](/integrations/livekit) | LiveKit Cloud sends room events to your per-organization Bluejay webhook URL. |
| [`POST /v1/evaluate`](/api-reference/endpoint/evaluate) | Your backend sends each conversation after it ends. |
| **Upload** | Upload one **Audio Call** or **Chat/Transcript** from the Logs page. |

Bluejay runs your Custom Metrics on each conversation when it arrives.

## Read a conversation

The table shows one row for each conversation. The default columns are **Date & Time**, **Agent**, **Status**, **Duration**, **ID**, **Caller Number**, **Label**, and **Issues**. Click the settings icon to show metric, metadata, and `Trace:` columns.

Use these controls to find conversations:

- **Time range**: **Last 24 hours**, **Last 7 days**, **Last 30 days**, **Last 90 days**, **All time**, or **Custom Range**.
- **Filter bar**: Select a field, an operator, and a value. Fields include **Status**, **Agent**, **Issue**, **Duration**, **Custom Metrics**, **Ended Reason**, latency fields, and **Metadata Filters**. You can also type a plain-text query, for example "failed calls yesterday".
- **Views**: Save the current filters as a view, and select it again later.
- **Table** and **Chart**: Show the conversations as rows or as a chart.

Click a row to open **Conversation Details**. It has these tabs:

| Tab | Shows |
|-----|-------|
| **Overview** | **Conversation Information**, **Summary**, and **Metadata**. |
| **Evals** | Results for built-in and Custom Metrics, in **General Metrics**, **Agent Metrics**, and **Customer Metrics**. Search the results, or filter by **Pass**, **Fail**, or **N/A**. |
| **Transcript** | The audio player and the transcript. Tool calls show at their position in the conversation. Click **Play from here** on a turn to start the audio there. |
| **Traces** | The OpenTelemetry spans linked to the conversation. See [Traces](/key-concepts/traces/overview). |

## Act on a conversation

Select one or more rows, then use the buttons above the table.

| Action | Result |
|--------|--------|
| **Reevaluate** | Runs the metrics again on up to 100 conversations. If all selected rows have the same agent, you can select a different Prompt Version. |
| **Replay** | Opens a simulation that tests the selected conversations against a **Target Agent**. See [Simulations](/test/simulations/overview). |
| **Metrics Lab** | Adds the conversations to a new or existing lab. See [Metrics Lab](/key-concepts/metrics-lab/overview). |
| **Delete** | Deletes the selected conversations. |
| **Export** | Downloads the conversations as a PDF package, JSON, or CSV. |

In the **Evals** tab, click **Edit metrics** to correct a metric result that you disagree with. In the **Transcript** tab, you can translate the transcript.
