## Get conversations into Logs

| Source | How conversations arrive |
|--------|--------------------------|
| Voice platform | Each ended call arrives after you [connect the platform](/integrations/vapi#monitor). |
| [`POST /v1/evaluate`](/api-reference/endpoint/evaluate) | Your backend sends each conversation after it ends. |
| **Upload** | Upload one **Audio Call** or **Chat/Transcript** from the Logs page. |

Bluejay runs your Custom Metrics on each conversation when it arrives.

## Find a conversation

Start from a failing metric or an Issue, then read the transcript to see where the agent went wrong. The search box accepts a plain-text query, for example "failed calls yesterday". If a transcript does not explain the failure, open the linked [Traces](/key-concepts/traces/overview).

## Act on conversations

- **Reevaluate** runs the metrics again. It can use a different Agent Version, so you can check a fix on real conversations.
- **Replay** tests the conversations against a **Target Agent** in a [simulation](/test/simulations/overview), so a real failure becomes a repeatable test.
- **Metrics Lab** adds the conversations to a [Metrics Lab](/key-concepts/metrics-lab/overview). Use it when a metric verdict looks wrong on many conversations.
- **Edit metrics** corrects a metric result that you disagree with.
