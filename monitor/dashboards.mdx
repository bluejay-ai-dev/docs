To create a dashboard visualizing your real-world calls, open **Observability → Dashboards**.

If you are setting up dashboards for simulation results, see [Dashboards](/test/dashboards).

![Observability dashboard with conversation count over time, conversation type, conversation count by agent, and latency over time widgets](/images/dashboards-observability.png)

## Build a dashboard

A dashboard holds widgets. Each widget charts one or more metrics, over time or broken down by agent or type.

To share a dashboard outside Bluejay, create a share link.

To get a notification when a metric crosses a value, add an [alert](/monitor/alerts).

## Build with Bluejay AI

Ask [Bluejay AI](/improve/bluejay-ai) to build a dashboard for you, for example "Make a dashboard of pass rate by agent for the last month". It can also add, change, and remove widgets.
