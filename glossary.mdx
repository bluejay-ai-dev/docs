  </div>
  <div data-glossary-item data-term="CHIRP"><Accordion title="CHIRP">
Conversational Handoff for Inter-agent Realtime Protocol. The message envelope for WebSocket simulations, with text, audio, status, and control message types.

See more: [WebSocket Integration](/simulation-integrations/websockets)
</Accordion></div>
  <div data-glossary-item data-term="Community"><Accordion title="Community">
A saved group of Digital Humans that you run again as a test suite. A Digital Human can be in more than one Community.

See more: [Communities](/key-concepts/communities/overview) | [API Reference](/api-reference/endpoint/create-community)
</Accordion></div>
  <div data-glossary-item data-term="Connection Type"><Accordion title="Connection Type">
How Bluejay reaches an Agent, for example Phone, SIP, Websocket, LiveKit, SMS, HTTP Webhook, Email, or a provider such as ElevenLabs or Retell.

See more: [Agents](/key-concepts/agents/overview#modes-and-connections)
</Accordion></div>
  <div data-glossary-item data-term="Conversation"><Accordion title="Conversation">
One call, text thread, or email thread between an Agent and a caller, with its transcript, metrics, and metadata. Production Conversations show on the Logs page.

See more: [Observability](/monitor/observability/overview) | [Retrieve Call Log API](/api-reference/endpoint/retrieve-call-log)
</Accordion></div>
  <div data-glossary-item data-term="Custom Metric"><Accordion title="Custom Metric">
A metric that you define to grade Conversations. An LLM-as-a-Judge metric uses a prompt. A formula metric combines other metrics. The same metric runs on simulations and production Conversations. The sidebar label is Metrics.

See more: [Custom Metrics](/key-concepts/custom-metrics/overview) | [API Reference](/api-reference/endpoint/create-custom-metric)
</Accordion></div>
  <div data-glossary-item data-term="Customer Traits"><Accordion title="Customer Traits">
Case facts that a Digital Human knows and can say, for example a member ID or date of birth. A fixed trait value makes runs repeatable.

See more: [Customer Traits](/key-concepts/customer-traits/overview)
</Accordion></div>
</section>

</Accordion></div>

</Accordion></div>
  <div data-glossary-item data-term="Digital Human"><Accordion title="Digital Human">
A simulated customer that calls, texts, or emails an Agent in a simulation. It has an intent, success criteria, traits, scripted responses, and behavior settings.

See more: [Digital Humans](/key-concepts/digital-humans/overview) | [Configuration](/key-concepts/digital-humans/configuration) | [API Reference](/api-reference/endpoint/create-digital-human)
</Accordion></div>
  <div data-glossary-item data-term="DTMF"><Accordion title="DTMF">
Dual-Tone Multi-Frequency. The tones of the phone keypad, including <code>*</code> and <code>#</code>. A Digital Human can send DTMF with the DTMF tool, a scripted response, or an extension.

See more: [Configuration](/key-concepts/digital-humans/configuration#tools)
</Accordion></div>
</section>

  <div data-glossary-item data-term="pcm_s16le"><Accordion title="pcm_s16le">
Signed 16-bit little-endian PCM. The raw audio format of the CHIRP WebSocket protocol.

See more: [WebSocket Integration](/simulation-integrations/websockets)
</Accordion></div>
  <div data-glossary-item data-term="Personality"><Accordion title="Personality">
A saved set of Digital Human behavior values, for example noise, speed, and patience. Each Digital Human in a run calls once as itself and once for each selected Personality.

See more: [Personalities](/key-concepts/digital-humans/personalities)
</Accordion></div>
  <div data-glossary-item data-term="Agent Version"><Accordion title="Agent Version">
A numbered copy of the system prompt of an Agent, with a commit message and Labels. Each edit creates a new version. Runs and Conversations record the version they used. The API field is <code>agent_version_id</code>, and <code>prompt_id</code> is an old name for it.

See more: [API Reference](/api-reference/endpoint/create-prompt-version)
</Accordion></div>
  <div data-glossary-item data-term="PSTN"><Accordion title="PSTN">
Public Switched Telephone Network: calls to phone numbers. A SIP connection skips PSTN and can carry headers for tool call tracking.

See more: [SIP Integration](/simulation-integrations/sip)
</Accordion></div>
</section>

  <div data-glossary-item data-term="Sample Rate"><Accordion title="Sample Rate">
The number of audio samples each second, in Hz. CHIRP uses 16,000 Hz.

See more: [WebSocket Integration](/simulation-integrations/websockets)
</Accordion></div>
  <div data-glossary-item data-term="Scenario"><Accordion title="Scenario">
A conversation graph that you build in the Scenario Builder, for example an IVR menu. Bluejay creates Digital Humans that follow its paths. A Scenario is different from a Workflow.

See more: [Scenario Builder](/key-concepts/scenario-builder/overview) | [API Reference](/api-reference/endpoint/create-scenario)
</Accordion></div>
  <div data-glossary-item data-term="Schedule"><Accordion title="Schedule">
A cron expression that runs a simulation at fixed times.

See more: [API Reference](/api-reference/endpoint/create-schedule)
</Accordion></div>
  <div data-glossary-item data-term="Simulation"><Accordion title="Simulation">
A set of Digital Humans, and optionally Personalities, that you run against one Agent. You can run a simulation many times. Custom Metrics score each run.

See more: [Simulations](/test/simulations/overview) | [API Reference](/api-reference/endpoint/create-simulation)
</Accordion></div>
  <div data-glossary-item data-term="Simulation Result"><Accordion title="Simulation Result">
The outcome of one Digital Human in a simulation run: scores, transcript, and metadata. You can add tool calls and metadata after the call with the API.

See more: [API Reference](/api-reference/endpoint/retrieve-simulation-result) | [Tool Calls & Metadata](/monitor/observability/tool-calls)
</Accordion></div>
  <div data-glossary-item data-term="Simulation Run"><Accordion title="Simulation Run">
One execution of a simulation. It gives a result for each Digital Human. You can compare runs to find regressions.

See more: [Simulation Runs](/test/simulations/simulation-runs) | [Queue Simulation Run API](/api-reference/endpoint/queue-simulation-run)
</Accordion></div>
  <div data-glossary-item data-term="SIP"><Accordion title="SIP">
Session Initiation Protocol. Connects voice systems directly, without PSTN. SIP calls can carry headers such as X-Simulation-Result-Id.

See more: [SIP Integration](/simulation-integrations/sip) | [Tool Calls & Metadata](/monitor/observability/tool-calls)
</Accordion></div>
  <div data-glossary-item data-term="Success Criteria"><Accordion title="Success Criteria">
The pass or fail condition of one Digital Human: one or two outcomes of the agent that the transcript can show.

See more: [Digital Humans](/key-concepts/digital-humans/overview)
</Accordion></div>
</section>
